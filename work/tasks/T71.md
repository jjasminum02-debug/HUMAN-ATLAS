## 고정 입력과 범위

`atlas-data/manifests/bodyparts3d-r4-t70/scope-inventory.json`의 `nextAcquisitionBatch`인 `T71-B01-TRUNK-SKELETON`만 처리한다. 정확한 source FJ ID는 `FJ3153, FJ3157, FJ3159, FJ3162, FJ3165, FJ3168, FJ3178, FJ3290, FJ3393`의 9개다. 흉골 component 3개, 요추 5개, 천골 1개이며 official FMA/compound/PART-OF 관계는 T70 target rows를 따른다. 총 1 batch, 최대 10개. 추가 source ID는 별도 task로 배정한다.

## 산출물과 필수 합격

공식 BodyParts3D R4 archive의 선택 member만 취득해 원본 header/FMA/BP/FJ/CRC/SHA와 좌표 단위·frame을 검증한다. 기존 T51/T52–55 원본·freeze·source bytes는 변경하지 않는다. 파생 GLB와 별도 manifest를 새 경로에 만든다. T53 몸통/T55 다리와 같은 source frame·static pose에서 9개를 중복 node 없이 결합한 실제 정면·후면·측면 render를 남기고, 요추–천골–골반 및 흉골–가슴우리의 눈에 띄는 위치 오류를 점검한다. AABB overlap만으로 실제 관절 접촉·표면 무관통을 주장하지 않는다. 1440/1024/390, 선택 ID/keyboard/console, 원본·파생 hash와 반복 변환을 확인한다. 누락·헤더 conflict는 held로 남기고 자의적 mirror/recenter/name binding은 금지한다.

이 task는 나머지 첫 시범 목표 11 source ID나 전체 35 뼈 누락을 완료했다고 선언하지 않는다. T70 통합 계약을 새 package에 확장하고 남은 목록을 확인해 T56 전에 필요한 다음 작은 취득 작업을 queue에 삽입한다. 공개 배포 권리와 anatomy review는 별도 상태다.
