- 핵심 필드 `label`, `korean`, `hanja`, `english`, `aliases[0]` 각각에 URL, 정확한 판본 또는 판본 미노출 사유, locator, 조회일, 접근방식을 기록한다.
- B05 TA2 이름은 Dalhousie가 호스팅하는 공식 PDF의 원문 텍스트를 열어 104쪽 문서의 Chapter 4 표 머리글과 배정된 행을 확인한다. FIPAT library URL의 HTTP 502, PDF 텍스트 계층 판독, 시각 페이지 검토 상태를 분리한다.
- KMLE는 사전 묶음의 정확한 판본/개정이 노출되지 않는 검색 발췌와 실제 열린 HTML 페이지를 분리한다. 완전한 출처 한자만 채택하고 다르게 보이는 한자/표기 후보는 합치지 않는다.
