# T11-B02 작업 명세 — 근군 용어 두 번째 배치

작성일: 2026-09-25. 상태: 실행 완료, 결측 포함. 이 명세는 실제 출처 대조와 검증의 증거가 아니다.

## 목적과 선행 조건

T11의 두 번째 최대 10개 용어 배치로, 기존 canonical 근군 ID에 근거가 확인된 한글 관용명·우리말·실제 출처 한자·영어/라틴어 표기를 연결한다. 선행: T11-B01의 배치·검색 overlay·필드별 evidence, T04의 부분 catalog/crosswalk, T03의 기존 데이터 계약. 전신 분모는 미동결 상태다.

## 출처와 데이터 규칙

- 기본 label은 출처에 실제로 있는 한글 관용명만 사용한다. 우리말, 실제 출처 한자, 영어/라틴어 동의어는 기존 ID의 별도 필드에 둔다.
- 필드마다 URL, 정확한 판본 또는 판본 미노출, locator, 조회일, 접근 방식을 기록한다.
- 검색 색인/발췌, 열어 읽은 페이지, 사람 해부학 검토는 독립 상태다. 용어 검색은 사람 검토로 승격하지 않는다.
- 없는 한자·합성 번역·group equivalence는 만들지 않는다. 모호한 값은 값을 비우고 이유와 확인 후보를 남긴다.
- 미확인 명칭을 학습 화면에 task 번호, JSON, 제작 도구와 함께 노출하지 않는다.

## 합격 기준

1. B02의 배정 ID 10개를 그대로 사용하고, 10개 모두 `web_checked_with_gaps` 또는 더 구체적인 조사 결과가 기록된다.
2. 모든 행은 label/korean/hanja/english/Latin alias의 값 또는 사유 있는 결측을 갖고, 값마다 field evidence에 URL·판본 상태·locator·날짜·접근 방식이 있다.
3. 필드 출처가 같은 ID로 연결되며 Hanja/한국어 충돌과 generic-near-match를 자동 동치어로 넣지 않는다.
4. 통합 검색 회귀, coverage/provenance validator, 기존 학습 overlay validator가 통과한다. 사람 검토는 계속 `not_performed`, `humanReviewed=false`다.
5. 사전 파일 hash, 기존 사용자 변경, OpenSim_Models의 HEAD/clean 상태를 작업 후 대조한다.
