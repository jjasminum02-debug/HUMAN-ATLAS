## 합격 기준

1. pilot muscle 6개를 각각 ID와 이름으로 찾고 선택할 수 있으며, 선택 항목과 화면/3D 모델이 일치하는지 확인한다.
2. 각 muscle의 이름→선택→3D→기시 및 정지 한국어 요약→상세 source 경로를 실제 브라우저에서 확인한다. 3개 뷰포트 폭(1440/1024/390), 키보드 탐색, 3D 선택, 첫 화면에서 정지 요약이 가려지는지, 출처 열기를 기록한다.
3. 6개 각각에 대해 Gray 판본/locator와 현대 자료 판본/locator를 구분한다. 검색 색인은 원문 확인으로, 웹 확인은 사람 해부학 검토로 표시하지 않는다. 해당 claim에 현대 근거가 없으면 `missing`/`needs_review`로 남긴다.
4. attachment별 exact surface candidate, text-only, missing geometry, human-review-pending을 서로 다른 분모·분자로 집계한다. 뼈 전체 검색 연결이나 geometry-null context record를 surface candidate로 세지 않는다.
5. UI 수정 시 해당 재현 결함이 해결됐음을 같은 브라우저 경로로 다시 확인한다. UI 수정이 없으면 그 이유를 기록한다.
6. T13c의 geometry-null drafts, T09 사용자 draft, 보호 파일·mesh와 `OpenSim_Models`를 전후 비교한다. T03/schema/provenance 검사, 관련 검색·공간자료 회귀, typecheck/build 및 `git diff --check`를 실행한다.
7. `reviewed`나 `reviewed_structure_release`를 만들지 않는다. T14a를 마친 후 T14b와 T15는 시작하지 않는다.

## 범위 밖 및 중단 조건

전신 목록 동결, 새 부착 좌표 생성, canonical 해부 claim의 추측 수정, 임의 Hanja/한글 번역, 사람 검토 대행, 공개·배포, 환자 진단·치료·침 시뮬레이션은 범위 밖이다. 외부 원문이나 적합한 표면 자료가 확인되지 않으면 미확인으로 명시한다. 기존 사용자 변경 또는 보호 파일 hash 불일치가 생기면 해당 파일 수정·저장을 중지하고 상태를 보고한다.
