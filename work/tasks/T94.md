# T94 — 광배근 Z-Anatomy exact-component·권리·frame gate

**상태:** planned_not_started · **담당:** Sol High · **위치:** T93 다음, T77 이전

## 입력과 범위

- T93 결정 및 evidence: `no_exact_source_found`; Z-Anatomy에는 package-level 후보가 있으나 정확한 mesh 객체가 노출되지 않았다.
- T73이 고정한 양측 광배근 visual target, T75의 BodyParts3D R4 결손, T50 source/scene/frame 계약을 사용한다.
- 공식 후보는 `Z-Anatomy/Models-of-human-anatomy` 저장소의 pinned commit `c7010a903b75a2fd24a13b1c2c4c3546a9223780`, archive root `Z-Anatomy.zip`, 그리고 Z-Anatomy app inventory의 `Resources/Models/FBX/MuscularSystem100.fbx`로 한정한다. 검색 결과의 파생 모델은 source evidence로 쓰지 않는다.

## 작업

1. 정확히 광배근 target만 조사한다. 공식 inventory에서 isolated object/member의 정확한 ID·path·edition/commit과 공식 제공 hash를 찾고, source ancestry와 underlying work를 객체 단위로 대조한다.
2. 원문 source가 명시하는 좌우·부분 구분만 기록한다. 한 generic object에서 양측을 추론하거나 mirror하지 않는다.
3. object-specific license/attribution, local technical use와 redistribution 권리를 각각 기록한다. repository-wide license를 구성요소 허가로 대체하지 말고 권리 보류를 유지한다.
4. unit, coordinate frame, transform, rest/reference pose를 원문 메타데이터에서 확인해 T50 frame과 비교한다. BodyParts3D ancestry만으로 좌표 호환을 가정하지 않는다.
5. 대형 archive와 aggregate FBX는 받지 않는다. 공식적으로 분리된 exact target asset 또는 작은 object-level metadata만 선택 취득할 수 있을 때만 원문 byte를 보존하고 SHA/hash provenance를 기록한다. exact member에 도달할 수 없으면 실패/미확인 사유를 남기고 누락 상태를 유지한다.

## 산출물과 합격 기준

- `work/reports/T94.md`, `work/evidence/T94/`, 필요한 경우 exact selected-source artifact를 기록한다.
- exact object identity, source lineage, rights, side/part, unit/frame/rest-pose를 각각 확인/미확인으로 판정하고 최종 상태를 `no_exact_source_found`, `candidate_requires_registration`, `metadata_candidate_frame_compatible` 중 하나로 기록한다.
- 획득이 가능해도 source-only/rights-held/unreviewed 상태를 유지한다. 이 task에서는 mesh conversion, canonical ID 생성, learner binding/UI, anatomy claim, human review, redistribution approval을 하지 않는다.
- exact object가 없거나 권리·frame을 확인할 수 없으면 T77 시각 gate는 partial로 남고 광배근을 보완했다고 보고하지 않는다.

## 금지와 다음 단계

전체 atlas download, body-wide ingest, mirror, 추정 정합, 합성 anatomy, 새 canonical ID, learner scene 변경, human-review 또는 rights-hold 승격은 범위 밖이다. T94를 마친 후 T77을 자동 실행하지 않는다.
