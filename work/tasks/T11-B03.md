# T11-B03 작업 명세 — 근군·눈곧은근 용어 세 번째 배치

작성일: 2026-09-25. 상태: `complete_with_gaps`. 아래 범위와 작업 결과가 일치하는지 확인하는 명세이며, 본문만으로 완료를 증명하지 않는다.

## 목적과 승인된 범위

T11에서 배정한 기존 canonical ID 10개의 이름만 조사한다. 대상은 `HA-G-000011`–`HA-G-000016`, `HA-M-000007`–`HA-M-000010`이다. 새 canonical ID, anatomy claim, 부착·기능·평가 데이터는 만들지 않는다. T11-B04와 T12는 시작하지 않는다.

## 이름 및 근거 규칙

- 학습 표시 이름은 출처에서 직접 확인한 한글 이름만 쓴다. 우리말, 실제 출처의 한자, 영어 및 라틴어는 동일한 기존 ID의 별도 검색 필드로 둔다.
- 필드별 증거는 URL, 정확한 판본 또는 판본 미노출, locator, 조회일, 접근방식을 명시한다. 값이 비어도 왜 비었는지와 확인한 근접 출처를 남긴다.
- 검색 결과/색인, 열린 페이지, 원문 대조, 사람 해부학 검토를 구분한다. 웹에서 용어를 확인한 사실을 해부학 검토로 승격하지 않는다.
- 일반 볼기근 및 발의 고유근 등 범위가 좁거나 넓은 용어를 근군 ID에 합치지 않는다. 한자 조합을 새로 만들지 않는다.
- 학습 화면에 내부 ID, task 번호, JSON, 제작 도구 정보를 추가하지 않는다.

## 허용 경로와 산출물

- 데이터: `atlas-data/terminology/learning-names.json`, `atlas-data/terminology/term-review-batches.json`
- 검색 회귀: `atlas-web/src/domain/search.test.ts`만 수정. 학습/검토 UI는 수정하지 않는다.
- 기록·검증: `work/tasks/`, `work/reports/`, `work/review-queue/`, `work/evidence/T11/B03/`, `work/STATUS.md`
- `OpenSim_Models/`는 읽기 전용이며 이 작업에서 열거나 변환하지 않는다.

## 완료 기준

1. 지정된 10개 ID만 `web_checked_with_gaps`로 갱신하고 필드 5종(label, korean, hanja, english, aliases[0])에 값 또는 사유 있는 결측과 필드별 source provenance를 기록한다.
2. 기존 ID를 유지하고, 확인된 값만 learner display/search overlay에 연결한다. 사람 해부학 검토는 `not_performed`, `humanReviewed=false`로 둔다.
3. B03 영어/라틴어·확인된 한글/한자 검색 회귀, coverage/provenance 검사, 기존 learning data 검증을 실행해 증거를 저장한다.
4. 작업 전 파일 해시, 프로젝트 변경, OpenSim revision/clean 상태를 대조해 pre-existing 사용자 파일이 보존되었음을 기록한다.
5. 미확인·충돌, T11 전체 미완, 다음 ID와 붙여 넣을 프롬프트를 기록하고 중단한다.
