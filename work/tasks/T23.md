이 파일은 **미실행 명세**다. 설계 존재를 완료로 세지 않는다. 실제 선행 파일과 검증을 먼저 확인한다. OpenSim_Models 및 기존 사용자 변경을 보존하고 해당 범위만 수정한다. 출처 조사에서 검색 색인·원문 열람·사람 검토를 구분한다. 미확보 자료는 항목별 이유와 다음 행동을 남기며 독립 작업은 계속한다.

작업이 한 번에 크면 시작 전에 suffix별 명세와 순서를 STATUS에 적고 그중 하나만 실행한다. 종료 시 work/reports/T23.md와 work/evidence/T23/에 명령·exit code·실제 결과·미실행·한계를 기록한다. UI 변경은 실제 브라우저, 데이터 변경은 schema/ref/provenance/stale/coverage를 검사한다. 학습 화면에 task 번호·JSON·개발 ID를 노출하지 않는다. 자동 배포하지 않는다.
