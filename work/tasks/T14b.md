> R13 변경(2026-09-26): 아래 사람 검토 절차는 선택적인 별도 검토 경로로 보존한다. 기본 문헌 데이터는 07의 AI 원문 대조로 학습에 사용할 수 있다. T14b의 실제 의견이 없다는 상태를 바꾸지 않되, T15나 다른 독립 개발을 중단시키지 않는다. 모든 내용을 사용자가 수기 확인할 필요는 없다.

## 합격 기준

1. 여섯 개 기존 muscle ID와 gastrocnemius 두 근두를 분리해 검토 대상으로 명시한다.
2. 각 항목에 역사적 Gray 번역 요약과 현대 원문의 범위/제한, exact source locator를 분리한다.
3. 웹 색인, 실제 열린 원문/초록, 사람 해부학 검토 상태를 각각 구분한다.
4. reviewer가 이름·기시·정지·좌우·모형 identity/범위별로 accept/revise/hold 의견과 이유를 기록할 수 있다.
5. 사람 입력 전 상태는 pending이며 humanReviewed=false를 보존한다. 자동 승격은 금지한다.
6. 진행 현황과 Astra가 답해야 할 설계 질문을 별도 파일에 남긴다.

## 중단·미완 조건

자격을 갖춘 사람 해부학 검토자와 실제 검토 의견은 아직 입력되지 않았다. 검토 패킷 준비와 source recheck는 가능하지만 T14b 사람 검토 gate를 완료 처리할 수는 없다. 이 조건이 유지되면 needs_human_review로 멈추고 T15를 시작하지 않는다. 새 좌표/표면 추정, 진단·치료·침 시뮬레이션, 자동 배포는 범위 밖이다.
