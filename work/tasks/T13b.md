## 목적과 수정 범위

`/review`의 미검토 annotation 초안을 T03 canonical `SpatialAnnotation`과 구별되는 versioned draft spatial layer로 저장·가져오기·검증한다. 검증된 미검토 surface만 learner `/`에서 읽기 전용 overlay로 그리며, learner 화면은 편집·승인 기능을 제공하지 않는다. T13 context-only manifest는 마이그레이션 기준 자료로 보존하고 그대로 읽는다.

수정 가능 경로: 별도 draft spatial schema/validator와 test-only fixtures, `atlas-web`의 draft 저장·import/export·상태 표시·learner overlay 경로, 관련 package script/test, `work/tasks/T13b.md`, `work/reports/T13b.md`, `work/evidence/T13b/**`, `work/STATUS.md`, 현재 단계의 `00-START-HERE.md` 인계.

기존 T09 storage key와 원문 bytes는 보존한다. migration은 새 versioned key로 복사하는 방식만 허용한다. 기존 catalog, context manifest, 실제 geometry, GLB/OBJ 및 OpenSim_Models는 수정하지 않는다. 테스트 도형은 fixture 또는 격리된 browser storage에서만 쓴다.

## 산출물

- 별도 spatial draft layer 계약과 실행 검증기: pending/context_only/draft_surface/reviewed/stale를 구분하며, source attachment/claim/hash, canonical instance, mesh asset/revision/hash/topology, side, frame/units/pose 및 geometry를 교차 검증한다.
- 기존 context-only manifest에 대한 읽기/상태 변환 경로와, 실제 review draft의 비파괴 import/export·storage migration 경로.
- 학습용 읽기 전용 overlay. draft surface는 미검토 상태를 계속 드러내고 stale/context-only/pending은 정확한 위치인 것처럼 그리지 않는다. reviewed 상태는 유효한 human review 증거 없이는 생성·수입·승격할 수 없다.
- 합성 point/polyline/surface fixture, 양성·음성 검증 결과, browser save→restart→read 및 learner overlay 상호작용 증거.
- baseline/after preservation, 실행 명령·결과, 한계와 미완 항목, STATUS/시작 안내의 `T13c-B01` 인계.

## 합격 기준

1. 작성 명세를 구현 전에 기록하고 별도 버전의 draft spatial schema 및 validator가 source/attachment/claim hash, instance/mesh 참조, 좌우, frame/단위/pose, asset revision/hash와 topology hash를 검사한다.
2. 고아 source/instance/mesh, claim hash·좌우·frame·단위·pose·asset hash 불일치는 저장/import/render 전에 거부한다. 같은 asset revision에서 topology hash만 바뀐 기존 초안은 stale로 격리하고 렌더하지 않는다.
3. pending, context_only, draft_surface, reviewed, stale 상태를 명시적으로 구분한다. reviewed 입력은 검증 가능한 human review record와 대상 hash가 없으면 거부한다. 자동 승인 경로는 없다.
4. 기존 T09 localStorage 원본 key/value를 쓰거나 지우지 않고 보존한다. 새 layer는 별도 key에 비파괴 복사·저장하고, JSON import 실패 시 현재 저장값을 유지한다.
5. test-only 합성 표면 fixture만 geometry 양성 사례로 사용한다. 해당 fixture는 production catalog/manifest/학습자료에 포함하지 않는다.
6. 별도 저장 후 페이지 재시작/새로고침에서도 draft layer를 읽고 learner `/`에 읽기 전용 미검토 overlay로 표시한다. `/review`만 편집할 수 있다.
7. 실제 브라우저에서 잘못된 참조·좌우·claim/asset hash 거부, topology stale 처리, 저장→재시작→읽기 표시를 확인하고 console 오류를 기록한다.
8. 보호 파일/hash 및 OpenSim_Models revision/status 전후 보존을 확인한다. 보고서·검증 로그·미완 항목·STATUS와 다음 `T13c-B01` 붙여넣기 프롬프트를 프로젝트 안에 남기고 이 task에서 중단한다.

실제 근육 부착 좌표 추정/입력, draft를 reviewed로 승격, T13c/T14, canonical `SpatialAnnotation` 생성, GLB/OBJ/OpenSim 수정, 공개/자동 배포, 환자 진단·치료·침 시뮬레이션은 수행하지 않는다. 근거 또는 browser storage 상태가 불명확하면 데이터를 바꾸지 않고 pending/held로 기록한다.
