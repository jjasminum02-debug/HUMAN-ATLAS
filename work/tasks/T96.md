# T96 — 전체 목표 분류·반복근·뼈 분모 의미 검증

T78 사용자 요청 개정 · Luna Max · planned_not_started

## 선행과 읽기

T78 실제 산출물. 21 설계와 T78 execution-queue.json이 충돌하는 이전 프롬프트보다 우선한다. 순서와 실제 gate를 구분한다.

## 정확한 범위·합격 기준

T78 reference/ta2-scope.json의 2422행, classification-ledger.json, targets.json 556 후보를 재검토해 근육/갈래/군/serial family/변이/뼈/랜드마크를 구분한다. 이 task는 기존 nomenclature의 의미·포함 규칙 감사이며 새 556개 콘텐츠 입력이 아니다. 정규식 후보를 확정 canonical 목록처럼 쓰지 않는다. 제외된 supporting rows에서 실제 근육 누락, 예: 별칭·근군 아래 근육을 역검사한다. TA2 각 part/group/member 및 variant/sex-specific, 좌우/중선/손발반복근 cardinality를 별도 필드로 확인하고 확정할 수 없는 수는 null로 보존한다. 전체 개별근 수를 억지로 만들지 말되 named-target concept 집합은 버전·포함 근거·누락 없이 동결한다. runtime 학습 catalog와 실제 데이터의 exact IDs를 대조하여 기존 content 상태도 필드별 연결한다. T110–T165의 고정 ID batch를 재검증한다. 추가 target은 새 정수 task(최대10개), 제거/분할/병합은 전후 대응 및 해부학적 근거를 남겨 T80 전에 배정한다. 사용자가 기본 목록을 작성하도록 넘기지 않는다. 허위 누락/전체 완료 주장을 해소하는 분모 validation이 합격 조건이며 UI/geometry 변경 없음.

대상: 위에 명시한 단일 UI 기능/분류 감사.

## 소유 경로·산출물

work/reports/T96.md, work/evidence/T96/, 지정 subset에 필요한 도구·overlay·manifest·앱 코드만. source cache는 ignore 경로에 두며 원본 변경 금지. 새로운 기능/다른 target은 이번 범위 아님. STATUS/registry는 소유 delta만. 검증 실패를 문서로 대체하지 않는다.
