# T07 — 부위별 3D 변환 파이프라인

## 목적

T02에서 실제 취득·검증된 BodyParts3D Release 4.0 오른쪽 종아리 OBJ 11개만, 원본을 보존하며 결정적으로 GLB 2.0으로 변환한다. 모델/mesh stable ID와 T04/T05의 canonical 대상 관계, source ID, 원본 및 derived hash, 단위·좌표계 변환과 attribution을 추적 가능한 manifest로 남긴다.

## 산출물

- 표준 라이브러리만 사용하는 OBJ→GLB 변환기와 결정적 mesh/node ID 규칙; vertex normals는 단위 scale 없이 같은 RH 회전으로 변환한다.
- 오른쪽 종아리 GLB에 독립 mesh node로 들어간 T02 원본 11개.
- T02 source crosswalk와 T04/T05 stable ID를 연결하는 provisional crosswalk 및 T03 MeshAsset 필드에 맞춘 derived manifest.
- 실제 값 기준 축·단위·우측성·mesh 수/인덱스·hash·attribution·원본 보존 검사와 독립 2회 변환 재현성 결과.

## 합격 기준

1. T02 manifest가 허용한 정확한 11개 원본만 변환되고 원본 파일 SHA-256 및 크기가 전후 동일하다.
2. GLB 헤더·chunk·accessor·mesh/node 연결이 glTF 2.0 형식 규약에 맞고 모든 파일의 geometry/normals가 원본 OBJ vertices/normals/faces에 결정적 변환을 적용한 값이다.
3. T02의 행 locator/FJ/BP/FMA와 안정 mesh ID, canonical target 관계가 추적된다. 매핑은 `needs_review`; 신규 anatomy claim, reviewed, annotation은 없다. T04/T05 catalog에 없는 talus canonical ID는 null/unresolved로 남는다.
4. Atlas 단위 m, RH, +X patient-left, +Y head, +Z anterior에 맞는 source mm→Atlas m 변환, determinant +1, 원본 우측성, 측정 경계 일치가 검사된다.
5. 서로 독립된 두 출력 경로의 GLB가 byte-identical이며, GLB 해석 후 mesh별 semantic geometry hash/ID도 일치한다.
6. T03 validator로 MeshAsset records를 검사하고, 별도 T07 crosswalk 검증은 canonical ID·원본 source crosswalk·laterality를 확인한다. 검증의 한계와 미해결 항목을 보고서/STATUS에 남긴다.
