## 허용 범위와 산출물
- 학습 이름 overlay의 기존 13개 레코드를 보존하면서 B01에서 실제 확인된 용어/영어 별칭/한자 및 출처 연결만 보완한다.
- atlas-data/terminology/term-review-batches.json에 85개 canonical coverage, 배치 순서, 필드별 출처·판본/판본 결측·locator·조회일·웹 확인 방식, 사람 검토 상태를 저장한다.
- work/review-queue/terminology-gaps.md에 B01의 미확보/충돌 및 B02–B09 대기 항목을 기록한다.
- 이 작업은 canonical 근육 엔터티나 OpenSim 자료를 고치지 않는다. UI/제작 화면 표시는 변경하지 않지만, 확인된 용어 overlay 근육 부분이 학습 검색 projection에서 빠져 있으면 해당 이름을 검색 가능하게 하는 최소 domain 수정은 허용한다.

## 합격 기준
- 정확히 85개 기존 canonical 항목을 모두 한 번씩 B01–B09에 배정하고 각 배치 10개 이하.
- B01은 8 canonical + 2 기존 lookup 기록; lookup은 canonical과 거짓 조인하지 않는다.
- 기본 표시명은 한글 관용명으로 유지하고, 우리말/실제 출처의 한자/영어 별칭은 동일 ID 또는 명시된 lookup 후보에 연결한다.
- 필드별 결측/충돌/검색색인 전용 근거를 분리한다. 자료를 찾았다는 이유로 해부학 사람 검토를 완료 처리하지 않는다.
- 14개 기존 검색 회귀를 실행하고 검증 및 보존 비교를 저장한다.
- 학습 화면에 내부 task/JSON/제작도구 정보를 추가하지 않는다.
