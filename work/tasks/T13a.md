## 합격 기준

1. 1440×900에서 관심 근육이 중앙 주대상으로 보이고, 보이는 canvas 높이의 대략 60–85%를 사용한다. 좁은 구조를 인위적으로 늘리지 않는다.
2. 화면에 보이는 한국어 기시·정지 요약이 영문 상세보다 먼저 보이며, 기본 상태에서 긴 영문 원문이 접혀 있다.
3. 부착을 선택해 강조한 뒤 보기 초기화를 누르면 카메라/표시 복원과 함께 부착 선택/강조가 해제된다. 근육 변경과 뒤로가기 상태도 서로 모순되지 않는다.
4. 1280×720 및 390×844에서 모델, 카드, 버튼이 겹치거나 수평 넘침이 없다.
5. 관련 typecheck/build 및 search/annotation 회귀와 실제 브라우저 확인을 수행하고 결과를 파일로 남긴다.
6. 기존 실제 데이터, GLB, 사용자 초안 및 `OpenSim_Models`는 변경하지 않는다. 임의 부착좌표를 만들지 않고 T13 전체/T14를 완료 처리하지 않는다.

## 수행 결과

- 학습 카메라는 전체 20개 메시 대신 선택 근육 메시 bounds에 맞추고 `focus(..., 1.4)`로 프레이밍한다. 부착 문맥을 고르면 관련 뼈와 근육을 함께 강조하되 카메라 표적은 근육에 둔다. 전체 보기 동작은 별도 버튼으로 유지하고, 보기 초기화 뒤에는 선택 근육 프레임으로 돌아온다.
- 기시·정지 한국어 요약을 구조 탭 맨 앞에 함께 배치했다. 부착별 관련 뼈 선택과 영문 설명/판본은 접힌 disclosure로 옮겼다.
- 보기 초기화가 부모의 부착 선택을 지우고, 관련 뼈 강조 안내와 선택 상태도 해제한다. 근육 전환과 브라우저 뒤로가기는 선택을 초기화한다.
- 모바일 근육 목록 카드 높이를 조정해 390px 화면에서 파일럿 6개 이름이 잘리지 않게 했다.
- 데이터, GLB, 자산, spatial annotation, 사용자 초안 및 OpenSim_Models에는 쓰기 변경을 하지 않았다. 부착 좌표를 만들지 않았다.

## 검증 결과

- 실제 브라우저 `/`: 1440×900에서 기시·정지 요약이 모두 첫 화면에 보이고, 선택 근육이 canvas 높이의 약 60–85%를 차지하는지 시각 확인. 1280×720 및 390×844에서 가로 넘침·주요 패널 겹침 없음.
- 실제 브라우저에서 부착 선택→보기 초기화, 부착 선택→가자미근 전환→뒤로가기 수행. 초기화/전환/뒤로가기 뒤 선택 부착 0개와 context 안내 미표시 확인.
- 장문 영문 설명은 기본 화면의 `innerText`에 나오지 않고 source detail disclosure는 닫힘 상태였다.
- `pnpm typecheck`, `pnpm test:search` 38/38, `pnpm test:annotations` 12/12 + exchange schema, `pnpm build` 통과. build는 현재 App 번들 500 kB 경고를 출력했다.
