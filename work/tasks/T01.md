## 필요한 검증

- 명령/브라우저 시나리오: JSON 파싱, 전신 부위 집합 검사, 제외 규칙·집계 규칙 검사, source/gap 상태 검사, `git diff --check`, 기존 파일 hash 비교, OpenSim HEAD·working tree 비교.
- 실패해야 하는 사례: 필수 부위 누락, 심근/평활근을 기본 대상에 포함, 좌우/근두/근군/액추에이터를 개념 수로 중복 집계, 미확보 파일을 확보 완료로 표시, 출처 이용 조건/귀속 미기록, 원본이나 기존 파일 변경.
- 출처/사람 검토 필요 여부: 출처 페이지에서 보이는 edition/license metadata는 기록 가능. 실제 용어 선정, 해부학 주장, 위치/메시, 검사 내용의 해부학적·교육학적 사람 검토는 T01에서 하지 않음.
- 미실행 시 보고할 내용: 전체 목록/항목 locator 추출, BodyParts3D 파일 내용 검사, OpenSim 모델 대응, clinical assessment protocol 검토, 화면/브라우저 검증.

## 차단 시 독립 작업

출처 페이지와 판본 정보를 확인할 수 없으면 후보 상태와 미확보 내용을 기록하고, 범위 및 집계 규칙만 고정한다. 근거가 부족한 한글·한자명, 해부학 주장, 자산 권리, 검사 절차를 만들어 채우지 않는다.
