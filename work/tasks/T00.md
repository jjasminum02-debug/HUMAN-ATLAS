# T00 — 실행 기반 만들기

## 목적과 범위

- 한 문장 결과: HUMAN ATLAS의 작업 경로·지침·task 기록 구조와 원본 보호 규칙을 준비한다.
- 선행 task와 실제 통과 증거: 없음.
- 읽을 파일: `design/2026-09-25-muscle-atlas/00-START-HERE.md`, `01-PRODUCT-AND-ARCHITECTURE.md`, `02-DATA-CONTRACT.md`, `03-LUNA-SERIAL-RUNBOOK.md`, `04-SOURCES-AND-DECISIONS.md`, 세 템플릿, 기존 루트 README, OpenSim 저장소 상태.
- 수정 허용 경로: `AGENTS.md`, `.gitignore`, `work/**`, HUMAN ATLAS의 새 최상위 Git 메타데이터.
- 수정 금지 경로: `OpenSim_Models/**`, 기존 `README.md`, `design/**`, 템플릿 원본, 기존 `.DS_Store`.
- 이 task에 포함하지 않는 것: 웹앱 구현, OpenSim 설치, 해부학 학습 데이터 입력, 데이터/좌표 변환, 외부 자산 다운로드, 배포, 환자 진단·치료·침 시뮬레이션.

## 산출물과 완료 기준

| 산출물 | 합격 조건 | 확인 방법 |
|---|---|---|
| `AGENTS.md`, `.gitignore` | task 운영 규칙이 원본 읽기 전용·설계 미구현·범위 밖 항목을 명시하고, 상위 Git에서 `OpenSim_Models/`와 비공개 원자료를 추적하지 않음 | 내용 확인, `git check-ignore`, `git ls-files` |
| `work/STATUS.md`, `DECISIONS.md`, `BLOCKERS.md` | 실제 경로, 상태표, NEXT_TASK=T01, 미확정 자료 공백을 기록 | 파일 확인 |
| `work/tasks/T00.md`, `work/reports/T00.md` | 템플릿 기반 작업 명세와 완료/검증 보고가 각각 존재 | 파일 확인 |
| 원본 보존 | OpenSim checkout revision과 working tree가 시작 시점과 같음 | 시작/종료 Git 상태 및 revision 비교 |
| 기존 자료 보존 | 루트 README, 설계 문서, 템플릿 해시가 작업 전과 같음 | 시작/종료 SHA-256 목록 비교 |
| 앱 범위 | 기존 Atlas 앱 부재를 기록하고 T00에서 앱/데이터 구현을 하지 않음 | 파일 검색 및 변경 파일 검토 |

## 필요한 검증

- 명령/브라우저 시나리오: 원본 Git 상태, 프로젝트 앱 파일 존재, OpenSim ignore/미추적 여부, 기존 자료 해시, 새 Git 체크포인트를 확인한다. UI 변경이 없으므로 브라우저 검증은 없다.
- 실패해야 하는 사례: 상위 Git에서 OpenSim 원본이 추적되거나, 기존 README/design/template 해시가 바뀌면 T00 실패.
- 출처/사람 검토 필요 여부: 해부학 내용 변경이 없어 해당 없음.
- 미실행 시 보고할 내용: OpenSim 데스크톱 응용프로그램의 전체 설치 위치 조사 및 향후 앱 실행 검증은 하지 않음.
- 완료 전 상태표의 T00을 완료, T01을 다음 task로 기록하고 task 전용 파일만 체크포인트에 포함한다.
