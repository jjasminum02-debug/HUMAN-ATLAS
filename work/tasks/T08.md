# T08 — 3D 선택·격리·카메라

## 목적과 범위

T06 로컬 탐색 앱에 T07의 고정 오른쪽 종아리 GLB와 manifest를 연결한다. manifest와 GLB의 안정 mesh ID를 함께 확인하며 mesh↔pilot card/list 선택, 선택 구조 초점, 전체/주변 보기, 개별 숨김·투명화·복원, 선택 항목 격리, 정면·후면·우측 측면 preset을 구현한다.

선행 자료: 설계 `00`–`04`, T06/T07 명세·보고서, T07 GLB 및 `atlas-data/manifests/derived-assets-t07.json`, T06 app와 기존 카탈로그. 구현 전 상태에서 Git HEAD는 T07 checkpoint이며 기존 untracked `README.md`와 `design/`은 보존한다. `OpenSim_Models/`는 read-only 원본이다.

## 작업 범위와 경계

- 앱 파일: `atlas-web/**`
- 작업 기록: `work/tasks/T08.md`, `work/reports/T08.md`, `work/evidence/T08/**`, `work/DECISIONS.md`, `work/STATUS.md`
- manifest에 선언된 T07 GLB와 11개 mesh만 읽는다. T07 mesh crosswalk 상태는 provisional/needs_review 그대로 보인다.
- 전체 gastrocnemius concept 선택은 manifest의 두 head part를 대응 대상으로 사용하고, head 선택은 동일 stable part ID를 선택한다.
- bone/talus mesh 선택은 mesh 상태만 바꾸며 없는 muscle concept/card를 만들거나 추정하지 않는다.
- 임의 포즈 변형, attachment annotation, claim 변경, anatomy `reviewed` 승격, T05/OBJ/OpenSim 변경, 공개·배포는 하지 않는다.

## 완료 기준

1. `pnpm typecheck`와 `pnpm build` 성공. Manifest model/mesh ID, GLB hash, byte count, mesh/node 수의 browser-side 확인.
2. GLB 직접 선택이 매핑된 muscle/part card 및 URL을 동기화하고 목록/part 선택은 대응 mesh를 강조·초점화한다. 빠른 선택 전환에도 최종 카드와 mesh가 같은 stable ID를 가리킨다.
3. mesh별 hide/transparent/show, isolate/restore all 및 hidden/transparent surface를 통한 선택 차단/통과를 확인한다.
4. front/back/right-lateral preset, 전체 보기, 주변 보기, 선택 구조 확대를 실제 브라우저에서 조작한다.
5. 실제 화면과 콘솔·동작 결과를 `work/evidence/T08/`에 보존한다. source geometry와 기존 파일·OpenSim revision을 전후 대조한다.
6. STATUS에서 T08 결과와 검토 제한을 기록하고 NEXT_TASK=T09로 표시한다. T09는 시작하지 않는다.

## 기술 제약

T06에는 Three.js dependency가 없고 현재 local pnpm metadata/store에도 Three.js 패키지가 없다. T08은 네트워크 다운로드 없이 진행한다. 선택한 로컬 구현은 T07이 현재 내보내는 단순 GLB triangle geometry에 범위를 제한하며, GLB/manifest identity·hash·node 계약이 바뀌면 명시적으로 실패해야 한다. 이 선택은 일반 목적 glTF renderer 또는 Three.js 호환 API가 아니다.
