# T13c-B01 — 비복근 외측두 대퇴골 기시 검토

## 목적과 제한

대상은 우측 비복근 외측두의 대퇴골 기시 한 항목뿐이다. 독립된 현대 근거가 설명하는 표면을 현재 femur mesh에서 재현 가능한 해부학 경계와 연결할 수 있을 때만 별도 draft layer에 미검토 후보를 기록한다. 문헌의 위치 설명만으로 삼각형 ID나 좌표를 만들어내지 않는다. 근거와 메시를 일치시키는 재현 가능한 경계가 부족하면 `geometry: null`, 보류 사유를 가진 `context_only` 또는 `pending` 상태를 기록한다.

T03 canonical `SpatialAnnotation`, catalog, T12/T13 manifest, 실제 GLB/OBJ, OpenSim_Models 및 기존 브라우저 저장 초안은 수정하지 않는다. `reviewed` 상태나 사람 검토 기록을 만들지 않는다. 인접한 별도 부착 claim, 다른 T13c batch, T14는 범위 밖이다.

## 산출물

- 정확한 판본/발행 정보, locator, URL, 조회일, 접근 방식이 있는 독립 현대 근거 기록
- 대상 한 건만 포함하는 schema/runtime 통과 spatial draft record. 근거로 표면 경계를 재현할 수 없으면 geometry를 비우고 사유를 기록
- 정면·후면·우측 측면·자유 회전 femur mesh 브라우저 검토 기록; 각 방향에서 보이는 것과 mesh만으로 알 수 없는 것을 구분
- source claim hash, 우측 instance, laterality, frame, unit, pose, asset revision/hash, topology, 상태의 검증 결과
- learner의 읽기 전용 overlay에서 후보가 있으면 표시, geometry-null/context-only이면 표면이 그려지지 않음을 확인한 브라우저 기록
- 실행 명세·검증·보존 결과·미완 항목·현재 상태와 다음 작업 프롬프트

## 합격 기준

1. task spec을 구현 전 기록하고, 범위를 지정한 attachment ID 한 건으로 제한한다.
2. Gray 원문과 독립된 현대 해부학 출처를 원문 페이지에서 확인해 판본, 구체 locator, URL 및 조회 방식을 남긴다. 검색 snippet만으로 출처를 확인 완료 처리하지 않는다.
3. 해당 femur mesh를 정면·후면·우측 측면·회전 보기로 실제 브라우저에서 관찰한다. 화면만으로 부착 면적을 추정하지 않는다.
4. 저장하는 draft의 claim/source/instance/side/frame/unit/pose/asset revision/hash/topology 참조를 현재 manifest·catalog와 대조해 validator에 통과시킨다. 넓은 뼈 전체를 부착 영역으로 표시하지 않는다.
5. 재현 가능한 표면 경계가 입증되지 않으면 geometry는 `null`; 상태는 승인/검토 완료가 아닌 보류 상태이며, 근거 부족 이유를 기록한다. learner overlay에서 면이 나타나지 않는 것을 확인한다.
6. 기존 T09 및 T13b localStorage 값, 보호된 catalog·GLB/OBJ·manifest, OpenSim_Models의 HEAD/status/hash를 전후 비교해 보존한다.
7. 관련 자동 검증과 실제 브라우저 검증을 evidence로 남기며, `reviewed` 승격·T13 전체/T14 완료 표시는 없다.
8. 보고서·review queue·STATUS에 불확실성, 미완 항목, 다음 T13c 작업 ID와 붙여넣기 프롬프트를 남긴 뒤 중단한다.

## 중단 조건

원문 외 독립 근거를 열어 확인할 수 없거나, 현재 mesh와 문헌의 표면 경계를 재현할 방법이 없으면 surface geometry를 생성하지 않는다. 저장소에 있던 사용자 초안이 예상과 다르거나 충돌하면 값을 보존하고 충돌을 기록한다. 해부학 검토를 자동 승인하거나 추측 좌표로 기술 기준을 채우지 않는다.
