## 이번 실행의 구체 범위

- 기존 T03 `Review`/`reviewState`를 수정하지 않는 별도 field-level AI evidence overlay 계약을 추가한다.
- overlay는 원문 단위 `source/work/locator/access` provenance, 값 hash, claim/evidence 참조, geometry/motion 상태를 표현한다. 사람 승인 필드를 AI overlay에 복제하지 않는다.
- 검증기는 canonical ID, source/evidence/claim/legacy claim hash 참조를 확인하고 `cross_checked`에는 서로 다른 underlying work 두 개 이상을 요구한다. 서로 다른 웹 URL이 같은 원문을 재인용하면 단일 원문으로 계산한다.
- learner adapter는 내부 상태 코드를 제거한 한국어 표시 projection과 quiz eligibility를 산출한다. 현재 legacy 요약은 원문 및 review/hash를 보존하고, fixture migration만 수행한다. 새 실제 해부학 claim은 입력하지 않는다.
- production overlay는 빈 상태로 두고 denominator/coverage를 미동결(null)로 유지한다. 합성 fixture는 `work/evidence/T16/fixtures/` 테스트 전용이다.

## 실행 중 검증 기준

- 같은 원문을 재인용한 서로 다른 두 사이트는 교차 확인으로 인정되지 않고, 독립 원문 2개만 `cross_checked`를 통과한다.
- 상충 값은 한 가지 정답으로 투영되지 않으며 퀴즈에서 제외된다. `single_source`/`unavailable`/`unresearched` 표시는 각각 정책에 따른다.
- geometry/motion enum은 evidence 상태와 독립적으로 조합 가능하다.
- legacy migration은 기존 canonical claim, review, 사용자 초안, T13 geometry-null draft를 수정하지 않고 summary/claim/source hash와 기존 review 상태를 보존한다.
- learner projection에는 schema/task/debug JSON 및 내부 evidence 상태 코드가 포함되지 않는다.
- OpenSim_Models 및 T15g denominator (`false`/`null`)은 그대로 유지한다.
