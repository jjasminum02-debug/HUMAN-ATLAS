# T15a — 명칭 요구 교정과 실제 한자 필수조건 해제

상태: todo. R12 개정2026-09-26. 담당: **Luna Max**.
선행: 이번 R12 개정.

## 작업

기존 이름 overlay를 분석하여 koTraditional/koModern/en projection을 구현한다. 기본명은 한자어의 한글 표기. 실제 한자 UI·입력·필수검증·누락경고를 제거하고 legacy 기록은 보존한다. 검색 UI를 근육·뼈 명칭을 받을 수 있는 표현으로 준비하되 뼈 검색 구현 완료로 세지 않는다.

## 수정범위·산출물

atlas-web/src/data, domain, ui; terminology projection·validator·관련 테스트; work. 구현 코드·데이터와 실제 검증 기록을 남긴다.

## 합격 기준

어깨세모근/삼각근/deltoid(+사용자 편의 alias deltoids) 동일ID. 없는 한국어 표기를 추정하지 않음. 실제 한자가 전부 null이어도 제품명칭 gate 통과 가능. 기존 alias와 source hash 보존. 브라우저에서 실제 한자/표기대조중 행이 사라지고 두 한국어 이름+영어 확인.

## 공통 경계·검증·Git

이 파일은 todo 명세이며 구현 완료 기록이 아니다. 설계 00/01/02/03/06, AGENTS.md, STATUS.md, 직전 보고서와 실제 파일을 읽는다. OpenSim_Models·원본 자산·기존 사용자 변경·초안을 보존한다. 실제 한자 문자는 필수 입력이나 완료 조건이 아니다. T14b의 사람 검토는 대기로 유지한다. 경혈·Pro mode·치료는 설계하거나 구현하지 않는다.

관련 도메인 검사와 타입 검사·빌드를 수행한다. UI 변경은 실제 브라우저에서 확인하고, 데이터 변경은 참조·좌우·해시·대상 범위를 검증한다. 문서나 합성 테스트만으로 실제 해부학 자료의 완료를 주장하지 않는다.

시작할 때 Git 상태와 HEAD, 기존 변경의 기준선을 기록한다. 종료 시 work/reports/T15a.md, work/evidence/T15a/, STATUS.md에 결과를 남긴다. 검증한 task 소유 변경만 선별하여 로컬 커밋한다. 같은 파일의 기존 변경과 분리할 수 없다면 임의로 포함하지 말고 이유와 남은 변경을 보고한다. git add .·reset·rebase·자동 push·배포는 금지한다. 커밋 해시, 포함 범위, 미완 상태, 다음 task ID와 붙여 넣을 프롬프트를 보고하고 멈춘다.
