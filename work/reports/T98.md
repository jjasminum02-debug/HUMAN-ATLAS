**결과: `partial` — 12부위 target 분모와 Z-Anatomy 직렬화 datablock inventory, 12개 exporter 후보는 고정했다. 평가된 Blender surface를 추출·미리보기하는 경로가 검증되지 않아 production base는 선택하지 않았다.** 같은 T98의 exporter/preview unit부터 재개해야 한다.

## 범위와 기준선

- 시작 HEAD: `703655a31e74bd509dc2d0992b43f7d99c867520`. 시작 porcelain 209 paths, staged 0; status bytes SHA-256은 [baseline](../evidence/T98/start-baseline.json)에 기록했다.

## Z-Anatomy 직렬화 inventory와 12개 시험 후보

T97의 pinned `Z-Anatomy.zip` (SHA-256 `e029688545627bd0214b269e1063143abb580aad72b2c2445d6d8a9a0d9da736`)을 재사용했고 다시 다운로드하지 않았다. 7 archive entries 가운데 6 files이며, 평가 대상 `.blend`는 `Startup.blend` 1개 (306,838,281 bytes; SHA-256 `9f08a17ea0115fed80b2a73ecdf0a1bc2ab2f6956f37c593ce23d513ea35afcd`)다. 별도 OBJ/FBX evaluated exporter member는 없다.

T97의 read-only BHead/SDNA reader를 새 T98 도구에서 확장해 모든 7,184 Object, 2,910 Mesh datablock, 1,898 Curve datablock, 1,945 Collection, 1 Scene 및 각 Object의 원본 ID name/pointer, parent, collection paths, data pointer, 직렬화 transform/flags, modifier/constraint/animation pointer를 기록했다. T97의 다른 datablock counts에는 Text 3,839, Material 188, NodeTree 42 등도 포함된다. Object type enum 원자료는 4,569 Mesh, 951 Curve, 1,660 Font 및 기타 4개다. 1,659 Mesh datablock은 복수 Object가 공유하고 3,318 Object reference가 여기에 속한다. 복수 Object가 참조하는 Curve datablock은 713개다. 직렬화 modifier 보유 Object는 2,701개 (Boolean 3, Decimate 1, Hook 1,076, Mirror 38, Nodes 6, Skin 18, Solidify 1,082, Subsurf 475, Wireframe 2), constraint 보유 Object는 3개다. `dup_group` collection-instance pointer는 0개지만 Geometry Nodes modifier 6개가 있으므로 evaluated dependency-graph instance 수는 미확인이다. armature datablock은 0, animation-data pointer는 1,025 Object에 있으나 이것만으로 유효한 rig·deformation을 뜻하지 않는다.

정확히 12개의 hash-bound exporter 후보를 고정했다. 해부학 대상으로 이름을 선택한 것은 11개이고 `Cross Section X`는 constraint helper 검사 전용이다. 후보들은 frontalis 1개, 양측 latissimus, 양측 clavicular deltoid part, tibialis anterior 1개, 양측 scapula, L5, sacrum 및 modifier 보유 `.ol` suffix deltoid Object를 포함한다. 표본에는 공유 Mesh pointer와 negative serialized matrix determinant, modifier, constraint 사례가 포함된다. archive 전체의 `dup_group` instance는 0이다. source `.l/.r` 문자열과 determinant는 직렬화 상태일 뿐 좌우 해부학/미러의 검증 결과가 아니다. exact locators 및 export 미완 상태는 [12개 표본 동결](../evidence/T98/representative-sample-freeze.json), 전체 Object pointer/hash는 [raw inventory](../evidence/T98/blender-raw-object-inventory.json)에 있다.

이 inventory는 canonical concept 7,184개, evaluated geometry 2,910개, 선택 가능한 instance 7,184개 또는 region coverage를 뜻하지 않는다. 모든 object가 실제 장면에서 표시되는지, modifier/Geometry Nodes가 만든 instance 결과, surface topology/hash, node별 hidden/inactive 상태는 평가하지 못했다. scene 단위 설정은 SDNA 원필드 `system=1`, `scale_length=1.0`, `length_unit=5`로 남겼지만 물리 단위 의미를 런타임에서 확인하지 못했다. serialized timeline은 start 0/end 100/current 0이다. source frame, rest pose, T50/T69 변환 가능성은 미확인이다.

## Exporter 시험 및 생산 base 결정

T97의 Blender 3.5.0/3.5.1/5.2.2 background 시도가 모두 139로 끝난 기록을 재사용했다. 동일 headless 실패를 반복하지 않고, 기존 공식 Blender 5.2.2 mount의 arm64 executable을 GUI 실행 경로로 한 번 열어 source file을 read-only로 시도했다. `--factory-startup --disable-autoexec`로 실행했으나 USD `Arch_ValidateAssumptions`에서 exit 134로 abort했다. source file이 성공적으로 열리거나 Python exporter가 실행되지 않았고 추가 재시도는 하지 않았다. Python에서 `bpy`, trimesh, assimp_py, open3d가 없었고 Blender/docker/podman/assimp executable도 PATH에서 찾지 못했다. 전체 결과는 [exporter attempts](../evidence/T98/exporter-attempts.json)에 저장했다.

따라서 이번 실행은 **평가된 surface preview, GLB, geometry hash가 없다.** T97의 raster preview는 저장된 raw array·object matrix 결과이며 evaluated modifier/instance 결과가 아니어서 T98의 exporter 합격으로 사용하지 않았다. 단위/frame/pose/laterality를 T50/T69 계약에 대조하고 cost를 측정하지 못했다.

Production base는 `undecided`다. Z-Anatomy는 7,184 Objects로 broad single-package candidate인 점 때문에 다음 비교의 선두 후보로 남겼지만, 430 lexical target 후보가 identity가 된 것이 아니고 평가된 surface·frame·pose·rights lineage·cost가 없다. BodyParts3D R4는 T104까지 검증된 subset 변환을 재사용할 수 있으나, 721개 기존 cache files는 542 target에 대한 전신 coverage를 의미하지 않으며 T96 source candidates도 exact mapping이 아니다. 두 source의 byte/object count를 같은 품질·완성도 지표로 비교하지 않았다.

## 출처·권리·사람 검토 상태

Z-Anatomy 고정 commit의 [README LICENSE와 MODELS attribution](https://github.com/Z-Anatomy/Models-of-human-anatomy/blob/c7010a903b75a2fd24a13b1c2c4c3546a9223780/Readme.md#license)은 Z-Anatomy 코드/콘텐츠 CC BY-SA 4.0과 BodyParts3D 원모델 출처를 말하며, Brainder/White matter, Dundee Cranial Nerves and Foramina (CC BY 4.0), Dundee Inner Ear (CC BY-NC-SA 4.0), Kidney (CC BY-NC 4.0)을 별도로 나열한다. Wikipedia CC BY-SA 3.0 attribution은 definitions에 해당하며 3D geometry 권리로 전환하지 않았다. template `__init__.py`의 GPL-3-or-later header와 README의 일반 code/content license statement도 별도 기록했다.

현재 LSDB [BodyParts3D database license page](https://dbarchive.biosciencedbc.jp/en/bodyparts3d/lic.html)는 2025-02-27 갱신 CC BY 4.0을 표기하지만, R4 OBJ header는 CC BY-SA 2.1 Japan을 유지한다. [R4 release note](https://dbarchive.biosciencedbc.jp/data/bodyparts3d/LATEST/release_4.0_e.html)는 2013-05-16, unique FJ filename과 concept relation table을 설명하며 canonical-model 사용 시 오류 가능성을 경고한다. T104가 기록한 file header/current page 차이를 그대로 보존했다.

.blend inventory에서 object→upstream source ID/예외 family 관계를 recover하지 못했고 이름만으로 예외 geometry를 확정하지 않았다. 전체 3D source는 `source-only`; T98 local-use eligibility 및 public redistribution은 승격하지 않았고 public rights는 `held`, human anatomy review는 `not_performed`다. 앱 claim, stable canonical ID, binding, learner visibility 및 사람 검토는 만들지 않았다.
