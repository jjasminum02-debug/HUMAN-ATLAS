# T104 — 근육 부분 누락 표면 4 취득·통합

**결과: `passed_with_gaps` — 정확한 10개 R4 표면의 로컬 기술 통합과 실제 브라우저 검증을 통과했다.** 공개 재배포 권리, 사람 해부학 검토, canonical learner binding은 보류 상태로 유지한다. 전신 coverage 완료를 뜻하지 않는다.

## 범위와 출처

T104가 동결한 ID `FJ1516`, `FJ1516M`, `FJ1518`, `FJ1518M`, `FJ1557`, `FJ1600`, `FJ1601`, `FJ2774`, `FJ2781`, `FJ2783`만 BodyParts3D Release 4.0 IS-A archive에서 선택 range로 취득했다. 전체 archive 다운로드는 없었다. 요청 range transfer 849,319 bytes, 압축 해제된 10개 OBJ 2,063,303 bytes였다. 각 파일의 FJ/FMA/BP header, 공식 exact/generic ELEMENT 관계, archive CRC32, SHA-256, 이름에 적힌 laterality, mm bounds, vertices/normals/triangles를 확인했다.

## 같은 장면 통합 및 중첩 조사

T103 다음에 `t104-upper-limb-muscle-parts`(4개)와 `t104-neck-muscle-parts`(6개)를 기존 `AnatomySceneRoot`, 단일 WebGL renderer, 기존 camera controller의 같은 scene에 append했다. 파생 표면은 총 21,299 vertices / 25,678 triangles / 680,808 bytes다. 두 chunk SHA-256은 source manifest와 validation evidence에 기록했다. 활성 parent scene과의 source FJ ID 충돌은 0이다.

정확히 일치하는 개별 whole-muscle parent mesh는 활성 parent scene에서 찾지 못했다. 이름의 ancestor만으로 parent geometry를 대체하지 않았다. 비교 가능한 pronator/FCU head 형제, longus colli component, cricothyroid component는 실제 OBJ 삼각형 표면의 정점·삼각형 중심·변 중점에서 양방향 최근접 표본 거리를 측정했다. AABB는 overlap 증거로 사용하지 않았다. 표본 거리는 근접도 관찰일 뿐 연속 표면 교차 증명이나 해부학적 합격이 아니다. 결과와 한계는 [surface-comparisons.json](../evidence/T104/surface-comparisons.json)에 남겼다.

## 실제 브라우저 및 성능

같은 localhost 학습 화면에서 1440×900, 1024×768, 390×844 CSS px를 실제로 설정해 렌더링과 선택을 확인했다. 팔·손에서는 정확히 4개, 목에서는 정확히 6개, 전신에서는 T104 정확한 10개가 각기 보였고 각 ID는 한 번씩만 렌더됐다. 390px에서는 접힌 부위 탐색을 열고 팔·손을 선택한 뒤 닫았으며, 근육 layer off에서 T104 mesh 4개가 사라지고 on에서 같은 4개가 복원됐다. 근접/전체 카메라 흐름에서는 canvas wheel로 확대하고 전체 보기로 기준 camera를 복원했다. 동일 scene root/renderer가 유지됐고 실제 console error/warning은 0건이다. learner 화면에는 개발 ID, JSON 또는 T104 제작 필드가 노출되지 않았다. 화면 캡처는 브라우저에서 확인했지만 repo에 PNG로 저장하지 않았다.

T22 비교를 위해 동일한 1440×900 viewport, DPR 1, 전신 camera, 동일 브라우저 탭에서 T103/T104 scene을 각각 완전히 로드하고 240 frame interval 표본을 비교했다.

`data-scene`의 최근 240 interval window는 관측 때마다 p95가 약간 변동했으며 T104에서 별도 관측된 상단값은 17.5 ms였다. 이는 T103 비교값보다 약 2.3% 높은 수준으로 T22의 +20% 경보선 아래다. 여기 기록은 warm local route의 steady-state frame/resource 측정이다. 빈 network/browser cache 조건의 cold-load 시간을 주장하지 않는다. 전체 GLB byte 차이는 실제 manifest 총량이다. 반복 지역·근육 layer 전환 중 T104 10개 node의 unique count와 chunk/resource 수가 증가하지 않는 것도 확인했다.

## 상태와 미완 항목

- 10개 mesh는 `source_only_unbound`; 새 stable learner ID/canonical binding은 0이며 해부학 검토는 수행하지 않았다.
- 각 OBJ header는 `CC Attribution-Share Alike 2.1 Japan`을 적고 현재 공식 LSDB license 페이지는 database에 CC BY 4.0을 적는다. 파일 수준 권리 관계는 해결되지 않아 public redistribution은 held다. local technical display 적격성은 별도로 제한 허용했다.
- T103의 기존 사용자 변경, T13 drafts, source bytes, history manifests 및 `OpenSim_Models`를 보존했다. 전신 denominator는 계속 미동결이고 visual coverage는 partial이다.
- cold network-load benchmark와 저장된 screenshot 파일은 없다. 이것은 browser/render pass를 취소하지 않지만 이 run에서 그 수치를 주장하지 않는다.
