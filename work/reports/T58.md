# T58 — 그래픽 품질·연속성 검증

2026-09-27 · Astra 직접 구현 · **partial**

렌더링·framing·패널 가림 개선과 로컬 검증은 완료했다. 그러나 실제 머리/전신 형상 누락으로 사용자가 원하는 완성된 전신 atlas 그래픽은 합격시키지 않았다. `passed_with_gaps`로 필수 시각 미달을 덮지 않는다. T59 이상은 시작하지 않았다.

## 구현

- 기존 단일 AnatomySceneRoot/renderer/camera/자산 queue를 재사용했다. 밝은 배경에 아이보리 뼈·차분한 근육색, 덜 강한 노출과 주변 구조 흐림, teal 선택을 조정했다. 불투명 재질을 유지해 투명 정렬 문제를 피했다. 실제 모형에 없는 디테일·그림자·해부학 표면을 만들지 않았다.
- `보기 옵션` 안에 **선택만 보기**, **선택 부위 맞춤**을 추가했다. 깊은 근육을 주변 구조 없이 살펴보고 복귀할 수 있다. 자동 선택이나 패널 열기는 카메라를 맞추지 않는다. 맞춤 버튼만 명시적으로 framing을 바꾼다. 단독 표시 상태는 닫힌 메뉴에도 남고 선택 변경 시 해제된다.
- 선택 가능한 기존 binding에만 hover 강조와 pointer cursor를 적용했다. pointermove는 프레임당 한 번 raycast하며 터치/드래그는 hover를 해제한다. source-only 앞면을 뚫고 뒤의 binding을 선택하지 않는다. hover 자체의 별도 브라우저 자동화 검증은 하지 않았다.
- 모바일 설명 패널이 열리면 같은 canvas의 표시 공간을 줄인다. 카메라 위치/target/root를 보존하고 패널 앞에 모형이 가려지는 문제를 해결했다. 설명은 패널 내부에서 스크롤한다.
- 시작 화면의 HUMAN ATLAS 글자와 실제 로딩 상태만 유지했다. 로고·인체 그림·슬로건은 복구하지 않았다. 로딩 컴포넌트와 T56/T57 역사 기록은 수정하지 않았다.

## 실제 화면과 성능

`work/evidence/T58/`의 home-1440, whole-back, leg-front, head-front, head-side, hand-front가 실제 동결 GLB 기준 캡처다. deep-selection-1440, selected-fit-1440은 명시적인 단독 표시와 맞춤이다. panel-1024, selected-390, panel-open-390은 실제 learner 화면이다.

390px에서 열린 패널 top=534.96px, canvas bottom=524.96px로 10px 간격을 확인했다. 화면 가로 넘침은 없다. 같은 root/camera에서 30개 주변 구조→선택 구조 1개→30개 복귀를 확인했다. 회전 키도 같은 root에서 작동한다. 검사 화면에서 검은 프레임·예기치 않은 레이어 소실·카메라 reset·투명 정렬 오류를 관찰하지 않았다. 모든 가능한 자세/기기에서 없다는 보증은 아니다.

## 미완·책임·재개 조건

**G58-01 (blocking)**: head-front/head-side에는 머리뼈/얼굴 윤곽을 이루는 형상이 크게 빠져 있고, 전신 홈에서도 같은 결손이 보인다. 이를 camera/material 문제로 오인해서 임의 형상을 추가하거나 숨겨진 held 자료를 승격하지 않는다. 전신/머리 fidelity C, 종아리 B, 손 B(근접 표면 단순화·완전성 미확인)이다. A는 연속적이고 상세한 학습용 형상이라는 로컬 기준이며 의학적 승인 등급이 아니다.
