## 변경

1. Animation adapter는 반환할 `gltf.scene` 하나를 active playback root로 명시한다. rig/path binding, 모든 반환 clip의 track target, active `SkinnedMesh`의 skeleton bone이 모두 그 트리 안에 있는지 검사한다. 다른 glTF scene은 자원 해제 소유 범위로만 유지한다. 정상 단일 scene과 원래 clip/hierarchy/skin 정보는 유지된다.
2. root GLB SHA 검증 뒤 GLB JSON chunk를 GLTFLoader보다 먼저 검사한다. 첫 운영 입력은 self-contained GLB 하나로 한정하며 buffer/image의 외부 URI 및 data URI를 거부한다. 네트워크 오류에 의존한 검증은 사용하지 않았다. frame·meter·duration·원본 SHA·abort gate와 GPU dispose는 유지했다.
3. 정적 종아리 loader는 T07 scene의 일곱 근육 mesh ID에 속한 canonical mapping만 검증한다. 전역 `20/6/7` 개수 및 다른 scene mapping의 `right/needs_review` 고정을 제거했다. T07 crosswalk·bone manifest의 검토 상태도 런타임 로드 조건으로 고정하지 않고 실제 값을 전달한다. 선택 scene의 자산/instance/evidence/target 참조는 검증한다. T07/T13 원본 GLB hash·bytes, revision·frame·pose, 현재 아홉 bone mapping의 `needs_review`, FJ3385 보류는 보존했다.
4. 현행 [motion source manifest](../../atlas-data/motion/motion-asset-sources.json)는 첫 후보를 `HA-M-000003` 전경골근/앞정강근/Tibialis anterior의 오른쪽 발목 배측굴곡으로 기록하고 self-contained 입력 정책을 명시한다. [ADR-001 후속 결정](../evidence/T22/ADR-001-animation-loader-boundary.md)에 동일 내용을 추가했다. T22 보고서의 당시 발바닥굽힘 기록은 그대로 두었다. 새 관절 좌표, rig, clip, 해부학 claim은 없다.
