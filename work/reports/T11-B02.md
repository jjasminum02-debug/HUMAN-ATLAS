## 출처 접근 및 검토 상태

필드별 URL·판본 상태·locator·조회일·접근방식은 `atlas-data/terminology/term-review-batches.json`의 B02 evidence와 `learning-names.json`의 sources에 기록했다. 조회일은 2026-09-25다.

- [FIPAT TA2 Part 2](https://fipat.library.dal.ca/wp-content/uploads/2020/09/FIPAT-TA2-Part-2.pdf): 정확한 판본은 TA2 제2판, Part 2, 온라인 2019. 공식 검색 색인 결과에서 지정한 10행·인쇄면의 라틴어/영어 문자열을 관찰했다. PDF 직접 open은 HTTP 502로 실패했고 파일/page image/표 열 역할을 시각 검토하지 않았다. 검색 색인은 원문 대조나 표 열 검증이 아니다.
- [KMLE extraocular 검색](https://m.kmle.co.kr/search.php?Search=extraocular), [rotator cuff 검색](https://m.kmle.co.kr/search.php?Search=rotator+cuff): 해당 페이지 텍스트를 열어 확인했다. KMLE가 표시한 사전 하위판본·연도는 미노출이다.
- [KMLE 근육 용어 검색](https://m.kmle.co.kr/search.php?Search=musc), [head/mastication group 검색](https://m.kmle.co.kr/search.php?Page=4&Search=group+of+muscles), [등근육 근접항목 검색](https://m.kmle.co.kr/search.php?Search=back), [thorax 검색](https://m.kmle.co.kr/search.php?Search=thorax), [upper limb 검색](https://m.kmle.co.kr/search.php?Page=2&Search=upper), [scapulohumeral 검색](https://m.kmle.co.kr/search.php?FuzzyTrack=scapula&IsFuzzy=YES&Search=scapulo): 검색 결과 발췌에 나타난 명칭만 기록했다. 정확한 dictionary edition/revision은 각 페이지에서 공개되지 않는다.

사람 해부학 검토자는 참여하지 않았다. 모든 B02 항목 및 필드는 `humanAnatomyReviewStatus=not_performed`, `humanReviewed=false`다. 용어 문자열을 찾은 결과는 구조·범주·해부학적 동치 승인으로 해석하지 않았다.
