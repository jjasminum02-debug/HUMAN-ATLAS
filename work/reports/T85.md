## 변경

현재 등록된 모든 22개 동작 결속을 검사하는 공통 프레임 문맥 경로를 추가했다. 동작 패키지의 고정 framing, 정확한 선택 표면, moving/co-moving 뼈와 정확한 기시·정지 연결 중 표시 가능한 whole-bone을 같은 장면 프레임에 포함한다. 패키지의 사지 뼈 사슬이 제공하는 팔/손·다리/발도 유지한다. 반대쪽 구조를 이름이나 근접성으로 추론하지 않는다. 뼈 layer-off, 선택 격리, hidden 상태는 자동 문맥보다 우선한다.

실제 표시 적격성은 기존 source ID·부착 관계·side·layer·visibility·hold 자료로 필터링한다. 이 변경은 새 해부 구조, 부착 좌표, 정상축, 좌우 매핑, 인체 측정값을 만들지 않았다. 별도 viewer나 renderer를 도입하지 않았다. 모바일 펼친 상세 패널 위치를 조정해 canvas·도구·상태와 겹치지 않게 했다.
