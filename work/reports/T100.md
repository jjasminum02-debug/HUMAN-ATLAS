## 구현과 상태 교정

- T98/T99의 “그 task에서 아직 승인하지 않음”을 후속 task의 영구 금지로 해석한 것이 반복 중단의 주원인이었다. AGENTS·25 설계·T100 명세·공식 프롬프트 생성기를 정정했다. 사람 검토 미수행 및 공개 배포 held를 로컬 표시의 일괄 선행 조건으로 사용하지 않는다.
- pinned ZA source-family 이용 근거/예외를 검토한 현재 `local-display-review.json`과 객체별 overlay를 추가했다. 원본의 source-only/기본 숨김/권리 기록은 T98/T99에 그대로 남고, 현재 local rendering과 검증한 semantic binding은 별도 결정이다. 공개 재배포와 사람 검토 승인을 발명하지 않았다.
- 일반 `/` 앱이 기존 WholeBodyViewer와 단일 AnatomySceneController를 재사용해 ZA를 표시한다. 별도 검정 화면·두 번째 renderer·BP3D 중첩·새 원본 다운로드 없이 공통 T99 chunks/LOD/cache를 사용한다. BP3D compatibility subset은 실제 hash 회귀로 보존한다.
- 부위 다중 선택/해제/빈 선택 전신, 표면 직접 클릭, typed muscle/bone cards, 좌우 전환, 검증된 세 이름·별칭·영어 오타 검색, 주변 흐림·선택 반투명·숨김·단독 보기·맞춤·undo/복원을 연결했다. 선택 시 카메라를 바꾸지 않는다. 일부 검증된 HA concept의 기존 기시정지·기능 문장은 그대로 재사용한다. 표정근 포함 움직임 버튼은 미지원 상태다.
- 학습 UI에 내부 task/승인/JSON/annotation 용어를 추가하지 않았다. 필수 자산 출처/변환/이용 조건은 앱 정보에 모았다. 로딩 로고·인체 그림·슬로건을 되살리지 않았다.
- 과거 AGENTS.md freeze 검사와 현재 runtime/source 검사를 분리했다. `test:whole-body`는 현재 runtime/실제 compiled source dependencies 및 46개 chunk hash를 검사한다. 원래 historical 검사는 별도 script로 남으며 과거 실패를 통과로 변경하지 않았다.
