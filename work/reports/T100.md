## T100에서 완료한 구현

- T98 target/source catalog와 T99 compiled manifest를 연결한 전신 coverage matrix 및 validator를 추가했다. 모든 target의 source candidate, source-side label, region membership, identity/geometry/frame/rights/review 상태를 별도 기록한다. 0 exact joins, 0 learner binding을 숨기지 않는다.
- T105–109 absorbed scope는 재취득 없이 기존 inventory/hold 입력으로 참조하고, T110–121 대상은 T96 역사 package 보존과 함께 지역별 최대 10개 내부 unit 59개로 표현했다. T166의 핵심 일부인 관찰 보기 상태 제어는 현행 scene controller에 구현했다.
- 기존 장면의 선택 표면에 **반투명**, **숨기기**, **되돌리기**, **보기 복원**을 추가했다. 숨김은 학습 selection을 유지하고 선택 표면만 감춘다. layer-off, 지역 필터, 기존 hold/표시 적격성을 복원 제어가 덮지 않는다. 새 canonical ID, name alias, ZA learner binding은 만들지 않았다.
- 실제 브라우저에서 기존 12개 부위 URL 전환, 기존 비복근 카드/세 이름, 선택 숨김→undo, 반투명, isolate, muscle layer-off→restore를 확인했다. 같은 canvas ID를 유지했다. 브라우저 장면은 기존 BP3D 호환 장면이므로 이것을 ZA 전신 통합 검증이라고 세지 않는다.
