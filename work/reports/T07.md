## 결과

T02가 실제로 취득한 우측 종아리 OBJ 11개만 단일 부위 GLB로 변환했다. mesh와 모델 ID는 원본 FJ ID를 바탕으로 고정했으며 무작위 ID나 재메시를 만들지 않았다.

- `modelId`: `HA-MODEL-BP3D4-R4-RIGHT-LOWER-LEG-STATIC`
- `meshAssetId`: 각 원본 FJ ID에 대응하는 `HA-MESH-BP3D4-FJxxxx`
- 포함: 근육 표현 7개(비복근 내·외측두 각각 1 mesh)와 뼈 표현 4개.
- GLB: `atlas-data/assets/derived-glb/bodyparts3d-r4-right-lower-leg/right-lower-leg.glb`, 712,192 bytes, SHA-256 `044450c3230bd23869a099d545151cb3d7518da3240a6e59f911f82786edc341`.
- 변환 단위/축: 원본 mm, RH, +X 환자 좌, +Y 후방, +Z 상방에서 Atlas m, RH, +X 환자 좌, +Y 머리/상방, +Z 전방으로 `[x,y,z]atlas_m = [x,z,-y]source_mm / 1000`를 적용했다. 회전행렬은 `[[1,0,0],[0,0,1],[0,-1,0]]`, 행렬식 +1이다. 원본 face index 순서/winding은 유지했고 vertex normal에는 scale 없이 동일한 회전을 적용했다.
- GLB scene 안 mesh/node는 별개 항목으로 남기고 manifest의 `meshNodes`가 node/mesh index, 안정 ID, source FJ/BP/FMA, 원본 hash, geometry/topology/normal hash, 표 행 locator와 canonical 대상 ID를 연결한다.
- T02 측정 Atlas 경계와 GLB float32 경계의 최대 차이는 `1.483535766455546e-8 m`였다. 모든 자산의 source와 Atlas +X 최대값이 음수로 남아 우측 확인을 통과했다.

## 매핑과 검토 경계

- 7개 근육 mesh는 T04 BodyParts3D crosswalk 및 T04/T05 canonical muscle/part ID에 provisional 연결했다. 뼈 mesh 중 calcaneus/fibula/tibia 3개는 현재 T05 structure ID에 연결했다. 연결 상태는 전부 `needs_review`다.
- FJ3385 / BP8033 / FMA24482 (talus)는 현재 canonical catalog에 talus structure ID가 없어 internal target ID를 null로 남겼다. 추정 ID를 만들지 않았다.
- T03 `MeshMapping`은 좌우 anatomical instance 또는 `muscleParts` 레코드를 요구하지만 현재 canonical dataset에는 instances, `muscleParts`, meshAssets 및 meshMappings가 없다. 따라서 이번 task는 schema-conformant `MeshAsset` records와 구분되는 provisional `meshCrosswalk`를 T07 manifest에 보관했다. canonical catalog와 T05 자료는 변경하지 않았다. mesh identity와 좌우 구조를 사람 검토한 것으로 간주하지 않는다.
- 포즈 ID는 T02의 `bodyparts3d-r4-static-reference`를 그대로 사용한다. 관절 자세가 문서화되지 않아 표준 해부학 자세나 변형 포즈를 뜻하지 않는다. 기시·정지 영역이나 공간 annotation을 만들지 않았다.
- OBJ에 `usemtl` 지시자는 있지만 선택된 T02 파일들에 `mtllib`/material 정의는 없다. GLB에서는 source 색상/재질을 주장하거나 생성하지 않았고 primitive는 source geometry와 normals만 포함한다.
- 권리/귀속은 T02가 기록한 정확한 LSDB Archive Release 4.0 조건을 따른다. manifest에 필수 문구 `BodyParts3D, © The Database Center for Life Science licensed under CC Attribution 4.0 International`와 source hash, 파일별 원본 hash, 변환 요약을 보존했다. 2013 OBJ 내부의 예전 CC BY-SA 2.1 Japan comment도 편집 없이 원본 bytes에 남아 있으며 별도 metadata로 기록했다. 외부 공개·배포는 하지 않았다.

재현 명령:

```sh
python3 atlas-data/tools/convert_bodyparts3d_obj_to_glb.py
python3 atlas-data/tools/convert_bodyparts3d_obj_to_glb.py --output-glb work/evidence/T07/repeat-run/right-lower-leg.glb --output-manifest work/evidence/T07/repeat-run/derived-assets-t07.json
python3 work/evidence/T07/validate_t07.py
```

GLB container는 [Khronos glTF 2.0 specification](https://registry.khronos.org/glTF/specs/2.0/glTF-2.0.html)의 header/chunk 순서와 4-byte padding 계약을 기준으로 작성했다. 해당 형식 계약과 데이터는 자체 decoder로 검사했으며 별도 Khronos glTF Validator 실행 파일은 환경에 없어 사용하지 못했다.
