## 구현

- 기존 T12 leg scene은 그대로 두고 T13 9 mesh의 별도 leg scene을 navigation 생성기에 추가했다. T13의 기존 6개 source-linked 뼈는 typed binding, 제2–4 중족골 3개는 unbound context다. 기존 T12 talus 1개도 unbound 그대로다. 전체 20 mesh, selectable 16, context 4이며 기존 nine bone mapping의 `needs_review`와 human `not_reviewed`를 보존했다.
- loader는 활성 부위 scene 목록의 assetRef만 읽는다. 출처 manifest의 ID/URI/hash/mesh 집합 및 frame/units/pose/side 일치를 확인하고, Web Crypto SHA-256 후 GLB를 decode한다. 같은 revision의 요청은 CPU cache를 공유한다. 부위/선택 수명 종료 시 AbortSignal로 취소하고 늦게 도착한 응답을 버리며 실패 entry는 제거해 재시도한다. cache는 최대 두 scene revision으로 제한한다.
- ThreeViewer는 검증된 mesh 배열에서 geometry/material을 만들고 장면 교체·unmount·오류 때 dispose한다. observer, canvas listener, OrbitControls, overlay callback을 정리하고 WebGL context를 release한다. 카메라 preset/fit과 canvas resize는 새 scene 기준으로 재설정한다.
- learner의 scene 선택은 category/side manifest로 결정한다. 첫 URL 해석 전에 기본 종아리 viewer가 잠깐 생성되어 빈 부위에서도 GLB가 요청되던 회귀를 실제 브라우저에서 발견하고 routeReady gate로 수정했다. 명시적 빈 typed selection URL은 재로드/뒤로가기에서도 빈 상태를 유지한다. 선택 해제 시 카드·부착 문맥·읽기 전용 overlay 강조가 사라진다. `/review`의 입력 도구와 사용자 storage 자료 자체는 수정하지 않았다.
- T07과 T13의 런타임 이중 파싱을 없애고 strict decoder 하나만 사용한다. 5회 Node 측정의 중앙값에서 추가 GLTFLoader 단계는 T07 약 0.65 ms, T13 약 0.26 ms였고 별도 CPU geometry를 만들었다. 양 parser의 stable node/position/normal/index 동등성은 `check-scene-decoders.mjs`로 production build QA에 포함했다. 이 수치는 Node 로컬 측정이며 브라우저 frame time이나 실제 GPU memory의 정량 측정은 아니다.

## 미완과 경계

- 11개 다른 부위에는 확보된 scene/structure membership이 없으므로 GLB를 가져오지 않고 준비 중 상태다. 전신 모델을 생성하거나 다른 좌표를 섞지 않았다.
- 현재 browser build의 출처 asset registry는 T07/T13 GLB 두 파일만 허용한다. 후속 부위 자산을 확보하면 URI import와 source/frame/pose/hash 검증 계약을 명시적으로 추가해야 하며, 미등록 모델은 로딩하지 않는다.
- 뼈/근육 해부학적 동일성, T05 부착 표면 0/41, T14b 사람 검토는 미완이다. 명칭/부착 claim 추가, `reviewed` 승격, rig/clip/움직임 제작은 없다.
- 실제 사용자 브라우저 localStorage의 원시 T09/T13b 초안 hash와 GPU 사용량 수치는 획득하지 못했다. 해당 저장소에 import/export/save/delete를 하지 않았고, 파일로 보존한 T13c draft 3건의 hash는 일치한다.
- T15f 이상, push/배포, 경혈/Pro mode, 환자 진단·치료, 침 시뮬레이션은 수행하지 않았다.
