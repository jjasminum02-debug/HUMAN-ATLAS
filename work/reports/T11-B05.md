## 출처 접근과 한계

TA2에서는 FIPAT Part 2 PDF의 표 헤더 및 행을 직접 열어 텍스트로 확인했다. 표 헤더에서 Latin term, Latin synonym, UK/US English, English synonym 열 이름을 확인해 B05 값의 실제 열 역할을 기록했다. HA-M-000023는 해당 row의 Latin term `Levator scapulae`, Latin synonym `Musculus levator scapulae`, English synonym `Levator scapulae muscle`을 구별해 관찰했다. 원 FIPAT library URL은 HTTP 502였지만 Dalhousie 공식 호스팅 PDF를 열 수 있어 행을 대조했다. 페이지 PNG 또는 시각 표 레이아웃 캡처는 확인하지 않았다.

KMLE 검색결과에서 확인한 완전한 한자 10개를 데이터에 연결했다. 하위 사전 판본·개정 정보는 대부분 노출되지 않았다. 예외로 HA-M-000030의 KMLE HTML 페이지를 열었으며, CancerWEB 항목에서 2000-03-05 날짜가 확인된다. `work/evidence/T11/B05/web-source-log.md`와 ledger source record가 각 값의 URL/판본 상태/locator/접근일/방식을 보존한다.

검색결과에서 발견한 `前方鋸筋`은 HA-M-000027에 추가하지 않았다. 정확한 해당 근육명/동일성으로 채택할 원문 근거가 부족하다. M30의 기존 영어 `Deltoid` 검색은 원문에서 직접 확인 가능한 동의어로 alias에 보존했고 TA2 필드는 `Deltoid muscle`로 정렬했다.

사람 해부학 검토는 미수행이다. 모든 B05 evidence와 overlay는 `humanReviewed=false`, 상태 `not_performed`다. 웹 용어 확인은 명칭·개념 연결에 대한 자격자 검토나 구조/기능/부착 claim 승인으로 계산하지 않는다.
