## 공식 R4 source 및 접근 상태

검토한 판본은 BodyParts3D Release 4.0이다. 현재 공식 metadata endpoint의 경로 표기는 `/LATEST/`이지만, 공식 README update history에서 3D R4 갱신일은 2013-06-19, 현재 README/license 안내 갱신은 2025-02-27로 구분했다. 공식 다운로드 페이지는 IS-A/PART-OF concept 목록, 관계표, compound→ELEMENT 목록 및 99%-reduced OBJ archive를 서로 다른 자료로 제공한다. 6개 TSV를 project cache의 실제 파일로 확인하고 T51 source manifest의 bytes/row/hash와 재대조했다. URL, 실제 판본 표기, 조회일, 행 수 및 SHA-256은 [source-research.json](../evidence/T73/source-research.json)에 있다.

이 R4 자료는 source FMA/BP/FJ 표이지 HUMAN ATLAS canonical 분모가 아니다. archive listing은 하나의 99%-reduced polygon set을 제공하며 다단계 LOD나 rig/animation을 뜻하지 않는다. R4는 정적 reference geometry이고 표준화된 articulated pose가 아니다. metadata 자체에는 전 dataset 단위가 명시되지 않았다. 기존 OBJ Bounds 헤더는 mm 표기이나 그 사실이 모든 source unit이나 mesh surface 검토를 보증하지 않는다. 공식 database page의 CC BY 4.0 안내와 로컬 legacy OBJ header의 CC BY-SA 2.1 Japan 문구는 파일 단위로 조정되지 않아 기존 public redistribution hold를 유지한다.

광배근 대안 source로 공식 Z-Anatomy 저장소/README/license를 열어 candidate 메타데이터만 확인했다. 저장소는 BodyParts3D에서 파생된 모델을 포함한다고 밝히며 저장소 내용에 CC BY-SA 4.0을 표시하지만, 제3자 포함 항목에는 별도 라이선스와 NC 항목이 있다. 현재 branch URL은 고정 판본이 아니고 광배근 exact object ID/path/hash, 구성요소별 허용조건, BodyParts3D/HUMAN ATLAS와 공통 frame/rest pose는 확인하지 못했다. 따라서 후보일 뿐 채택 source가 아니다. 1차 출처와 실제 열린 page는 evidence에 기록했다.
