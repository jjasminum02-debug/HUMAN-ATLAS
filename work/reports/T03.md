## 계약과 안전 경계

T02 변환은 source mm `(x,y,z)`를 Atlas m `(x,z,-y)/1000`로 옮기며 회전행렬은 `[[1,0,0],[0,0,1],[0,-1,0]]`, determinant는 `+1`이다. 알려진 표지의 Atlas 위치를 mm로 잘못 취급한 1000배 오차는 허용치를 넘어서 실패한다. Atlas v1 world는 RH, +X 환자 좌, +Y 머리/상방, +Z 전방, m다.

`reviewed`는 evidence ID, source locator, 현재 content hash에 붙은 `human/approved` review record를 구조적으로 요구한다. 이 문자열만으로 사람의 실제 신원·서명은 인증할 수 없고 별도 승인 시스템도 T03 범위에 없다. Positive fixture에 있는 synthetic approval은 검증기 gate용이며 실제 사람 리뷰를 뜻하지 않는다.

## 미실행 및 미확인

- 외부 공개, 자동 배포, OpenSim 원본 편집/복제, 앱 UI/browser 검증은 수행하지 않았다.
- anatomy 의미/해부 위치는 검토하지 않았다. Mesh 및 evidence fixture는 synthetic으로, 실제 근육·근복·부착부 데이터가 아니다.
- 일반 JSON Schema Draft 2020-12 전체 기능을 구현한 validator는 아니다. 현재 스키마에서 사용한 키워드를 검사하고 미지원 키워드는 fail-closed 처리한다.
- `python3 -m py_compile` 시도는 Python bytecode cache를 보호된 시스템 경로에 쓰려다 실패했다. 프로젝트 파일을 쓰지 않는 내장 `compile()` 구문 검사와 모든 JSON 파싱은 통과했다.
- T04에 필요한 정확한 표준 edition, 개별 항목 locator, 전신 canonical list는 미확보이며 source gap queue에 이어진다.
