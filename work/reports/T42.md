# T42 — 학습 화면 정리와 뼈 세 이름

**상태: passed_with_gaps · 담당: Luna Max · 2026-09-27**

T23 선행은 `work/reports/T23.md` 및 재개 evidence에서 `passed`로 확인했다. T23의 실제 클립 없음은 그대로 유지했다. 시작 HEAD와 사용자 변경 기준선은 [start-baseline.json](../evidence/T42/start-baseline.json)에 기록했다. 변경을 표시 계층에 한정했고 canonical claim/evidence/source/license records, 원본 GLB/OBJ, 사용자 초안 및 `OpenSim_Models`는 수정하지 않았다.

## 구현

- 근육과 뼈 선택 카드에 **우리말명 / 한자어명(한글 표기) / 영어명** 세 행을 통일했다. 실제 한자는 수집하지 않았다.
- 기존 선택 바인딩이 있는 뼈 9개만 `bone-name-overlay-t42.json`에서 이름/동의어 검색으로 연결했다. 검색은 기존 `HA-S-*` ID·instance·mesh selection을 사용하며 canonical ID나 구조 목록을 확장하지 않는다. 일반어 `중족골`은 첫째/다섯째 두 결과로 남겨 모호성을 임의 해소하지 않는다.
- 근육 기시·정지와 기능 learner projection에서 source/review 설명을 표시하지 않는다. 기능 텍스트에서 출처 범위 문장만 표시 계층에서 걸렀고, 원본 action 문장, claims, evidence refs와 source hashes는 그대로다. 충돌 필드는 `설명 정리 중`으로 유지한다.
- 선택 이름 아래, 구조/기능 탭 위에 비활성 **움직임으로 이해하기** CTA와 자료 준비 안내를 뒀다. 평가 탭은 숨겼다. 기능 탭에는 작용 요약과 선택만 표시한다. 주변 흐림과 모형 선택 컨트롤은 유지했다. 생산 clip 0개라 MotionPlayer를 마운트하지 않는다.
- 뼈의 영문 landmark를 한국어로 새로 추정하지 않도록 학습 화면에서는 감췄다. 카드에는 표지 준비 안내만 표시하고 원래 landmark/관계 자료는 내부 데이터에 보존했다.
- BodyParts3D attribution은 앱 정보 대화상자에 분리했다.

## 출처 대조

이름의 출처와 필드/동의어별 locator는 [source-access.json](../evidence/T42/source-access.json)과 [bone-name-overlay-t42.json](../../atlas-data/terminology/bone-name-overlay-t42.json)에 기록했다.

- [FIPAT Terminologia Anatomica, TA2 Part 2: Bones](https://cdn.dal.ca/content/dam/dalhousie/pdf/library/FIPAT/TA2/FIPAT-TA2-Part-2.pdf)의 열린 PDF text layer에서 판본 **Second Edition (2.07), 2019**와 IFAA 총회 채택(2020)을 확인했다. Locator는 overlay에 항목 번호, 인쇄 쪽, PDF 쪽 index로 남겼다: femur 1360/p51; tibia 1397/p52; fibula 1427/p53; calcaneus 1468/p54; navicular 1484/p54; medial cuneiform 1486/p54; cuboid 1489/p55; first metatarsal 1500/p55; fifth metatarsal 1502/p55. PDF는 text layer를 읽었으며 페이지 이미지의 독립적인 시각 판독은 주장하지 않는다.
- [KMLE 대한해부학회 용어 검색](https://m.kmle.co.kr/search.php?Search=femur) 결과는 각 구조 query URL의 열린 HTML 페이지에서 확인했다. 검색 snippet만 사용하지 않았다. KMLE 결과에 정확한 underlying edition 표기가 노출되지 않아 모든 해당 source row에 **판본 미노출**로 기록했다.
- [BodyParts3D 공식 license 안내](https://dbarchive.biosciencedbc.jp/en/bodyparts3d/lic.html)의 credit을 별도 앱 정보 화면에 표시했다: `BodyParts3D, © The Database Center for Life Science licensed under CC Attribution 4.0 International`.
- 인간 해부학 검토는 하지 않았으며 모든 새 이름 entry는 `not_reviewed`다. 검색/문헌 확인은 사람의 해부학 승인이나 geometry 검토가 아니다.

## 남은 사항

- KMLE 페이지는 원문 text를 열어 확인했지만 underlying exact edition을 노출하지 않는다. 향후 판본을 추정해 채우지 않는다.
- 뼈 landmark는 원문 영어 자료를 learner 화면에서 숨겼다. source-backed Korean locator를 조사·검토하기 전까지 학습 표지는 준비 중으로 둔다.
- 이름/표면/claim에 대한 사람 해부학 리뷰는 미수행이며 T14b 대기 상태를 유지한다. `reviewed`로 승격하지 않았다.
- production `MotionDefinition`/`MotionAsset`/clip은 0이다. 실제 움직임 재생은 미검증이며 이번 완료 항목도 아니다.
- production build에서 기존 500 kB 초과 App chunk 경고가 계속된다.
