## 원문 자산 취득과 재현성

선택 취득 대상은 공식 BodyParts3D Release 4.0 99%-reduced OBJ archive의 frozen archive members다. 공식 archive URL은 [BodyParts3D R4 IS-A OBJ archive](https://dbarchive.biosciencedbc.jp/data/bodyparts3d/LATEST/isa_BP3D_4.0_obj_99.zip)다. 전체 archive(공식 응답 Content-Length 142,903,898 bytes)는 받지 않았다. 140개 member는 HTTP 206 byte-range로 취득했고, T53에서 이미 해시 검증된 같은 원본 FJ 파일 2개는 cache에서 복사했다. 142개 모두 member path, ETag/Last-Modified, CRC32, byte count, FJ/source ID 및 SHA-256을 work/evidence/T54/source-acquisition.json에 기록했다.

- 선택 payload 합계: 27,120,886 bytes; 다운로드 실패 0.
- 변환 패키지: atlas-data/source-cache/bodyparts3d-r4/converted/t54/T54-shoulder-upper-limb-static-source.glb, 9,579,756 bytes, SHA-256 b114fc8644ea8de0f7d213262ebc02eb23b0e8b51d419516c0f52f03d4cf04cd.
- 이 큰 원본/파생 binary는 로컬 ignored source cache에 남기고 Git에는 넣지 않는다. staged manifests와 acquisition evidence에 재생성 입력·경로·hash가 남는다. 빌드 도구는 같은 검증된 입력에서 반복 생성하는 경로를 제공한다.
