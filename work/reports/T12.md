## 결과

Three.js 0.186.1 GLTFLoader/OrbitControls/WebGLRenderer/Raycaster 어댑터를 적용했다. 앱은 GLB SHA-256 및 11개 메시의 stable ID, position/normal/index 배열을 기존 T07 decoder와 정확히 비교한 뒤 장면을 만든다. 일반 화살표 회전과 Home 전체 보기를 명시적으로 구현했다. Raycaster의 faceIndex와 원래 index 배열로 triangle ID 및 barycentric 좌표를 기록한다.

T07의 11개 MeshAsset을 canonical catalog에 동일하게 연결하고, 우측 6개 근육 Instance와 7개 근육 MeshMapping을 추가했다. 비복근 내측·외측 머리는 기존 `muscle_part` concept ID를 각각 대응시켰다. 모든 연결은 `needs_review`이며 source table line과 원본 OBJ hash를 가리키는 dataset Evidence 7개를 추가했다. T03 validator는 canonical `muscle_part` concept을 MeshMapping.partIds와 향후 SpatialAnnotation의 부모 검사에 사용할 수 있도록 보완했다. 이는 해부학 동일성 승인이나 새 부착 위치 확정이 아니다.

뼈 4개 메시도 canonical MeshAsset에 보존했다. T03 MeshMapping에는 structure 대상 필드가 없어 이 4개를 근육 mapping으로 위장하지 않고 `atlas-data/manifests/canonical-geometry-t12.json`에 명시적 제외로 기록했다. 종골·비골·경골은 기존 구조 ID 후보가 있지만 사람 검토 전이다. **talus FJ3385는 canonical structure ID가 없어 null로 제외했다.** 다음 작업에서는 출처 대조 후 ID를 정해야 한다.
