작성일: 2026-09-26

## 범위와 결과

오른쪽 종아리 파일럿 6개(HA-M-000001–HA-M-000006)에 대해 학습 경로의 이름 검색 → 선택 → 선택한 근육의 3D 장면 → 한국어 기시/정지 요약 → 출처 경로를 실제 Codex 인앱 브라우저에서 확인했다. 한국어/영어 검색과 키보드 검색·선택은 각 6/6 통과했다. 선택 ID·URL·목록의 선택 상태·상세 제목이 일치했고 3D 장면, 기시와 정지 요약이 각 항목에서 표시됐다.

기존 파일에서 두 개의 잘못된 용어 출처 연결을 발견해 바로잡았다. 여섯 이름 행은 TA2의 비장근 locator(행 2272–2274)를 가리키고 있었으므로 잘못된 공통 연결을 제거하고 canonical 항목별 TA2 행/페이지를 출처 패널에 표시하도록 했다. 단비골근(HA-M-000006)의 KMLE 링크는 장비골근 검색이었다. 직접 열린 단비골근 KMLE 검색 링크와 출처 메타데이터로 교체했다. 표기·우리말·한자·별칭·humanReviewed 값과 canonical 해부 claim은 수정하지 않았다.

모바일에서 긴 이름 카드가 첫 화면의 기시/정지 요약을 밀어내던 현상에는 작은 화면 레이아웃을 조정했다. 390×844에서 6개 모두 scrollY=0 상태로 기시와 정지가 화면 안에 들어온다. 3D 캔버스는 화면 아래에 있어 스크롤이 필요하다.

## 현대 원문과 Gray 1918 비교

Gray 자료는 Henry Gray, Warren H. Lewis 편집, Anatomy of the Human Body, 제20판(미국판), Lea & Febiger, 1918의 다리 근육 장 8c다. 학습 출처 링크에서 Bartleby 원문 장과 1918 서지 표기를 열어 확인했다. TA 앞정강근 절 locator는 인쇄면 480이며 다른 다섯 항목의 인쇄면은 이번 검증에서 독립 확인하지 못했다. Gray 설명은 역사적 요약이며 현대 측정이나 사람 검토를 대신하지 않는다.

현대 자료는 원문에서 실제 측정한 항목만 claim에 대조했다.

각 Gray locator의 장/근육 제목, modern-source의 판본·URL·locator·접근일·열람 방식, 필드별 직접성 및 미확인 사항은 work/evidence/T14a/modern-source-register.json과 acceptance-matrix.json에 보존했다. 검색 색인/초록 접근과 출판사 전문 열람을 분리했다. 사람 해부학 검토는 여섯 근육 모두 수행되지 않았다.

학습 화면은 이름·TA2 locator·Gray 링크를 제공하지만 현대 논문 비교 자료는 화면에 직접 노출하지 않는다. 현대 근거와 Gray 요약의 필드별 비교는 검증 evidence에만 있다. 이를 화면의 해부학적 승인으로 오해하지 않도록 보고서와 상태 안내에 미완을 기록했다.

키보드 영어 검색 후 Tab/Enter 선택은 6/6 통과했다. 선택된 3D 장면은 우측 종아리 GLB 안에서 각 선택 ID에 연결된 근육을 유지했고 선택 목록/URL/상세가 일치했다. Gray 장은 학습 출처 링크에서 열었다. TA2 항목별 row/page를 6개 모두 확인했고, 단비골근 KMLE의 정확한 목적지도 열어 대한해부학회 현재 표기와 옛 용어 항목을 확인했다. HMR 뒤 브라우저 error/warn 로그는 반환되지 않았다.

1440/1024 재측정 시 브라우저 자동화가 바깥 창 너비만 바꾸고 CSS viewport를 390으로 유지해 마지막 수정 후 새 데스크톱 측정으로 주장하지 않는다. 이는 출처 패널 수정 전 수행한 실제 화면 검증이며, 모바일 재검증은 출처 수정 후 수행했다. 별도 화면 캡처 파일은 저장되지 않았다. 자세한 실행 근거는 browser-validation.json에 있다.

## 부착 범위와 보류

T13 manifest의 분모는 41개 부착 claim이다. 영역 분류는 상호 배타적이며 사람 검토 상태는 별도 축이다.

‘text_only’는 whole-bone 검색 맥락만 있는 항목이며 footprint가 아니다. ‘missing’은 맞는 표적 메시가 없는 항목이다. 41개 모두 surfaceReviewState=not_started로 사람 해부학 표면 검토 대기다. T13c-B01/B02/B03 geometry:null, context_only draft 3건은 별도 evidence 기록으로 보존하며 surface 후보에 넣지 않았다. 새 좌표/면은 추정하지 않았다.

## 미완 및 다음 경계

- 사람 해부학 검토자/날짜/의견이 없다. reviewed 또는 reviewed_structure_release 승격은 전혀 만들지 않았다.
- 실제 surface 후보 0/41이며 정확한 footprint와 mesh landmark 대응이 없다. 28개는 뼈 전체 검색 맥락, 13개는 대상 메시가 없다.
- 현대 근거가 해당 부착을 직접 측정하지 않는 필드가 남고, 일부는 초록만 열람했다. TA와 Gray의 locator가 미확인인 값도 보고서에 그대로 남겼다.
- 현대 논문 비교는 현재 학습 출처 패널에 보이지 않는다. 작은 화면의 3D는 첫 화면 아래라 스크롤이 필요하다.
- T14b와 T15는 시작하지 않았다. 배포, 진단, 치료, 침 시뮬레이션을 수행하지 않았다.
