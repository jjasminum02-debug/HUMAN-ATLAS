# AT10/F3 — 얼굴·귀·목 형상 수정, 미완료

2026-10-15 · 담당 Sol xhigh. 시작 HEAD `30653a77746d7c6164234b2d1001c5d41280289e`.

**형상 수정과 실제 앱 검증을 수행했으나 F3는 합격하지 않았다.** 검토 후보는 **f3c11**이다. 더 최신인 f3c12는 목 아래 접힘 때문에 반려했다. V1의 사용자 외관 반려, 부모 AT10의 partial/acceptance=false와 제품 등록 보류를 유지한다. 교수 검토나 자료 확보를 기다려 멈춘 결과가 아니다. 실제 source/native의 연결 조건과 자연스러운 형상이 아직 미달이다.

## 눈으로 달라진 것과 남은 결함

- 단일 young target의 찌그러진 얼굴 대신 고정 MakeHuman core의 얼굴 형태를 사용해 코·입·턱 윤곽을 다시 맞췄다. 원본/기존 derived source 좌표와 AI core-head recipe를 구분했다.
- 기존 sparse helix 고정점이 만든 뾰족한 귀를 반려했다. 귓바퀴 전체 원형 접힘을 일관된 국소 변환으로 복원하고 주변 머리와 같은 양의 3D field에 연결했다. 양측 실제 native를 각각 검사했다. 제어점 잔차만으로 귀 전체를 승인하지 않았다.
- 실제 ZA의 공막·홍채·각막·수정체를 발견해 같은 SkinLayer/root에 28,548-byte 표시용 LOD로 연결했다. 눈을 피부에 그리지 않았다. 실제 안구는 움직이지 않았다. 흰색/갈색/각막/어두운 수정체 표현은 AI 재질이며 원본 홍채색이나 광학 시뮬레이션을 주장하지 않는다.
- 목의 source/native 단면 관계를 다시 작성했다. f3c11은 목 윤곽이 개선됐지만 고정 어깨 경계의 접선이 급변한다. 위치 틈 0을 연속 정합 성공으로 세지 않았다.
- 실제 중립 화면에서 이마의 평탄·울퉁불퉁한 구간, 왼쪽 눈 안쪽의 native 노출, 귀 일부의 경계/관통과 목·어깨 연결 문제가 남았다. **자연스러운 성인 얼굴/목의 최종 외관 승인도 하지 않았다.**

원형/반려 자산/고정 native를 동일 오프라인 정면·측면 크기로 비교했다. 이것은 앱 QA를 대체하지 않는다. 이후 실제 앱에서 중립 재질과 V1 각각 정면·양측 귀·뒤·목·전신·상반신을 확인했다. Complete Anatomy 공식 참고 이미지는 전체 실루엣 방향만 참고했고 자산/좌표를 복제하지 않았다.

## 왜 최신 f3c12를 채택하지 않았는가

f3c11의 고정 경계 바로 안쪽이 원래 F2에서 최대 약58mm 이동했다. 이를 두 개 내부 ring 158 vertices로 보존한 f3c12는 원래 seam dihedral 차이 0, native 전체 2,765/F3 1,514, local self0, 최소 3D determinant0.0835와 byte-exact 재현을 얻었다. **그러나 실제 중립 측면에서 경계 안쪽이 말려 올라가는 새 collar 접힘을 만들었다.** scalar seam 문제를 안쪽으로 옮긴 것이므로 반려했다. 실제 화면/접촉/field/reproduction 결과를 따로 보존하고 runtime DEV 목록에는 f3c11만 남겼다. f3c12는 최신이라는 이유로 최종본이 아니다.

첫 sparse pinna 시도, 두개 단면 축 비율 시도, 전체 native 접촉 보정의 한계도 `attempt-ledger.json`에 남겼다. 같은 입력의 가중치만 바꾸는 재시도로 합격시키지 않았다.

## 정확한 남은 단위와 다음 실행

다음은 **같은 AT10/F3의 collar/source-surface-pair 및 ocular/oral/pinna 잔여**다. F4는 계획상 후속이며 자동 실행하지 않았다.

1. F3 collar: 임의 source 높이 cut의 점 고정만으로 접선을 맞추지 않는다. 실제 source collar ring와 native 경추/목근/빗장뼈 관계를 다시 확인하고, 원래 표면의 접선·국소 두께/3D 연속 조건을 함께 작성한다. c12처럼 두 ring을 원위치로 고정해 접힘을 옮기는 방법은 반복하지 않는다. 실제 실패 주소는 `shared-boundary-f3-f4.json`, `collar-transition-f3c12.json`.
2. F3 ocular: 실제 좌/우 palpebral/globe와 원형 eyelid rim/return의 연속 표면 쌍. 왼쪽 눈 안쪽의 native 노출을 숨기거나 안구를 옮겨 해결하지 않는다.
3. F3 oral: 실제 있는 Gingiva/Tongue/Soft palate와 원형 입술/내부 return/아래턱 관계. closed neutral lips에서 전체 점막 접근은 미지원이다. Teeth.g는 annotation 선이며 치아 체적 표면으로 쓰지 않는다.
4. F3 pinna: 복원한 원형 접힘을 지키며 helix/concha/lobule 전체의 접촉·두께·attachment를 해결한다. nearest/ray와 낮은 control residual은 의미 검증이 아니다.
5. F3 자연스러움: 중립 forehead의 평탄/굴곡, 귀·목, 전신 비례를 다시 판독한다. 위치·재질 통과와 분리한다.

필요한 입력은 새 전신 source나 교수 승인 대신 **기존 source/native 실제 주소 간의 연결 조건**이다. 원문과 실패/성공 위치는 보존한다. `remaining-units-final.json`, `remaining-probes-f3c11.json`, 전체 raw NPZ 및 새 점막 관계 주소를 시작점으로 사용한다. 붙여넣을 다음 실행문은 evidence의 `NEXT-F3.md`다.
