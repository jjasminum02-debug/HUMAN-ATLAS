## 결정 요약

T52가 과거 표시한 source-name/bounds-center 반대 3건과 14개 추가 중앙면 AABB 교차를 원본 FJ/FMA/BP 관계, acquisition/hash, OBJ 표면, 대응 좌우 구조, 실제 GLB 정점, 열린 해부학 자료와 비교했다. 17개는 재검증 대상으로 유지했지만, AABB 중심 또는 `x=0` 교차만으로 오류나 사람 확인 의무를 만들지 않았다.

공유 frame은 T50 계약의 `[x,y,z] mm → [x,z,-y] m`이며 x 부호를 보존한다. 공식 BodyParts3D R4 좌표계 설명은 x 양수가 대상자의 왼쪽, 음수가 오른쪽이라고 정의한다. 85/85 source bounds가 이 변환과 맞고, 17개 대상의 원본 OBJ 정점을 동결 T52 GLB 실제 POSITION 정점과 순서대로 비교한 결과 float32 변환 값이 전부 일치했다(최대 차이 0 m, 노드 변환 identity). 모든 85 OBJ와 9 QA GLB의 hash/크기/ID 소속도 통과했다. 이것은 BodyParts3D 패키지 내부 frame/변환의 기술 검증이지, 라벨·해부학·OpenSim 정합을 승인한 것이 아니다.

- **T53 진행 가능: 예.** 동일 BodyParts3D R4 frame/변환을 지키는 독립 부위 취득은 진행 가능하다. 본 task에서는 T53을 시작하지 않았다.
- **T52 잔여: partial 유지.** FJ2742 right middle pharyngeal constrictor와 FJ2754 left middle pharyngeal constrictor는 표면이 서로 반대 방향에 놓인다. 파일 헤더/공식 ID 관계는 내부적으로 일치하지만 같은 source lineage이므로 어느 단계에서 라벨과 geometry가 엇갈렸는지는 확정할 수 없다. 둘 다 원본 라벨/정점을 보존하고 좌우 학습 binding에서 보류한다. FJ2780의 bounds center는 source 이름과 반대였지만 mesh가 정중면 양쪽에 분포하고 근육이 반대쪽 피열연골로 진행한다는 현대 원문과 맞아 별도 오류로 볼 근거가 없다.
- **T56 통합 한계:** 이번 85개는 source-only이며 canonical learner binding은 0이다. FJ2742/FJ2754를 좌우를 요구하는 학습 surface에 넣지 말고, 이 두 ID를 수정·mirror·교환하지 않는다. 아직 source별 license 텍스트가 상충하며, static mesh는 rig/움직임 자산이 아니다. 같은 frame 규약은 재사용할 수 있지만 이 조건을 전신 scene 배포 승인으로 해석하지 않는다.
- **사람 검토:** 수행하지 않았고 `reviewed` 승격은 0건이다. 개별 중앙 교차 16개를 일괄 사람확인 큐로 만드는 규칙을 두지 않았다.
- **배포:** 로컬 기술 검증만 완료. 현재 라이선스 페이지의 CC BY 4.0 문구와 frozen OBJ 헤더의 CC BY-SA 2.1 Japan 문구 사이 file-level 적용범위를 해결하지 못해 공개/재배포는 계속 보류한다.

### 확인된 개별 불확실성

1. **FJ2742/FJ2754**: reciprocal surface/label conflict. 동일 BodyParts3D FMA/FJ 관계는 파일의 현재 mapping을 기록할 뿐 올바른 geometry owner를 독립 확인하지 않는다. 해결할 최소 증거는 upstream의 file-to-label 수정/정정 기록 또는 독립 source의 고유 좌우 element correspondence다. 그런 것이 없으면 사람 해부학자가 원본 source identity 및 인접 구조를 검토해야 한다. 결과 전까지 기존 source ID, 라벨, 원본 정점을 모두 보존하고 binding은 held.
2. **FJ2738 left genioglossus**: named side 표면 면적 68.00%, 반대편에 1.506 mm 도달. mental spine 중앙 기시 문맥은 원문 검색결과와 맞지만, 정확한 좌우 mesh ownership 경계를 정의하지는 않는다. label error라고 볼 근거는 없고, exact surface ownership이 제품 요구가 될 경우에만 source-level 확인이 남는다.
3. **FJ2743/FJ2755 palatopharyngeus**: 98.83/99.72%가 명명된 쪽이며 작은 중앙 교차. supporting cadaver study는 초록만 확인되어 정중 경계의 세부 mesh owner는 아직 미확인이다. 현재 label conflict는 보이지 않는다.
4. **FJ3380 right parietal bone**: 99.04%가 음수 x에 있고 +x의 0.96%만 넘어간다. 왼쪽 짝 FJ3274는 공식 index에 있으나 T52 frozen 85개 밖이라 취득하지 않았다. 비교 대상 mesh 부재는 범위 제한이지 좌우 오류 주장이 아니다.

나머지 crossings는 실제 face area가 명명된 쪽에 우세하고 중앙 부착/접촉 맥락의 독립 자료가 있거나, 매우 작은 분리 파편이 AABB만 넓힌 사례다. 특히 SCM FJ1595 주 성분은 전체 표면 면적의 99.794%이며 음수 x 안에 있다. thyrohyoid FJ1599는 전체의 99.69%가 주성분/명명된 쪽에 집중되고 양수 x 파편 면적은 약 0.0033%다. 따라서 상자 끝점이 중앙면을 넘었다는 사실을 label 결함으로 자동 분류하지 않는다.
