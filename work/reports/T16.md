## 구현 결과

- `atlas-data/schemas/ai-evidence-overlay.schema.json`에 field-level evidence, source/work/locator/access, claim/evidence hash, legacy binding, evidence/geometry/motion 상태를 분리해 정의했다. AI field에는 사람 승인·canonical `reviewState` 필드가 없고, `additionalProperties: false`로 새 승인을 거부한다. 기존 review는 test-only migration binding에 이전 값 그대로 스냅샷한다.
- `atlas-data/schemas/validate_ai_evidence.py`는 canonical subject·source·claim·evidence 참조, 상호 evidence 링크, field/value/source/evidence hash, legacy claim/review hash를 검사한다. 새 `single_source`와 `cross_checked` claim은 검색 색인·초록·메타데이터가 아닌 열린 field text를 요구하며, cross-check는 서로 다른 `underlyingWorkId` 2개 이상도 요구한다. 같은 원문을 재인용한 두 사이트는 같은 underlying work로 계산한다. 충돌값은 각자 근거가 있어야 하며 `unavailable`은 설명을 요구한다. 읽지 않은 원문은 legacy migration preview의 명시된 예외에서만 exact legacy record로 보존한다.
- `build_ai_evidence_overlay.py --check` 및 `validate_ai_evidence.py --check`는 현재 14 legacy summary를 메모리 안의 test-only migration preview로 만들어 같은 schema/ref/hash 검증에 통과시킨다. Production overlay는 `items: []` 상태다. preview 경로도 `atlas-data/terminology/` 내부에는 쓸 수 없다.
- TypeScript domain types는 schema의 evidence/source/access/geometry/motion 상태를 구분한다. learner projection은 `cross_checked` 문장에 저위험 퀴즈 사용 가능성을 주되 사람 해부학·3D 검토는 별도라고 평이하게 안내한다. `single_source`는 제한을 붙이고 기본 퀴즈 정답에서 제외하며, `conflicted`는 대안만 제시하고, `unavailable`과 `unresearched`는 서로 다른 문구를 쓴다. projection에는 내부 상태 코드나 제작 JSON을 담지 않는다.
- 학습 adapter는 production overlay field를 우선하고 없으면 기존 summary text를 바꾸지 않는 legacy fallback을 쓴다. 현재 14개 기존 요약과 canonical claims/review는 원래 위치에 그대로 남겼고 새로운 claim, canonical ID, 사람 승인, geometry 또는 motion 값을 입력하지 않았다.
- 합성 fixture 8개로 같은 원문 URL 2개의 단일출처 판정, index-only 근거 거부, 독립 원문 교차대조, 충돌 field, geometry/motion 독립 조합, stale ref/hash 거부, AI가 human review를 추가하려는 경우의 거부를 확인했다.
