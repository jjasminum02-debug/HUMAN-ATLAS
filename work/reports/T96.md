## 수행 범위

T78의 TA2 2.07 source snapshot 2,422행, 기존 provisional target 556개와 supporting ledger를 대조했다. 모든 source 행의 표기·동의어·parent·flag와 원래 T78 분류를 새 semantic ledger에 그대로 남기고, 후보 제외와 support 승격은 exact TA2 row ID 및 parent chain으로 설명했다. 동결 결과는 `atlas-data/catalog/target-scope-t96.json`과 12개의 지역 package manifest다.

Inconstant 24, sex-specific 7, source에서 명시된 side 12건만 표시하고 반대쪽 복제나 개별근 수로 환산하지 않았다. bilateral instance 수, midline instance 수, repeated-family member 수는 정확한 source 개별 수가 없으므로 모두 null이다. 범주·각 target의 source cardinality 필드에 laterality, sex, inconstant, repeated 상태를 별도로 보존하고 side/반복 확장을 하지 않았다.

## 기존 자료와 승인 상태 대조

기존 canonical crosswalk는 이름 유사도로 결합하지 않았다. 85개 source crosswalk row 중 83개만 exact `tableRow`로 동결 target에 연결되고, HA-G-000007/HA-G-000010의 두 cross-region rollup은 context로 남는다. 연결된 canonical 83개 모두 `needs_review`다. target scope는 runtime lexical candidates, geometry, side, frame, canonical binding, 세 이름, 기시·정지, function, animation, human review, rights를 서로 독립적으로 보존했다. T96에서 새 canonical claim/binding 0, 사람 review 승격 0, rights 승격 0이다. 실제 개별근 denominator null이며 learner/geometry 완료를 뜻하지 않는다.

공식 TA2Viewer의 2.07 snapshot이 전체 2,422행의 source hierarchy 기준이다. FIPAT Part II 공식 PDF 검색 색인에서 auditory ossicles(row 880, p.37), ribs/individual rib(rows 1105/1118, p.44), bony pelvis(row 1282, p.49), obturator internus/externus(rows 2605/2636, p.94)를 추가 대조했다. FIPAT errata는 2.07을 2021-08-16 revision으로 기록한다. PDF binary를 내려받아 모든 table을 시각 검수한 것은 아니며 이 결과는 independent human anatomy review가 아니다. [공식 TA2 Part 2](https://fipat.library.dal.ca/wp-content/uploads/2020/09/FIPAT-TA2-Part-2.pdf), [공식 TA2 errata](https://fipat.library.dal.ca/wp-content/uploads/2021/08/FIPAT-TA2-Errata.pdf).
