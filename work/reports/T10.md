이번 요청을 개정 T10으로 기록했다. 기존 T00–T09를 재실행하거나 완료 기록을 소급 변경하지 않았다. 기존 T10 부착 매핑은 새 T13이다. T11–T24 명세는 미실행 계획이다.

## 판단

T00–T09는 원본 보존·근거 기록·검증·실제 소규모 3D를 만드는 기반으로 유효하다. 그러나 사용자에게 필요한 학습 경험이 완성된 상태는 아니다. 제작용 작업대를 학습 UI에 노출한 설계/구현 방향, 한국어 명칭 자료의 부족, 아직 매우 작은 형상 범위가 핵심 문제다. 모델을 Luna에서 Sol로 바꾸는 것만으로 해결된다고 볼 비교 증거는 없다. 이번에는 화면 분리와 표시 정책, 실제 코드, 후속 task의 검증 기준을 함께 바꿨다.

## UI와 구현 경계

- `/`: 학습 전용. 필요한 이름, 검색, 3D 선택/회전/격리/주변 투명/뼈 표시, 구조·기능·평가 탭. 기능/평가는 아직 준비 중이라고 표시.
- `/review`: 개발 환경에서만 기존 작업대. JSON은 자료 작성/교환에 필요하지만 학습 화면에는 필요 없다. production 경로는 학습 앱으로만 진입한다.
- `src/ui`: 화면; `src/data`: 학습 데이터와 표시명 projection; `src/domain/search.ts`: 검색; `src/viewer`: 모형; `atlas-data`: 근거 있는 원자료/파생정보; Python/Node scripts: 변환·검증.
- 현재는 정적 웹앱이다. 별도 서버 백엔드/인증/운영자 권한 시스템을 이번에 구축한 것은 아니다. 개발 전용 경로는 공유 서버의 인증 대체물이 아니다.
- 전신 목록 중 3D 없는 근육을 선택하면 파일럿 종아리를 해당 근육처럼 표시하지 않고 준비 중 안내를 보여준다.
- 모바일은 목록→모형→카드 세로 배치. 3D는 현 파일럿 범위이며 전신 부위 선택/완전한 학습 퀴즈는 후속 범위다.

## 용어와 콘텐츠의 현재 수준

13개 보조 용어 항목 = 파일럿6 + 비복근 근두2 + 승모근1 + 삼각근/견봉부2 + 판상근 lookup2. 실제 한자 기입4개, 그 밖은 근거 대조 대기이며 모든 근육의 한자 학습이 완성된 것이 아니다. 85개 canonical에 lookup2를 더해 87개 항목을 검색할 수 있으나 상당수는 영어 fallback이다. 판상근2개는 검색용 개별 후보이며 아직 canonical 채택되지 않았다.

`승모근`은 한자어의 한글 표기, `僧帽筋`은 한자 문자열, `등세모근`은 우리말 대체명이다. 사용자 요구는 첫 번째를 기본으로 이해하고 구현했다. 용어 웹 근거가 있으면 표시할 수 있으나 부착면/기능/평가 정답까지 검토됐다는 뜻은 아니다. 일부 KMLE 한자는 손상/오기가 있어 복사하지 않았다. 순우리말인 가자미근 등에 억지 한자를 생성하지 않는다.

구조 요약14개는 기존 Gray1918 claim을 한국어로 압축한 AI 번역이다. claim ID와 hash를 연결했고 원문 claim이 바뀌면 build 검증을 실패시킨다. 현대 해부학 검토는 T14에서 한다. 학습 UI의 출처 펼치기에 이 상태를 설명한다.

- `preservation.json`: 기존 atlas-data 파일 전부 hash 동일. OpenSim checkout clean, revision d9b05d470b1a481c222372c85b75772faf8f7792 유지. 기존 README/이전 작업 보고서를 수정하지 않음. 사용자 미추적 design 문서는 이번 수정 허용에 따라 개정, 강제 Git add/commit 없음.

## 남은 위험과 다음 작업

단어13개 추가를 전체 근육사전 완성으로 볼 수 없다. 구조 설명은 역사적 근거 초안이고 실제 부착면이 아직 없다. 학습 UI는 6근육에 맞는 첫 개편이며 전신 자산·부위별 탐색·성능 검증이 추가로 필요하다. 자체 renderer는 복잡한 glTF/투명 정렬/전신 대형 장면에서 검증되지 않았으므로 T12를 건너뛰지 않는다.

다음 **T11 — 현재 목록의 다국어 용어 완성**. 최대10개 단위 suffix 배치를 기록하고 하나씩 직렬 수행한다. `00-START-HERE.md`와 `work/STATUS.md`의 프롬프트를 사용한다. T11 전체 완료 전 다음 번호를 자동으로 올리지 않는다. 자료 차단 시 이유와 독립 진행 가능 범위를 명시한다.
