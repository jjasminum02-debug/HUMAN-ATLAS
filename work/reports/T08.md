# T08 결과 — 3D 선택·격리·카메라

## 완료 범위

T07의 정적 오른쪽 종아리 GLB/manifest를 T06 로컬 학습 앱에 연결했다. GLB, manifest와 OpenSim 원본을 수정하지 않았다. renderer는 이 T07 산출물 계약의 triangle mesh만 대상으로 하며, 전체 glTF 엔진으로 표시하지 않는다.

- Browser-side manifest/model/mesh ID, byte count, SHA-256 확인 후 11개 mesh를 로딩한다.
- mesh 선택과 연결된 근육/근두 카드 및 URL을 stable ID로 맞춘다. bone처럼 pilot card가 없는 mesh는 메시만 선택한다.
- 목록·카드 선택, 전체/주변/선택 확대, 정면/후면/우측 측면, mesh별 숨김·투명화·복원, 선택 격리/해제를 구현했다.
- 숨기거나 투명하게 한 표면은 picking 대상에서 제외된다. 원본 crosswalk의 `needs_review`와 provisional 상태를 화면에 남겼다.

## 검증

- `pnpm typecheck` — 통과.
- `pnpm build` — 통과. Vite가 T07 GLB 712.19 kB와 app bundle을 출력했다.
- 실제 브라우저에서 mesh→card, card/list→mesh, 빠른 4회 선택 전환을 확인했다. 빠른 전환 최종값은 FJ1409→HA-M-000006, FJ1437→HA-M-000002, FJ1439→HA-M-000003, FJ1440→HA-M-000004로 서로 일치했다.
- bone 선택은 기존 pilot card를 추정 생성하지 않았다. tibia hide 및 soleus transparency 이후 같은 캔버스 위치의 picking이 아래 보이는 mesh로 통과했고, restore all과 isolate 해제를 확인했다.
- 정면/후면/우측 측면 preset, 전체 보기, 주변 보기, 선택 구조 확대를 브라우저에서 작동시켰다.
- 마지막 브라우저 console error/warning 수는 0이다. 최종 주소는 `?muscle=HA-M-000004`, card와 선택 mesh는 각각 `HA-M-000004` / `HA-MESH-BP3D4-FJ1440`이다.
- 화면 증거: `work/evidence/T08/browser-screen.jpg`. 시나리오별 ID와 manifest 확인: `browser-qa.json`. Console: `console.json`. 명령 결과: `commands.json`.

## 보존 및 한계

T08 이전 53개 파일의 SHA-256 기록과 대조했다. 설계, README, AGENTS, T02 OBJ/GLB, T07 GLB/manifest 및 T05 데이터는 그대로다. `OpenSim_Models` HEAD는 `d9b05d470b1a481c222372c85b75772faf8f7792`, 작업 트리 clean으로 전후 동일하다. 비교 결과는 `preservation-before.json`, `preservation-after.json`에 있다.

Three.js는 local pnpm metadata/store에서 찾지 못했고 offline 설치도 실패했다. 외부 패키지를 추가하지 않고 T07 GLB의 실제 계약에 한정된 로컬 WebGL viewer를 만들었다. 모델 선택과 표시 동작은 해부학적 동일성, 포즈 정확도, 부착 표면 또는 사람 검토 완료를 뜻하지 않는다. 모든 mesh 관계와 관련 anatomy claim은 계속 `needs_review`이며, 공개·배포·임상 사용은 수행하지 않았다.
