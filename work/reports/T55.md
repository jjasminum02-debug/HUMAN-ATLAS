## source set, 취득, 변환

T51이 같은 BodyParts3D R4 source에서 만든 원자 source ID 목록 세 개를 취득 전에 동결했다: 넙다리 20, 종아리 30, 발 80, 총 130 unique FJ ID/130 region membership, 중복 소속 0. 13개 내부 batch를 사용했고 batch 최대 크기는 10이다. `frozenMembershipSha256=ce4d7206f840a97c97b9287f8b0b41e2ee5216009f8b7cbc9f24590e1220810b`; frozen source-set file SHA-256은 `da916638c5745d19ddeb3aedb8ca97f80739c9c9498874ff95a47cb16ae55fab`이다.

공식 BodyParts3D Release 4.0 archive에서 요청 ID만 range로 가져왔다. 110개는 공식 HTTP 206 selected-member range, 20개는 T51/T07에 있던 파일 bytes를 공식 archive CRC와 비교해 재사용했다. 130/130 파일의 FJ/FMA/BP identity, ZIP CRC, SHA-256과 OBJ header를 확인했고 다운로드/identity 실패는 0이다. 전체 archive는 받지 않았다. 세 region list와 FMA/BP/FJ/source node/canonical learner ID는 별도 필드로 유지했다.

하나의 source frame/pose에 T50 contract의 변환 `[x,y,z]mm → [x,z,-y]m`를 적용했다. x sign을 유지했고 mirror, label swap, 시각적 reposition은 없었다. 130개 원본 polygon surface를 하나의 5,876,784-byte 정적 GLB로 변환했으며 GLB SHA-256은 `7012f34696d1156a529d6dad3bad8313af674cc4e13630a9e2fd6a325ce932b7`이다. GLB는 ignored local cache `atlas-data/source-cache/bodyparts3d-r4/converted/t55/`에 두었다. 공식 archive·개별 OBJ 취득 hash와 재생성 도구는 manifest/evidence에서 확인할 수 있다. 이를 Git에 추가하지 않았다.

## identity, 좌우, 경계 및 기존 종아리 매핑

검증된 node 130개 중 T51 source-root context는 bone 58개와 muscle 70개다. 기존 T07에 이미 연결된 비복근 두 머리 FJ1394/FJ1397도 실제 mesh로 포함했지만 두 ID는 T51 bone/muscle roots 바깥 항목이라 새 root membership을 만들지 않았다. 이 기존 crosswalk는 `HA-P-000001`/`HA-P-000002`, `provisional_head_name_match_no_independent_anatomy_review` 상태로 유지한다. source label은 left 64/right 66, 빈 mesh 0, 정확 중복 geometry 그룹 0, wholly opposite label 0, central-plane crossing 관측 0이다. 이 수치는 BodyParts3D R4 source label/표면 진단이며 독립된 해부학 판정이나 사람 검토가 아니다.

T53 pelvis/hip에서 양측 femur, 양측 tibia, 양측 talus까지 여섯 same-laterality AABB 경계쌍을 확인했다. 모두 같은 source frame/pose에 있고 AABB는 겹친다. AABB 겹침은 surface 접촉 증명이 아니다. 별도 QA preview의 실제 전체 mesh scene에서 정면·후면·측면을 확인해 pelvis–thigh, knee/leg, leg–foot 연결의 눈에 띄는 frame offset이 없음을 확인했다. geometry는 자동 보정하지 않았다.

기존 T07 오른쪽 하퇴 조각과 겹치는 11개 FJ ID 모두 원본 file hash, vertex/triangle count, converted geometry hash와 topology hash가 일치했다. FJ1439 오른쪽 앞정강근은 기존 stable source node `HA-MESH-BP3D4-FJ1439`, 기존 learner ID `HA-M-000003`, 2,204 vertices/2,510 triangles, T07 topology SHA-256 `17aa54b23b003e253001abc360b19ad35d0ca004a1716e120be0e339895da1eb`를 보존했다. 신규 canonical binding 0, 사람 검토 승격 0이다. 모바일 preview에서 키보드 Tab→Return으로 FJ1439를 선택하고 카드, 황색 surface 강조 및 기존 ID가 일치하는지 확인했다.

원본 OBJ `Bounds(mm)` header와 실제 vertex bounds는 130개 중 95개만 일치했다. 나머지 35개에서 최댓값 차이는 0.3968 mm다. 원본 header와 실제 좌표를 모두 기록했고, render/GLB geometry는 실제 vertex에서 왔다. header를 실제 surface나 ID를 바꾸는 근거로 쓰지 않았다.

## 미완·제약

공식 현재 README의 CC BY 4.0 안내와 취득 OBJ header의 CC BY-SA 2.1 Japan 문구 사이 파일별 적용 범위를 정리하지 못했다. 따라서 OBJ/파생 GLB는 local technical QA만 허용하고 공개·배포·재배포는 보류한다. archive의 99%-reduced representation 한 종류만 있고 별도 LOD는 0이다. 제품 learner scene이나 animation/motion asset은 아니다.
