## 공식 원본·선택 취득

사용한 원본은 [BodyParts3D 공식 다운로드 목록](https://dbarchive.biosciencedbc.jp/en/bodyparts3d/download.html)의 Release 4.0, 99%-reduced IS-A OBJ archive다. 파일명은 `isa_BP3D_4.0_obj_99.zip`, URL은 `https://dbarchive.biosciencedbc.jp/data/bodyparts3d/LATEST/isa_BP3D_4.0_obj_99.zip`이다. 공식 README의 update history는 3D Release 4.0을 2013-06-19에 갱신했다고 기록하고, 현재 README/license 페이지는 2025-02-27 갱신본이다. [README](https://dbarchive.biosciencedbc.jp/data/bodyparts3d/LATEST/README_e.html)는 atomic ELEMENT만 polygon mesh로 제공되고 compound 개념은 constituent ELEMENT로 표현된다고 설명한다.

## 파생 package 및 통합 계약

기존 T50 transform `[x,y,z] source mm → [x,z,-y] HUMAN ATLAS m`을 적용했다. 각 exact OBJ `Bounds(mm)` header가 mm 단위를 제공하고, 원본 archive metadata는 별도의 전역 unit을 명시하지 않는 점을 기록했다. mirror·recenter·수동 정렬은 하지 않았다. pose는 `bodyparts3d-r4-static-reference`이며 standardized articulated pose라는 주장은 없다. Bounds와 vertex extrema 차이는 보존했지만 surface-contact 증명으로 사용하지 않았다.

## 미완과 상태 경계

- 공식 [현재 license 안내](https://dbarchive.biosciencedbc.jp/en/bodyparts3d/lic.html)는 2025-02-27 갱신된 CC BY 4.0을 표기하지만, 실제 원본 OBJ header는 legacy CC BY-SA 2.1 Japan 문구를 포함한다. 해당 파일의 배포 조건을 이 task에서 해석·승격하지 않았다. 파일별 권리 적용 확인 전 `file-level redistribution hold`와 `publicRelease=false`를 유지한다.
- `source-only`; canonical learner binding 0; default visibility 및 learner policy 변경 0; 독립 사람 해부학 검토 false. 이름·source crosswalk를 learner UI로 노출하거나 claim/animation을 만들지 않았다.
- 99%-reduced surface의 품질, region membership의 사람 검토 및 표면 접촉 검토는 미완이다. 동일-source geometry의 화면상 연결은 사람 승인이나 독립 근거가 아니다.
- 전신 canonical 분모는 미동결/null이며 T92 task 완료는 전신 coverage 완료를 뜻하지 않는다.
- `OpenSim_Models`, 기존 사용자 변경, T13 draft와 역사 T50–T76 자료는 보존했다. source cache raw OBJ와 derived GLB는 local ignored cache에만 남겼고 commit에서 제외했다.
