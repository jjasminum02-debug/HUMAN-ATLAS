## 구현

- 새 T77 byte-preserving repack: T70+T71+T72의 513개와 T74 두개골 9개, T75 삼각근 부분 6개, T76 골반바닥 9개, T92 승모근 부분 6개를 합쳐 **543개 unique source nodes**, 30 regional/layer chunks, 68,126,860 bytes. 공유 source ID는 한 node이며 geometry vertex/normal/index bytes는 원본 파생 GLB와 동일하다.
- **531개 기본 표시 / 12개 integrity-held 숨김 / 기존 선택 binding 10개**. 기존 481개 기본 표시를 보존하고 기존 opt-in 20개 및 새 30개에 정확한 source row/hash/frame/기술 검증을 연결한 per-ID local display 결정을 남겼다. 기존 source-only의 identity·surface 기술 검증과 local context 표시만 허용한다. 공개 재배포와 anatomy human review 승인을 의미하지 않는다.
- v2 runtime contract는 localDisplay, binding, public rights, review를 독립 검증한다. 기존 holdReasons 원문, stable IDs, source hash, runtime side, bounds, memberships는 유지된다. 원본에서 읽은 명시적 side 정보는 내부 결정에 별도 보존하며, 기존 runtime null side를 조용히 승격하지 않았다. 실제 integrity/좌우/identity 보류 12개는 계속 비표시·선택 금지다.
- 요추 L1–L5 `FJ3157/FJ3159/FJ3162/FJ3165/FJ3168`와 엉치뼈 `FJ3393`이 기본 장면에 표시된다. learner의 **보완 모형 보기** checkbox와 관련 내부 설명을 제거했다. 취득 package 구분은 내부 provenance에만 남긴다.
- T56의 AnatomySceneController/root/renderer/camera를 그대로 사용한다. 사용자 뼈/근육 layer-off 상태, 선택 강조, 선택만 보기, 선택 맞춤, 12부위 탐색과 미니멀 로딩을 유지한다. HA 로고·인체 로딩 그림·슬로건을 추가하지 않았다.
- `prepare:whole-body`는 새 파생 cache만 생성하며 기존 준비 스크립트와 산출물은 수정하지 않는다. Vite는 localhost 개발 경로에서만 T77 cache를 제공한다. production build에 held GLB/OBJ를 내보내지 않는다.

## 남은 구조·내용 범위

`work/evidence/T77/current-inventory.json`은 실제 543개 source 항목의 geometry/표시/binding/rights/review를 기록하고 공식 캐시와 38개 주요 근육명 query를 대조한다. substring 일치는 후보 탐색이며 비근육 구조도 포함될 수 있다. 검색 0건을 해부학적 부재로 해석하지 않는다. 가림(카메라/깊이에 종속)·사용자 layer-off는 geometry missing과 구분하며 모든 표면의 occlusion을 개별 측정했다는 주장은 하지 않는다.

- 이두근·삼두근: 공식 metadata의 `FJ1512/FJ1512M/FJ1478/FJ1478M/FJ1479/FJ1479M/FJ1480/FJ1480M/FJ1477/FJ1477M` 10개가 새 runtime에도 없다. 현재 화면에서 못 찾은 이유는 해당 표면 미통합이며 사용자 조작 문제가 아니다. 취득·surface identity까지 검증된 것으로 부르지 않는다. T78–79 및 추가 batch queue 대상이다.
- 삼각근·승모근: 실제 표면은 통합했지만 source-only. 이번 task에서 이름 카드/기시정지/기능/animation 연결을 새로 만들지 않았다. 기존 종아리 6개 근육과 일부 뼈 선택만 유지한다.
- 광배근: **missing**, geometry/binding=null. T94의 공식 metadata/aggregate 후보는 exact object/ancestry/side/part/unit/frame/pose/개별 권리 근거가 아니다. 대체 mesh·ID·binding·anatomy claim을 만들지 않았다.
- 사용자가 이번 대화에서 광배근도 구현해 달라고 추가 요청했다. 최종 구현 대상으로 유지한다. T78에서 metadata 검색 반복을 넘어 실제 source object 검사, 필요 시 별도 model registration, 이후 동일 장면 통합을 bounded task로 배정하도록 구체적 인계를 남겼다. 지금 취득·통합을 완료했다는 뜻은 아니다.
- 전신 목표 분모, 모든 근육 binding/내용/동작, license reconciliation, human review는 미완이다. T72 당시 bone-root gap 26은 역사 수치로만 보존한다. T74 이후 현재 전체 뼈 gap이라고 재해석하지 않는다.
