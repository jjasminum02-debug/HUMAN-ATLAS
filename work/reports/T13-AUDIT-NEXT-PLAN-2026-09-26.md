# T13 감사 후 권장 실행 순서 — 제안, 미실행

2026-09-26. 기존 T14–T24 큰 번호는 유지한다. 현재 STATUS를 자동으로 완료 승격하지 않는다. 아래 suffix는 새로 제안한 작업이며 시작할 때 work/tasks에 명세를 만들고 STATUS의 다음 실행을 맞춘다. 시작 안내의 고정된 T11 프롬프트도 정리한다. 이번 감사에서 이 계획을 실행하지 않았다.

## T13a — 학습 화면 회귀 수정 (권장 다음 작업)

목표: 사용자가 원하는 큰 모형과 간결한 한국어 카드 복원.
입력: T13 감사, App.tsx, GLBViewer.tsx, ThreeViewer.ts, 현재6근육/20mesh.
수정: atlas-web UI/카메라/상태 처리 및 회귀검사, work 인계문서. 실제 해부학 좌표·기존 자산은 변경하지 않는다.
산출물: 관심근육+인접구조 기본 프레임; 전체 보기 별도; 한국어 기시·정지 요약 우선; 상세 영문 접기; 부착 선택 해제/초기화의 일관성.
합격: 1440×900에서 기시/정지 두 요약을 스크롤 없이 읽고 근육이 중앙 주대상으로 보임. 선택 부위가 보이는 canvas 높이의 대략60–85%를 쓰도록 시각 확인하되 좁은 구조를 인위적으로 늘리지 않음. 1280/390에서 카드/모형/버튼 겹침 없음. 선택/보기초기화/근육변경/뒤로가기 상태 일치. T번호/JSON/긴 원문 기본 노출 없음. type/build 및 영향받는 검색/annotation 검사.
중단: 잘못된 해부학 내용이나 임의좌표로 시각 요구를 채우지 않는다.
다음: T13b.

## T13b — 실제 표면 후보의 저장·검증·학습 표시 연결

목표: /review 초안을 실제 파일의 draft 공간자료로 검증하여 읽기 전용 학습 overlay까지 전달한다.
입력: T09 초안 계약, T12 instance, T13 context, T03 SpatialAnnotation 계약.
수정: 별도 draft 공간자료 계약/변환기, source/instance/mesh 참조, renderer overlay, 검증기, work. 원 context-only manifest는 마이그레이션 근거로 유지.
산출물: pending/context_only/draft_surface/reviewed/stale 등의 명시적 상태 및 타입; 파일 import와 topology/좌우/pose/claim hash 검사; 기시/정지 구별되는 패치·경계 렌더러. canonical 계약이 사람승인을 요구하면 별도 draft layer를 만들고 승인 경계를 유지한다.
합격: 합성 테스트 fixture의 점/선/면은 테스트 화면에만 표시. 생산 학습 데이터로 섞이지 않음. valid draft의 저장→재시작→읽기 표시, invalid source/instance/side/hash 거부, topology 변경 stale, 미검토 표시가 확인됨. 표면0/41 강제는 versioned context snapshot 검사로 한정. 기존 사용자 localStorage 초안을 보존하며 자동 승인 없음.
중단: 테스트 도형을 실제 부착면 후보로 채택하지 않는다. 다음T13c에서 실제 근거 기반 입력.
다음: T13c-B01.

## T13c-Bxx — 실제 부착 영역 소량 입력

목표: 41개 전체를 한 번에 요구하지 않고 1–2개 근육/검토 가능한 소수 부착부터 완성 경로를 만든다.
입력: 현재 원문, 해당 부착의 현대 독립 근거, 다각도 장면. T14 예정 원문 대조 중 실제 후보 입력에 필요한 부분은 여기서 먼저 수행.
수정: 해당 batch의 근거·후보 geometry·검토 패킷. 학습 표시 read-only, 입력 /review.
산출물: 근육/근두/역할/뼈·비골성 구조/좌우/좌표계/pose/범위/근거/revision가 연결된 candidate와 미확인 이유.
합격: 뼈 전체를 영역으로 제출하지 않음. 넓은 부착은 패치/경계. 판독 근거 없으면 보류. missing13개는 뼈없음/복합대상/연부조직별로 분류하여 자산추가·복합대상분해·text_only 중 이유를 정함. 근거로 정체가 확인된 뼈는 프로젝트 내부 stableID를 신규 등록할 수 있음(외부표준ID를 날조하지 않음).
중단: 독립 사람 검토가 없으면 draft 유지. 사람 검토 대기는 필요한 범위의 release gate를 막되 독립적인 자료 조사 전체를 막지 않음.
다음: 잔여batch 또는T14a.

## T14a / T14b — 통합검증과 사람검토 결과 분리

T14a: 파일럿6개 언어 공백 처리, 현대 근거 대조, 이름→3D→기시/정지→출처 경로 실제검증. 본문의 한국어 간결성/카메라 크기/정지까지 보이는 첫 화면을 회귀 기준에 포함한다. 실제후보 coverage, text_only, missing, human_review_pending을 각각 보고한다.
T14b: 실제 사람 검토 의견 반영 및 검토된 범위만 릴리스. AI가 스스로 human review를 채우지 않는다. 미확보 surface가 있으면 파일럿 부분완성이라고 기록한다.
T15 목록 조사는 독립 진행 가능하나, 미완 파일럿을 검증된 전신 확장 템플릿으로 보지 않는다.

## T15–T24 유지 및 보강

- T15 유지: 전신 목록 동결. 용어별 명칭/한자/영어/부분 구분의 실질coverage. 조사한 항목수=완성항목수로 세지 않음.
- T16 유지: 배치 구조 확장. 시작 전 task숫자/개수 고정값 제거, manifest 기반 부위 로딩, 여러asset 장애 분리, runtime 이중decode 비용 측정. 각 부위 최초 배치마다 실제 시각검증.
- T17 유지: 전신 구조 gate. 전신 이름·텍스트·모형·부착면·사람검토의 분모/분자를 별도로 공개.
- T18–T20 유지: 기능 계약·파일럿·확장. 원본 근육 메시의 존재가 애니메이션/rig/기능 정확성을 보장하지 않음.
- T21–T23 유지: 평가 계약·파일럿·학습. 검사 절차/관찰/한계 분리, 자동진단/치료 없음.
- T24 유지: 로컬 전달. 모바일/키보드/production-route/성능·라이선스 및 미완표 확인. 최종 단계까지 시각검증을 미루지 않는다.
