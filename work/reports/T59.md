사용자 요청대로 **움직임으로 이해하기** 버튼 하나로 조작한다. 느리게 보기·멈춤·처음 자세 버튼을 제거했다. 첫 클릭은 lazy load 후 반복 왕복 재생, 다시 클릭하면 반복을 중단하고 0.7초 smoothstep으로 처음 자세에 돌아가 원본 자원으로 복원한다. 카메라와 layer/hidden 상태는 유지된다. 교육용 회전 진폭은 5°에서 **6.5°(+30%)**로 키웠다. 진행 막대는 키보드로 자세를 살펴볼 수 있고, 움직임 줄이기 설정에서는 자동 재생하지 않는다. 명시적으로 연결한 motion은 기존 작용 카드를 재사용하며 새 자산 때문에 카드/키가 중복되거나 이동하지 않는다. 실제 지원 작용을 기본 선택하되 반대쪽에는 미지원 안내가 나온다.

## 원본과 작성된 가정

`author_source_surface_motion.py`는 실제 source POSITION/NORMAL/index·instance matrix·side·frame·resource/chunk hash를 읽고, 명시한 정점 영역과 관절 가정으로 POSITION/NORMAL morph 및 동반 뼈 TRS track을 생성한다. 기존 `derive_source_surface_motion.py` exporter의 보조 함수를 재사용한다. 입력의 정점 mask·회전축·clip timing·접촉/표면 보정은 **authored engineering choice**다. source-provided neutral/bind pose, 정확한 해부 부착 footprint/instantaneous axis, 실측 생리 수축량·임상 운동 범위를 확인한 것으로 쓰지 않았다. pivot은 눈으로 확인한 실제 목말뼈 표면 정점 호의 재현 가능한 fit이며 해부학적 회전축 확정이 아니다.

패키지는 58개 실제 원본 구성원이다. 선택 근육은 비-scale morph, 정강뼈/종아리뼈는 고정, 발의 뼈와 내부 근육은 함께 움직이고, 필요한 종아리 주변 근육은 별도 passive morph로 처리했다. 고정 1,253개·이동 40개의 선택 근육 작성 영역을 명시했다. 네 개 morph 표본과 normals를 만들어 중간 자세의 선형 chord 오차를 줄였다. 고정/이동 mask 오차는 0이며 원본/cache geometry는 변경하지 않았다. 원본의 퇴화 삼각형과 기존 겹침을 별도로 기록하고 삭제하지 않았다. 머리 방향 양수인 프레임에서 앞쪽 발의 실제 중심이 올라가는 등쪽굽힘 방향 검사도 통과했다.

초기 확대 후보의 접힘·뼈/주변 근육의 새 정점 관통과 최종 좌표 대조에서 확인된 회전 방향 오류를 수정했다. 비교 진단은 선택 근육→57개 context의 171건, passive 근육→뼈의 783건, 목말뼈→고정 뼈의 6건, 총 **960건**이다. 처음/중간/끝 자세의 새 정점 containment는 모두 0, 작성 표면의 뒤집힘은 0이다. source baseline의 겹침은 유지한다. 이는 전 삼각형 교차/연속 시간 충돌이나 생체역학 승인 검사가 아니다. 거친 단일 hinge와 최소 접촉 clearance도 작성된 가정이며 record에 수치를 남겼다. 작은 taper 삼각형의 최대 상대 edge 변화도 기록했지만 생리학적 strain으로 해석하지 않는다.

최종 asset: `atlas-data/assets/motion/t59-za-right-ankle/motion.glb`, **1,092,164 bytes**, SHA-256 `671289393379dd31e5514c2ff39b6f1b163e057b76b63236a5b0f88f70a392c0`. 정적 reference subset은 binding 검증 자료이며 별도 viewer가 아니다. local dataset 혼합 여부와 무관하게 ZA component revision/frame/hash에 정확히 묶는다. 같은 resource인 overview/detail을 label 차이로 오인해 실패하던 경우를 수정했고, 등록된 GLB를 HTML fallback 대신 hash 검증된 binary로 dev/build 양쪽에서 lazy 제공한다.
