# T63 — 같은 장면의 신경 주행·지배근 선택

T63은 **completed / passed**, `nextUnit=null`이다. `contractRevision=app-completion-2026-10-01`, `productReadiness=local_app_ready`, `contentCompleteness=partial`, `unresolvedProductBlockers=[]`로 기록했다. 합격 범위는 기존 단일 장면에서 사용하는 좌우 Common / Deep / Superficial fibular nerve **6개 원본 정적 주행**과 typed 선택·카드·분지 탐색·확인된 지배근 강조·복원이다. 전체 신경 완성이나 공개 배포 승인이 아니다.

## 구현 결과

- T62가 확인한 identity·side·branch·지배 관계를 유지하고 새 T63 overlay에 형상 근거를 연결했다. T62 원장과 당시 3D 미등록 기록은 수정하지 않았다.
- 기존 Blender 실행 파일의 해시는 역사 기록과 같고, 제한된 sandbox 밖에서 수행한 읽기 전용 `codesign --verify --deep --strict`는 성공했다. T62의 sandbox 서명 실패를 원본 손상으로 확정하지 않았다. 기존 고정 DMG와 실행 파일·원본 blend 해시도 재확인했다.
- `--background --factory-startup --disable-autoexec`, `load_ui=False/use_scripts=False`로 원본 frame 0의 Curve를 평가했다. 원본 두께·분지·정점·법선을 보존하고 reflection의 winding을 교정했다. 이름이나 끝점으로 Tube/주행을 생성하지 않았고 원본을 저장하지 않았다. 원본의 비신경 oesophagus dependency-cycle 안내와 종료 시 작은 메모리 안내는 유지됐으며, 6개 신경에는 modifier·constraint·animation data가 없고 산출물의 모든 정점/법선·인덱스와 해시가 통과했다.
- 평가된 native source-world 좌표를 공통 indexed GLB compiler로 묶었다. 신경 추가분은 **348,184 bytes / 19,008 triangles / 선언 geometry 343,872 bytes**다. 기존 8 MiB chunk·20 MiB overview·1M triangle·96 MiB cache 예산을 높이지 않았다.
- 기존 `DatasetSceneAdapter → DatasetResources → ResourceQueue → AnatomySceneController`를 사용한다. renderer·scene·camera·LRU·취소 경로를 추가로 만들지 않았다. 원본 object transform은 파생 좌표에 한 번 적용했고 instance에는 기존 ZA 축 변환만 적용한다. domain registry의 `source_world`와 기술 dataset의 namespace 좌표인 `source_local`을 구분했으며 BP3D와의 공간 정합을 주장하지 않는다.
- 신경 레이어는 기본 꺼짐이다. 검색·실제 표면 클릭·키보드로 typed 신경 카드를 연다. 좌우 Common의 Deep/Superficial 하위 링크 **4개**를 제공한다. Sciatic 조상 2개는 미지원으로 유지하여 selectable route를 만들지 않았다. 원장 branch 관계 6개는 그대로 남는다.
- Deep fibular의 확인된 좌우 tibialis anterior 운동 지배 관계 **2개**만 강조한다. 선택 해제·레이어 끄기·숨김·지역 제외·지원되지 않은 pose에서는 강조를 해제한다. 강조를 위해 숨긴 근육을 다시 만들거나 근육 레이어를 켜지 않는다. 감각영역·피부분절·고유감각·경락 관계를 운동 지배로 혼합하지 않았다.
- 1024px에서 늘어난 옵션 줄이 canvas와 겹치는 실제 결함을 수정했다. 레이어 5개 제어는 한 줄에 놓고 신경의 지배근 강조는 기존 강조 버튼 자리를 사용한다. 카드·옵션·canvas 공간이 1440/1024/390에서 분리된다.

## 실제 검증

관련 계약·정책·scene·delivery 회귀 **86/86** 통과. 최종 asset/reference hash 강화와 metadata 집계 이후 신경 형상·표시 정책·delivery **7/7**을 다시 확인했고 typecheck·production build도 통과했다. build의 기존 >500 kB JavaScript chunk 안내는 비차단이며 임계값을 변경하지 않았다.

PNG **10장**을 hash 검증했고 Common/Deep/Superficial의 주변 뼈 문맥, 좌우 전경골근 강조, 전신, 1024/390 레이아웃을 실제로 읽어 확인했다. 원본 주행의 source-specific 로컬 위치 확인이며 개인별 주행·full extent의 사람 승인으로 세지 않는다. 깊은 주행 일부는 근육에 가려지며 근육 레이어를 꺼 접근한다. 390px desktop Chrome은 모바일 실기기 검증이 아니다. GPU 시간·VRAM·total-process memory는 관측하지 않았다.

동일한 기존 960 ZA 행의 이름·side·region·bounds·eligible·HA 연결을 전수 대조했다. 뼈/근육의 geometry와 shader 색은 유지하여 기존 T58 시각 근거를 재사용했고, 변경된 옵션 배치와 새 신경 유형은 새 캡처로 검증했다. 최종 runtime은 **979 records**, 일반 learner eligible **678**(기존 672 + 신경 6), 별도 inspection eligible **13**, HA 연결 **130**이다. `work/product-scope.json`의 G1/T58 target/member 집계는 보존하고 신경 지원을 별도 `featureExtensions.nerveScene`으로 추가했다.
