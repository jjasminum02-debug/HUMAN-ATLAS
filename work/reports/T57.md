# T57 — 앱 시작·전신 홈·레이어 조작

2026-09-27 · Astra · 현재 대화 직접 구현 · **passed (로컬 UI 범위)**

T56의 실제 정적 모형을 단일 AnatomySceneRoot/renderer로 유지하면서 시작 화면과 전신 홈을 구현했다. T57 필수 UI 검증을 통과했다. 이 판정은 전신 해부학 coverage, canonical binding, 공개 배포, 운동 또는 T58 그래픽 품질 합격을 의미하지 않는다.

## 구현

- 새 방문 `/`은 부위/선택이 없는 전신 홈이다. 특정 종아리 근육을 자동 선택하지 않는다. 부위를 고르면 해당 부위만 탐색하며 구조 선택은 별도 사용자 동작이다.
- 초기 JS/catalog/manifest/실제 GLB 로딩을 같은 HUMAN ATLAS 시작 화면으로 연결했다. 실제 취득 수와 렌더 결과를 사용하며 최소 대기시간·가짜 진행률은 없다. 초기 실패와 재시도, 부분 실패의 비차단 안내를 제공한다. manifest 연결은 20초 후 실패 안내로 전환한다.
- 사용자 후속 요청을 최종 반영했다. 로딩의 HA 로고와 인체 그래픽, 로딩/본 화면 헤더의 “구조를 보고, 움직임을 이해하다”를 모두 제거했다. 최종 로딩은 HUMAN ATLAS와 로딩 상태만 표시한다.
- 넓은 모형 화면 위에 12부위 탐색과 선택 시의 설명 카드를 배치했다. 검색 중에는 부위 목록보다 결과를 먼저 표시한다. 모바일은 탐색을 여닫고 설명 카드를 하단에서 접는다. 패널 개폐는 canvas를 교체하거나 camera를 변경하지 않는다.
- 상단 뼈/근육, 전체 보기/화면 맞춤, 선택 강조, 기존 보완 모형 옵션을 유지한다. 둘 다 끄면 복구 안내를 표시한다. 신경/경혈 실행 버튼은 추가하지 않았다.
- 기본 three-name 카드와 기시·정지/기능을 재사용한다. 기시·정지에는 출처/작업 번호가 없다. 근육 이름 아래 “움직임으로 이해하기”를 배치하되 실제 같은 모형 운동이 없으므로 비활성 상태를 유지한다. 구조 클릭은 운동을 시작하지 않는다.
- 전신 상태에서 구조를 클릭해도 전신과 카메라를 유지한다. `view=whole`은 선택의 region과 독립적인 보기 상태를 URL에 보존한다. 새로고침과 history로 전신/부위·선택을 복원한다. 브랜드 홈 버튼은 SPA 이동이며 renderer를 재생성하지 않는다.
- 초기 camera fit 전에 실제 host 크기를 측정한다. keyboard 회전/확대, 탭의 방향키/Home/End, 모바일 카드 Enter와 선택 후 focus를 지원한다. 로딩 뒤쪽 조작은 inert 처리했다.
