# T09 — 부착부 annotation 검토 도구

## 결과

T07 로컬 뷰어에 점, polyline, surface patch를 작성·편집·삭제하는 draft 전용 검토 도구를 연결했다. 도형은 T07 asset frame의 meter 좌표와 surface topology 기준으로 저장하고, 카메라 회전·확대 시 현재 카메라에 다시 투영한다. 저장 위치는 browser localStorage이며 JSON 교환 파일을 만들거나 읽을 수 있다.

T03 canonical `SpatialAnnotation`을 변경하지 않았다. 전용 교환 스키마 `HA-annotation-draft-exchange-v1`은 `instanceId: null`과 `reviewState: draft|stale`만 허용하므로 canonical annotation이나 검토 완료로 표현되지 않는다. UI와 importer는 T05 attachment, 설명 claim/evidence, owner와 T07 mesh target, 좌우, revision/hash, frame/units/pose, surface triangle range를 확인한다. revision/hash 불일치는 거부하고 기존 저장 데이터가 topology 변경을 가리키면 stale로 격리해 렌더를 막는다. T05 source claim들은 계속 `needs_review`다.

## 증거 제한과 미확인 범위

브라우저 화면은 CUA에서 시각적으로 캡처해 확인했지만 이미지 파일은 프로젝트에 저장하지 못했다. 캡처 bytes를 저장하기 위한 browser navigation이 Codex URL policy에 의해 거부됐으며 그 경로를 우회하지 않았다. 상호작용 로그와 console 결과는 JSON으로 저장했다.

도형 작성 경로를 확인한 것이 실제 부착면 위치 검토나 T05 claim의 해부학적 정확성을 뜻하지 않는다. 임시 browser draft 외 실제 annotation candidate는 만들지 않았으며 anatomical instance는 여전히 0개다. 사람 검토, public release, 진단·치료·침 시뮬레이션은 범위에 포함하지 않았다.
