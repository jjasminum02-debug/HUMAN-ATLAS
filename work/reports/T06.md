# T06 결과 — 로컬 텍스트 탐색 앱

## 수행 결과

T06을 완료했다. React/TypeScript/Vite 로컬 앱과 Vite 카탈로그 로더를 `atlas-web/`에 만들었다. 로더는 `catalog-status.json`의 pilot ID를 선택 기준으로 삼고, canonical catalog에서 개념·용어·근육 부분·구조·부착·claim·근거·출처를 연결한다. 이름, 부착 서술, 출처 locator는 앱 코드에 작성하지 않았다.

목록 검색, 근육/근육 부분 상세, 용어별 출처, 기시·정지 카드, `needs_review`/결측/부분 catalog 상태, URL의 `?muscle=<stable-id>` 선택 복원, 잘못된 ID 안내를 구현했다. 카탈로그 파일을 읽지 못하거나 데이터 구조가 잘못되면 오류 안내 화면을 보인다. 앱은 3D 자산 없이 텍스트로 동작하며 로컬 학습용이다.

## 주요 파일

- `atlas-web/src/ui/App.tsx` — 접근 가능한 검색·목록·상세 화면과 URL 선택 상태
- `atlas-web/src/data/catalog.ts`, `atlas-web/vite.config.ts` — 실제 canonical catalog/status에서 만드는 파일럿 데이터 projection과 오류 처리
- `atlas-web/src/ui/styles.css` — 기본/좁은 화면 layout 및 키보드 focus 표시
- `atlas-web/package.json`, `atlas-web/pnpm-lock.yaml`, `atlas-web/pnpm-workspace.yaml` — 고정 dependency 및 package 설정
- `atlas-web/README.md` — 설치·실행·빌드 명령과 현재 workspace runtime 안내
