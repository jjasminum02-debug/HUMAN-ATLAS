## 수행 범위와 결과

현재 선택 가능한 양측 종아리신경의 세 개념(공통·심부·얕은종아리신경)에 주행/변이, 기능 변화, 해부학적 압박 맥락을 한국어 설명으로 연결했다. 신경 카드는 기존 단일 장면에서 접힌 **「기능 변화와 포착 맥락」** disclosure를 제공한다. 분지 전환 뒤 자동으로 접히며 키보드 Enter로 열고 닫힌다. 화면 문구는 교육용 기능·주변조직 설명에 한정하고 개인 증상 진단이나 처치를 권하지 않는다.

T90 후속 범위로 양측 9개 source 근육 개념, 총 18개 source surface의 기시·정지 요약을 추가했다: 삼각근 빗장/봉우리/어깨뼈가시 부분, 승모근 하행/횡행/상행 부분, 작은·큰마름근, 넓은등근. 기시/정지 문장에는 명시된 기존 전체 뼈 문맥만 같은 쪽으로 연결했다. 표면 부착점, 좌표, 새 geometry, 새 canonical ID/binding은 만들지 않았다. 널힘줄로 표현되는 하부 승모근의 정지는 어깨뼈에 직접 붙는 것으로 확정하지 않고 뼈 link를 두지 않았다.

상부/하부 승모근 구분을 실제 카드와 원문 locator로 확인했다. 상부(`Descending part`)는 뒤통수·목덜미·C7에서 시작해 빗장뼈에 닿고, 하부(`Ascending part`)는 T4–T12에서 시작해 어깨뼈 부근 aponeurosis로 모인다. 따라서 목 부위가 상부, 아래쪽 흉추가 하부라는 표시가 유지된다. 삼각근은 세 source 부분을 각각 요약했으며 전체 근육 claim을 각 부분에 복사하지 않았다.

## 원문 근거와 한계

직접 연 원문, 판본/갱신정보, 항목 locator, field/value hash와 접근방법은 `work/evidence/T65/source-review.json` 및 `source-review-notes.md`에 있다. 종아리신경 주행·분지 변이는 [2019년 해부학 연구](https://pmc.ncbi.nlm.nih.gov/articles/PMC6960080/)와 대조했고, 앞가쪽 종아리 근막/널힘줄 변이는 [2025년 해부학 연구](https://pmc.ncbi.nlm.nih.gov/articles/PMC12519015/)에서 확인했다. 각 신경의 일반 기능 구분은 [2026년 해부학·기능 종설](https://pmc.ncbi.nlm.nih.gov/articles/PMC13591402/)의 해당 절을 사용했다. 삼각근/승모근은 [상지 외전근 해부](https://www.ncbi.nlm.nih.gov/books/NBK537148/), 넓은등근·마름근은 [등 바깥근 해부](https://www.ncbi.nlm.nih.gov/books/NBK537216/)와 [마름근 해부](https://www.ncbi.nlm.nih.gov/books/NBK534856/)의 구조/기능 절을 필드별로 대조했다.

웹 리더에서 전체 본문을 열어 확인했지만 원문 HTML bytes는 내려받아 보관하지 않았다. 그러므로 원문 byte SHA-256은 null이며, 자료에 기록한 해시는 읽기 검토 노트의 SHA-256이지 웹 원문 파일의 해시가 아니다. 요약은 직접 인용이 아닌 한국어 요약이다. 상완이두근 갈래는 검색 결과 후보만 있고 직접 연 원문에서 정확한 부분별 locator를 확보하지 못해 이번 반영에서 제외했다.
