# T13c-B02 결과 — 우측 전경골근의 경골 외측과 기시

작성/검증일: 2026-09-26
상태: `complete_with_geometry_held` — 분리 context record 1건, surface geometry 0건, 사람 검토/승격 0건.

## 범위와 판정

이번 작업은 `HA-A-T05-TA-TIBIA-CONDYLE-ORIGIN` 한 건만 다뤘다. 대상 claim은 `HA-C-T05-TA-TIBIA-CONDYLE-ORIGIN`, 기존 역사적 근거는 `EV-GRAY1918-TIBIALIS-ANTERIOR`다. Gray 원문과 독립된 현대 해부학 자료는 경골 외측과의 넓은 기시 위치를 지지한다. 다만 현대 연구의 측정 결과와 현재 FJ3387 mesh 사이에 재현 가능한 footprint 경계나 mesh landmark 대응이 없다. 따라서 뼈 전체를 부착 영역으로 제출하거나 화면 모양에서 좌표를 추정하지 않고 `context_only`, `geometry:null`, `reviewId:null`로 보류했다.

## 원문 및 독립 현대 근거

- 역사적 claim은 Gray, *Anatomy of the Human Body*, 20th US edition (1918), section 8c, subsection “The Tibialis anterior (Tibialis anticus)”, printed p. 480이다. 프로젝트 출처 등록부가 판본의 편집자·출판사 정보를 기록한다. 해당 Bartleby chapter를 in-app browser에서 직접 열어 원문을 확인했다. [원문 장](https://www.bartleby.com/lit-hub/anatomy-of-the-human-body/8c-the-muscles-and-fasci-of-the-leg/)
- 독립 현대 근거는 Kimata K, Otsuka S, Yokota H, Shan X, Hatayama N, Naito M. “Relationship between attachment site of tibialis anterior muscle and shape of tibia: anatomical study of cadavers.” *Journal of Foot and Ankle Research*. 2022;15:54. DOI `10.1186/s13047-022-00559-y`; version of record 2022-07-12. Springer Nature 출판사 full-text HTML의 Materials and Methods, Results, figures/captions, Discussion 및 limitations를 열어 확인했다. [출판사 원문](https://link.springer.com/article/10.1186/s13047-022-00559-y)
- Methods/Results는 20구의 일본인 사체에서 얻은 40개 하지 표본을 사용했고, 근섬유가 뼈 피질에 단단히 붙는 위치를 부착으로 정의했다고 설명한다. 저자들은 전경골근 앞쪽 섬유의 기시가 경골 외측과와 앞모서리에 걸친다고 보고한다. 반면 이 연구가 보고한 종축 방향 distal endpoint 비율은 경골 길이에 따른 종말점 측정이며 외측과 footprint의 면 경계나 FJ3387 triangle IDs를 제공하지 않는다. 대상 표본도 프로젝트 mesh와 동일 표본이 아니다.
- 원문/검색 색인/독립 근거/사람 검토를 구분한 판본·locator·조회일·접근 기록은 [source-evidence.json](../evidence/T13c-B02/source-evidence.json)에 남겼다. 검색은 자료 발견에만 사용했고, 지지 판단은 열린 출판사 원문을 기준으로 했다. 자격 있는 프로젝트 해부학자의 사람 검토는 수행되지 않았다.

## 실제 tibia mesh 검토

in-app browser의 실제 `/review?muscle=HA-M-000003`에서 대상 attachment의 “관련 뼈 보기 · 표면 미지정”을 선택해 우측 경골 FJ3387을 표시했다. 선택 mesh를 격리한 다음 정면·후면·우측 측면 preset과 수동 회전 시점을 확인하고, 카메라를 전체 보기로 초기화했다. 모델의 방향 표시는 `RH · m · +X 좌 / +Y 머리 / +Z 앞`이다.

mesh는 BodyParts3D Release 4.0 right tibia `HA-MESH-BP3D4-FJ3387`, revision `BP3D-R4-OBJ-TO-GLB-V1`이다. 실제 GLB SHA-256은 `044450c3230bd23869a099d545151cb3d7518da3240a6e59f911f82786edc341`, topology hash는 `1a44d95c1a84f014cce9452a7185814ec3c416efe3781e05bd223650c3c26f38`; frame/unit/pose는 `HUMAN_ATLAS_RH_M_XLEFT_YHEAD_ZANTERIOR` / `m` / `bodyparts3d-r4-static-reference`다. 화면에는 뼈의 무표식 표면만 있었고, 외측과 부착 경계를 재현할 표시·삼각형 ID·source landmark crosswalk는 없었다. 시점 변화는 표면 형상만 바꿔 보여 주므로 부착 위치의 근거로 사용하지 않았다. 상세 관찰은 [browser-mesh-review.json](../evidence/T13c-B02/browser-mesh-review.json)에 기록했다. viewport 화면 이미지는 실제로 확인했으나 browser surface에서 파일로 내보내는 기능은 없어 관찰 내용을 JSON으로 남겼다.

## 분리 spatial draft 및 learner 경로

[spatial-draft-layer.json](../evidence/T13c-B02/spatial-draft-layer.json)은 대상 한 건만 포함한다. canonical T03 `SpatialAnnotation`, canonical catalog/claim/evidence, T12 bridge, T13 context manifest는 건드리지 않았다. 기존 T13 context-only manifest는 migration 근거로 그대로 남겼고 현대 문헌은 B02 sidecar evidence로만 추가했다.

`/review`에서 JSON 가져오기·검증은 한 건을 받아들였고 화면에 `context_only · 관련 구조만 있음 geometry 없음`을 표시했다. 같은 브라우저 profile에서 페이지 새로고침 뒤에도 한 건을 다시 불러와 참조/hash 검증했다. 같은 세션의 T09 annotation JSON export는 `annotations: []`였다. 작업 전에도 공간자료 export 0건과 T09 export 0건이 확인됐다. 기존 B01 파일은 별도 프로젝트 evidence로 hash 대조했다.

일반 learner `/` route는 실제 브라우저에서 정상 렌더링됐다. 기존 전경골근 학습 화면 및 관련 뼈 표시를 확인했고, B02 record는 geometry가 없으므로 이 첨부에 대한 patch/점/선 강조는 나타나지 않았다. 일반 learner 화면에 B02 task ID나 내부 JSON을 노출하지 않았다. 이는 geometry-null 상태의 표면 비표시 확인이며 이 task에서 learner data-sync 기능을 새로 구현하거나 surface 표시 기능을 주장한 것이 아니다. 화면·reload·export 기록은 [browser-validation.json](../evidence/T13c-B02/browser-validation.json)에 남겼다. read-only browser inspection은 raw localStorage digest를 제공하지 않아 digest는 주장하지 않는다.

## 미완 항목

- 경골 외측과의 exact surface footprint/좌표/triangle 경계 및 사람 해부학 검토는 미완이다. 이 B02 draft는 검토 대상 연결만 제공한다.
- T13의 표면 geometry는 0/41, 사람 검토는 0/41이다. B01/B02의 두 evidence record는 각각 geometry-null hold이며 canonical annotation이 아니다.
- learner route는 현재 읽기 전용 화면으로 확인했다. 이 작업은 spatial draft를 일반 학습 화면에 동기화하는 기능을 만들거나 검증하지 않았다. 표시할 surface geometry가 없으므로 B02 patch는 없다.
- 브라우저 raw localStorage digest는 도구에서 읽을 수 없었다. 저장/새로고침/export 결과를 사용했으며 raw digest 검증으로 과장하지 않는다.
- T13c에는 검토 대기 건이 남아 있다. T14a/T14b는 미착수다.
