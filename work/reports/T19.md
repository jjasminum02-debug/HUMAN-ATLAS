## 구현

- `ThreeViewer`에서 mesh의 base visibility/color와 선택 focus를 분리했다. 기본 선택 근육은 유지하고 다른 근육은 alpha 0.28로 흐리게 하며, 관련 뼈는 흐림 대상에서 제외한다. “주변 근육 흐리게”는 기본 ON이고 끈 뒤 다른 근육을 골라도 OFF를 유지한다.
- 선택/초점 강조를 끄면 base 색으로 돌아간다. 숨김·투명 base state는 focus/isolation과 별도로 보존하며, 학습 “보기 초기화”는 isolation만 해제하고 사용자가 끈 뼈/가시성 상태를 그대로 둔다. authoring `/review`의 기존 pointer 정책과 “모두 복원”은 변경하지 않도록 transparent pick-through와 base-visibility 보존을 learner 경로에 한정했다.
- “이 근육만 보기”는 선택 근육과 기존 attachment context에서 mesh 참조가 확인된 필요한 뼈를 남긴다. 활성 isolation 중 다른 구조를 선택하면 선택 카드·URL과 isolation target이 함께 이동한다.
- 학습 pointer picking은 흐림/투명 mesh를 모두 숨김 처리하지 않는다. raycast 후보에서 숨김·격리 제외는 계속 차단하고, 먼저 투명면 뒤의 가장 가까운 불투명 구조를 고른다. 불투명 hit가 없으면 서로 다른 흐린 mesh를 통과해 가장 깊은 고유 mesh를 선택한다. authoring 경로는 기존처럼 투명 mesh를 직접 고르지 않는다.
- 좁은 화면에서 7개 보기 조작이 한 줄로 넘쳐 문서 폭이 450px가 되는 것을 발견했다. 760px 이하 툴바를 캔버스 안에서 여러 줄로 접어 390px 가로 넘침을 없앴다.
- `visibilityPolicy.ts`에 focus/pick 순수 정책을 두고 투명 뒤 불투명 선택, 전체 흐림 상태의 깊은 후보 선택, 숨김 제외, 뼈 보존 및 학습/author 복원 정책 테스트 5개를 추가했다.
