새 파생 GLB는 10개 node, 812,256 bytes, SHA-256 `64c42361163c9e1f50f0a0b700436526f4253f2c84a8407e1cd2478448656759`이다. source manifest와 integration extension은 `atlas-data/manifests/bodyparts3d-r4-t102/`에 있다. 원본 OBJ와 파생 GLB는 ignore 처리된 source cache에 남아 있으며 커밋하지 않았다.

### Parent/part 중복 검사

T102의 official parent relation과 현재 parent scene의 실제 source ID·원문 명칭을 대조했다. FJ1433/M은 T72의 exact OBJ header에서 rectus femoris이고, FJ1395/M은 T101에서 biceps femoris long head, FJ1398/M은 adductor hallucis oblique head다. 새 target은 이들 각각과 구분되는 vasti·short head·transverse head다. generic IS-A/side-specific 행이 같은 FJ를 가리키는 경우 한 mesh node만 유지하며 ancestor 명칭으로 별도 node나 learner binding을 만들지 않았다. target concepts에 대응하는 whole-muscle aggregate parent surface는 active parent manifest에서 발견하지 못해 surface 대체/억제는 필요하지 않았다. 각 대상 header와 원시 vertex 범위를 확인했지만 AABB를 surface 교차·접촉의 증거로 사용하지 않았다. 자세한 판정과 근거 file은 `work/evidence/T102/product-representation-review.json` 및 source manifest의 `wholeMusclePartRepresentation`에 있다.

## 같은 장면과 실제 브라우저 검증

새 chunk를 기존 T77+T95+T79+T101 manifest chain 뒤에 append했다. 별도 viewer, renderer, camera 또는 root는 만들지 않았다. 한 `AnatomySceneRoot`, 한 renderer canvas, 한 카메라가 유지됐다. 새 10개는 source-only/unbound로만 표시되고 canonical ID·선택 카드·세 이름·사람 검토 상태를 만들지 않았다. local technical display는 이 정확한 subset의 검증 후 허용했고 public redistribution은 held다.

실제 Codex in-app browser에서 전신, 넙다리 확대, 발 확대, 근육 layer off/on을 확인했다. 넙다리 필터에 8개, 발 필터에 2개, 전신에 10개 T102 node가 보였으며 각 node는 unique였다. 5회 반복한 30개 region/layer transition의 전체 순서에서도 같은 결과가 나왔다. 반복 전후 전신 scene은 draw calls 561, triangles 2,456,098, geometries 561, materials 573, geometry attribute/index bytes 65,343,180으로 돌아왔고 리소스 누적이나 canvas/root/renderer 교체가 없었다. 근육 끄기에서는 T102 가시 node가 0개였고 다시 켜면 10개가 복귀했다. console error/warning 0건.

전신 camera Z는 3.434m, 넙다리 close view Z는 1.327m였다. renderer pixel ratio는 1.75, CSS canvas는 823×499, RAF interval p50 16.7ms/p95 17.2ms (240 표본)였다. RAF 값은 cadence proxy이며 GPU render time으로 해석하지 않는다.

22 설계의 성능 비교용으로 T101 parent scene의 object-level 카운터를 같은 live T102 장면에서 정확한 T102 GLB 기여분만 빼서 비교했다. T102 chunk는 추가 전송/캐시 payload 812,256 bytes, decoded geometry buffer 783,960 bytes, 36,092 triangles, draw calls/geometries/materials 각 10을 더했다. 분해된 T102 GLB accessor byte·triangle 합계와 현재 runtime 합계가 일치한다. 반복 부위/layer 전환은 chunk를 resident set에서 재사용했다. 브라우저 CUA 평가 scope는 Resource Timing API를 제공하지 않아 네트워크 cold/warm duration은 별도 계측하지 않았다. 저장된 T101 report는 RAF baseline을 남기지 않았으므로 프레임 cadence 개선/저하를 주장하지 않는다.

자세한 browser interaction·stats는 `work/evidence/T102/browser-validation.json`을 참조한다. 최종 deterministic build 뒤 localhost 브라우저를 다시 열어 넙다리 표면, 넙다리+발 전환, 근육 layer off/on, 전신 복귀를 확인했다. 시각 캡처는 브라우저 안에서 확인했고 파일로 export하지 않았다.
