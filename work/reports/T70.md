## Git 범위

새 T70 코드·manifest·evidence·보고서와 T70/T71 task 파일만 이 task의 commit 대상이다. STATUS는 기존 수정 파일, R15 registry와 T56은 기존 미추적 사용자 계획 파일이므로 **작업트리의 live pointer/명세는 맞췄지만 파일 전체를 임의 commit하지 않는다.** 이 세 파일을 새 clean checkout에서 자동 복원했다고 주장하지 않는다. 다른 기존 사용자 WIP, R14/R15 계획, 과거 review, source cache, OpenSim_Models는 commit에서 제외한다. push·배포·T71/T56 실행은 하지 않는다.
