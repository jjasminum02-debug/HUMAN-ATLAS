## 실행 요약

BodyParts3D Release 4.0을 근육과 뼈의 **같은 source/reference coordinate에서 관리할 잠정 정적 전신 기준**으로 선택했다. BodyParts3D는 공식 문서상 성인 남성 whole-body model의 개념별 3D 구조를 제공하고 polygon은 atomic `ELEMENT` 단위 OBJ로 분리한다. 여기서 말하는 공통 기준은 source reference geometry를 뜻한다. 표준 관절/해부학 중립 자세를 공식 자료가 선언하지 않으므로 그 자세를 부여하지 않았다.

실제 파일을 확인한 것은 기존 우측 하퇴 샘플이다. 그 GLB는 7개 근육·4개 뼈의 11개 mesh node로 구성되고 외부 URI, skin, animation, morph target이 없다. 추가 우측 뼈 GLB 9개도 같은 BodyParts3D Release 4.0 계열이지만 전신 모델 취득은 아직 없다. 따라서 이 선택은 static reference geometry의 원천 선택이고 애니메이션-ready 또는 전신 product scene 승인과는 별개다.

별도 private browser spike에서 실제 FJ1439 앞정강근 표면 일부 808/2204 정점에 비균일 국소 변위를 적용하고, FJ3385 거골 mesh를 임의 시험 중심으로 회전한 뒤 원본 geometry/hash·행렬·camera를 되돌렸다. 기술적으로 같은 WebGL renderer와 `AnatomySceneRoot` 안에서 surface buffer와 bone transform을 처리할 수 있음을 확인했다. 임의 displacement field와 pivot은 해부학적 근육 수축·부착·관절 운동이 아니다. 생산 변형은 아직 없음.

## 출처 및 모델 선택

### BodyParts3D Release 4.0 — 잠정 정적 기준 선택

공식 [BodyParts3D README](https://dbarchive.biosciencedbc.jp/data/bodyparts3d/LATEST/README_e.html)는 성인 남성 whole-body model을 기술하고(lines 0–5), concept/FMA ID와 representation/file ID를 분리하며(lines 35–63), atomic ELEMENT mesh와 compound-to-ELEMENT crosswalk를 구분한다(lines 97–123). Release Note는 Release 4.0에서 skeletal coordinates와 기존 부위 위치가 바뀌었다고 기록한다(lines 2–10); 따라서 한 장면은 하나의 release/source frame으로 고정해야 한다. README update history는 Release 4.0 polygon data update를 2013-06-19로 적지만 [Release Note](https://dbarchive.biosciencedbc.jp/data/bodyparts3d/LATEST/release_4.0_e.html) 머리글은 2013-05-16으로 표시한다. 이 날짜 차이는 기록하고 별도 추측으로 정리하지 않았다.

현재 [다운로드 목록](https://dbarchive.biosciencedbc.jp/en/bodyparts3d/download.html)은 IS-A tree 136 MB 및 PART-OF tree 62 MB의 99%-polygon-reduced OBJ archive를 제공한다(lines 24–51). 이는 두 개의 단일 reduced archive이지 여러 해상도를 오가는 multilevel LOD chain이 아니다. T50은 전체 archive를 받지 않았다. 현 [license page](https://dbarchive.biosciencedbc.jp/en/bodyparts3d/lic.html)는 CC BY 4.0 및 배포 시 요구되는 attribution을 적는다(lines 25–40). 기존 2013 OBJ 일부 주석에는 CC BY-SA 2.1 Japan과 동일 archive link가 보존돼 있다. 두 문구를 임의로 덮어쓰지 않았으며 file-level release/legal review를 남긴다.

Project frame conversion은 기존 `atlas-data/manifests/assets.json`의 `[x_atlas,y_atlas,z_atlas]m=[x_source,z_source,-y_source]mm/1000`을 따랐다. BodyParts3D 원점/좌표는 OpenSim Gait2392와 등록되지 않았다. 좌우는 현재 실제 표본과 manifest가 우측으로 기록한 범위뿐이며 반대쪽 대칭/전신 bilateral coverage로 외삽하지 않았다.

Gait2392 core model의 model-level license는 CC BY 3.0으로 선행 T44가 기록했으나 실제 VTP에는 파일별 license notice가 없고 개별 redistributability 확인이 남았다. OpenSim 자료 전체에 license 하나를 유추하지 않았다.

## Shared AnatomySceneRoot 계약

Architecture decision은 `work/evidence/T50/scene-contract.md`에 있다. 핵심 결정:

1. 학습 화면은 단 하나의 renderer/canvas/scene controller와 persist하는 `AnatomySceneRoot`를 사용한다. 화면에 별도 시범 모델을 보여주거나 region 선택 때 검은 viewport/model switch로 운동을 대신하지 않는다.
2. scene controller만 renderer·camera/OrbitControls·공유 lighting/material policy·ID binding·base pose·layer/pickability·selection·motion session/cache/disposal을 소유한다. UI는 명령/선택 결과를 그리는 쪽이다.
3. 명시적 버전형 binding(`canonicalId → instanceId → stable node path`)에는 source/version/file ID/hash, scene revision/hash, laterality, frame/unit, reference-pose ID가 필요하다. fuzzy name binding 금지.
4. pose, layer, selection과 `MotionSession`은 분리된 typed owner로 두되 같은 root만 갱신한다. pose restore는 camera/layer/selection을 묵시적으로 리셋하지 않는다. layer 숨기기는 운동 대체가 아니다.
5. 표면 변형은 reviewed per-vertex weight/deformation basis, attachment/joint constraint, topology·pose/frame binding이 선행되어야 하며 전체 muscle scale-only는 금지한다.
