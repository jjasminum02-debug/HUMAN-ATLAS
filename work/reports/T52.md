### source 접근 및 권리

공식 [BodyParts3D README](https://dbarchive.biosciencedbc.jp/data/bodyparts3d/LATEST/README_e.html), [download 안내](https://dbarchive.biosciencedbc.jp/en/bodyparts3d/download.html), [license 안내](https://dbarchive.biosciencedbc.jp/en/bodyparts3d/lic.html)와 T51 Release 4.0 source manifest를 사용했다. 공식 `isa_BP3D_4.0_obj_99.zip`의 HTTP Range/ETag를 확인하고 선택된 85 OBJ member만 추출했다. archive 크기 142,903,898 bytes 중 OBJ member 요청 10,199,119 bytes와 ZIP directory 요청 235,582 bytes를 읽었으며 archive 전체는 받지 않았다. 추출된 파일은 85/85, 총 34,836,124 bytes; ZIP CRC, source SHA-256, FJ/FMA/BP/tree 식별 및 mesh 유효성을 확인했다. 파일별 경로/크기/hash와 acquisition ETag는 `work/evidence/T52/source-acquisition.json`에 있다.

현재 공식 DB license 페이지는 CC BY 4.0(2025-02-27 갱신)을 표시하지만, Release 4.0의 OBJ header 일부에는 CC BY-SA 2.1 Japan 문구가 있다. 파일 단위로 이 범위가 어떻게 조정되는지 해결되지 않아 manifest의 `redistributionStatus`는 held다. 원본 및 파생 GLB를 공개/배포하지 않는다.

## 좌우 확인 결과 — 사람 판정 대기

T50의 source frame에서 양의 x는 좌측, 음의 x는 우측이다. 이는 geometric diagnostic일 뿐 mesh identity를 승인하지 않는다.

- `FJ2742` / Right middle pharyngeal constrictor: bounds 중심은 좌측이지만 bounds가 median을 겹친다.
- `FJ2754` / Left middle pharyngeal constrictor: bounds 전체가 우측에 있다.
- `FJ2780` / Left oblique arytenoid: bounds 중심은 우측이고 median을 가로지른다.
- 별도 14개는 `bounds_cross_midline_direction_inconclusive`; 위 세 반대 중심 중 FJ2742와 FJ2780도 median과 겹친다. 따라서 전체 median 교차 AABB는 16개이며 AABB로 좌우를 승인하지 않았다.

공식 source 이름과 원본 file identity는 보존했으며 좌우 명칭, mesh 좌표, FJ↔FMA 관계를 수정/미러/승격하지 않았다. 해부학 검토자가 세 반대 중심 사례를 독립 해부학 근거·mesh topology와 함께 판정하고, 14개 경계 사례에서 단순 AABB 외의 sides evidence를 제시하거나 미확정 상태를 승인해야 T52의 방향 검증 게이트를 닫을 수 있다.
