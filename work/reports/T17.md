## 구현

- `atlas-data/schemas/source-research-manifest.schema.json`은 canonical `individual_muscle` ID 및 필드를 받는 manifest 계약이다. manifest 하나에 근육은 최대 6개이며, CLI가 각 ID를 현재 canonical catalog에서 확인한다.
- `atlas-data/sources/source_research.py`는 offline CLI다. 인터넷 검색, 네트워크 요청, 계정, 브라우저 데이터, 모델 호출이 없다. 출처를 실제로 연 사용자가 JSON manifest에 접근을 수동으로 기록한다. `--hash-value`는 입력 값의 canonical SHA-256을 계산한다.
- 각 출처에는 URL, 정확한 판본 또는 `not_exposed`/null, 명시적 `underlyingWorkId`와 그 근거, 제목이 있다. 접근 행에는 locator, ISO 날짜, T16 접근 방식, 원문/색인/초록/메타데이터/실패 상태와 실패 이유가 들어간다. URL 숫자로 독립 출처를 추정하지 않는다. 같은 underlying work의 서로 다른 URL은 한 work로 집계한다.
- field extraction은 같은 구조 ID·필드·접근 레코드를 따라야 하며, 열린 원문(full/partial) 또는 test fixture 외에는 허용되지 않는다. 검색 snippet/index, 초록, 메타데이터, legacy row, 실패 접근은 field claim을 지지할 수 없다. field 값 해시와 source/access/locator 참조가 일치해야 한다.
- `agreement`, `wording_difference`, `variation`, `substantive_conflict`, `not_comparable` 분류와 근거는 입력된 비교 기록을 그대로 보존한다. 도구가 해부학적 동등성이나 충돌을 추론하지 않는다. 접근 불가는 별도 `unavailable` 예외 및 field summary 상태로 보존한다.
- 출력은 `access-ledger.json`, `field-observations.json`, `comparison-table.csv`, `run-summary.json`, `exceptions.json`이다. source metadata, 접근 레코드, 관찰값에 재현 가능한 해시를 만든다. 캐시 키는 전체 manifest hash이고 출처 메타데이터/접근/값/참조/비교가 바뀌면 무효화된다. 출력/캐시 쓰기는 `atlas-data/`와 `OpenSim_Models/` 아래에서 거부된다.
- 입력 계약은 `assessmentMode`에 AI 후보와 조사자 입력을 구분하지만 reviewer, `reviewState`, `humanReviewed`를 받지 않는다. 결과에는 사람 해부학 검토가 이 도구에서 수행되지 않았다고 명시한다. 출력은 T16 production AI evidence overlay가 아니며 자동 승격/승인을 만들지 않는다.
- synthetic fixture와 실행 결과는 `work/evidence/T17/fixtures/` 아래에만 있다. fixture 값/분류는 모두 test-only이며 학습 catalog나 실제 구조 데이터로 복사하지 않았다.

## 미완 및 경계

- 실제 anatomy source를 검색하거나 열지 않았고, 실제 근육별 extraction/comparison을 만들지 않았다. T17은 도구 완료이며 T18 자료 내용 완료가 아니다.
- `underlyingWorkId`와 `workIdentityBasis`는 조사자가 근거를 보고 입력한다. 도구는 work identity의 진실성이나 출처 독립성을 외부 서지정보로 인증하지 않는다. 사람이 기록한 비교 분류도 사람 해부학 검토/승인이 아니다.
- 생산 source 입력 시 원문 locator·edition/access 상태·짧은 요약 및 값을 확인하고, 각 claim이 해당 문장에 실제로 지지되는지 별도로 재검토해야 한다. 이 프로젝트의 human review 상태는 자동 변경되지 않았다.
- 전신 분모는 미동결이며 T32/T33/FU01은 실행하지 않았다. 앱 화면, 임상/환자 기능, 배포도 추가하지 않았다.
