# T53 결과 — 몸통·골반 source package

## 판정

**partial.** T51의 BodyParts3D Release 4.0 지역 candidate를 취득 전에 고정하고 등·가슴우리·배/허리·골반/샅·볼기/깊은엉덩이의 실제 source mesh 138개를 한 좌표계의 QA 전용 GLB와 다섯 지역 manifest로 준비했다. 실제 browser에서 단일 renderer/`AnatomySceneRoot`, 세 camera direction, 지역 필터와 selection을 확인했다.

T51 region roots에 등·배허리·골반샅 뼈 candidate가 없고 볼기/엉덩이도 좌우 hip bone mesh 두 개뿐이다. thorax에는 좌측 clavicle/scapula 후보만 보인다. 8개 OBJ identity header는 비어 있고, source bounds header 47개가 실제 vertex bounds와 허용오차 밖 차이가 있다. 1,751개의 AABB 후보에 대해 triangle surface 교차를 계산하지 않았다. 따라서 제품 전신/몸통 coverage, torso-limb connection, deep-muscle completeness, 완전한 좌우 검증 또는 표면 무관통을 주장하지 않는다.

학습 화면·canonical membership은 변경하지 않았다. 공개/배포 권리는 legacy OBJ header와 공식 최신 안내 간 파일별 적용 확인까지 보류한다. T53은 `complete_with_gaps`가 아니라 **partial**이다.

## 원문과 실제 자산

BodyParts3D official README는 성인 남성 전신 개념-표면 데이터베이스, atomic ELEMENT polygon mesh, Release 4.0 99%-reduced OBJ bundle 및 최신 license 안내를 제공한다. Release note는 R4를 2013-05-16으로 표시하고 FJ를 고유 polygon file ID로 설명한다. 같은 release note는 데이터에 canonical human model로 쓰기에 오류가 있을 수 있다고 경고한다. 99%-reduced bundle은 source 제공 mesh resolution이며 별도 LOD chain으로 해석하지 않았다.

- Source/version: `BODYPARTS3D_LSDB_ARCHIVE_RELEASE_4_0`, **BodyParts3D Release 4.0**, official `IS-A` tree. T53은 이 한 source/version만 썼고 다른 모델을 시각 정렬하지 않았다.
- Archive: `https://dbarchive.biosciencedbc.jp/data/bodyparts3d/LATEST/isa_BP3D_4.0_obj_99.zip`; 138개 frozen member만 HTTP 206 byte-range로 추출했다. 전체 archive(공식 표시 크기 136 MiB / acquisition Content-Length 142,903,898 B)는 다운로드하지 않았다. Archive ETag/Last-Modified, member path, CRC32, size 및 SHA-256은 `work/evidence/T53/source-acquisition.json`에 있다. 추출 payload는 112,768,729 B이다.
- 원본 cache: `atlas-data/source-cache/bodyparts3d-r4/mesh/t53/`; 최종 통합 GLB 37,179,596 B, SHA-256 `25b9850ded5fe6e8c38e48578ba6a4d4e617dca1169cd1c6d63dfda52814709b` at `atlas-data/source-cache/bodyparts3d-r4/converted/t53/T53-trunk-pelvis-static-source.glb`. 대용량 source/derived 파일은 ignored local cache에 보관하고 Git commit에서는 제외했다. Source IDs와 payload hashes는 manifest가 결속한다.
- Frame/unit/transform: T69/T50 확인 계약 `HUMAN_ATLAS_RH_M_XLEFT_YHEAD_ZANTERIOR`; `[x,y,z] mm → [x,z,-y] m`, x 부호 유지, no mirror. 각 OBJ의 `Bounds(mm)` 단위 헤더를 확인했다. `BodyParts3D Release 4.0 static reference`; standardized articulated pose나 OpenSim registration은 주장하지 않는다.
- License: 공식 README의 2025-02-25 license section/2025-02-27 update는 CC BY 4.0 및 제공 attribution을 명시한다. 취득한 138개 OBJ header 모두에는 CC BY-SA 2.1 Japan 문구가 있다. release 4.0 파일 header와 현재 database license의 적용 범위를 파일별로 reconciliate하지 않았으므로 manifest `redistributionStatus=held_pending_file_level_reconciliation_with_legacy_OBJ_headers`, public release=false로 유지했다. 이는 로컬 기술 QA 허용과 별도다.

## Identity, bounds, relative position, laterality

- 130개 OBJ는 header의 FMA/BP pair를 Release 4.0 metadata에 대조할 수 있었다. `FJ1450`, `FJ1451`, `FJ1454`, `FJ1455`, `FJ1525`, `FJ1543`, `FJ1547`, `FJ1548` 8개는 header Concept ID, Representation ID, English name이 비어 있다. 안정적인 source File ID와 실제 geometry는 보존했지만 해당 세 이름/identity fields는 null, side는 unknown으로 뒀다. T51 context 이름은 candidate로만 보존하고 정확한 identity/name/laterality로 채우지 않았다.
- OBJ `Bounds(mm)` header 대 실제 vertex bounds 비교 tolerance는 0.01 mm다. 91/138은 tolerance 안에서 일치, 47 ID는 초과 차이가 있고 최댓값은 0.4761 mm다. 각 header bounds와 실제 vertex bounds를 모두 manifest에 기록했다. 변환/region bounds는 actual vertices에서 계산했고 차이를 조용히 덮지 않았다.
- Source label side는 left 55, right 52, non-lateralized label 23, blank-name unknown 8이다. actual triangle surface가 project x=0을 가로지르는 mesh는 27개이며 source label과 완전히 반대편에만 놓인 mesh는 0개다. x=0 crossing/AABB로 identity를 고치거나 source label·geometry를 교환, mirror, promote하지 않았다. FJ 이름 끝의 `M`은 별도 official source File ID로 유지했다.
- 전체 138 OBJ→GLB actual FLOAT32 POSITION payload hash가 T50 transform으로 계산한 값과 일치했다. 한 source frame 안의 source bounds와 three-view integrated GLB에서 rib/thoracic-spine, torso muscle, hip region의 상대 배치를 관찰했다. region union Y extents가 등 `0.735–1.500 m`, 가슴우리 `0.986–1.377`, 배/허리 `0.794–1.212`, 골반/샅 `0.754–0.829`, 볼기/엉덩이 `0.668–0.958`로 인접 범위를 겹치지만 bounds overlap은 anatomy continuity 증거가 아니다.
- Frozen set에는 T53 볼기 region의 양측 hip bone mesh 2개는 있으나 T53 package에 sacrum/femur node가 없고, 등·배허리·골반샅 source roots의 bone context도 0개다. 흉곽 bone context는 rib/thoracic-spine과 왼쪽 clavicle/scapula source candidate를 포함하고 오른쪽 어깨뼈 후보는 없다. 따라서 양측 어깨 및 torso-to-limb skeletal connection은 확인되지 않았으며, 새 region ID나 crosswalk를 추정 추가하지 않았다.
- Pairwise AABB broadphase는 1,751 overlap candidate를 남겼다. 가장 많은 cross-region box candidate는 등↔가슴우리 591쌍, 배/허리↔가슴우리 43쌍, 볼기/엉덩이↔골반/샅 23쌍이다. AABB overlap은 surface penetration, contact, duplicate, anatomy error의 증거가 아니다. 브라우저 세 방향에서 gross displacement/duplicate rendering을 눈으로 살폈으나 triangle-level surface intersection solver는 실행하지 않았다. 따라서 표면 관통 부재를 보증하지 않는다.
