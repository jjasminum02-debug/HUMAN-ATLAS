- 실패/손상 object checkpoint를 격리·재개한다. 의도적으로 한 checkpoint를 손상시킨 검사에서 **959 재사용 / 1 재평가 / 0 실패**를 확인했다. pending failure가 남으면 전체 compile을 거부한다.
- ResourceQueue에 실제 CPU geometry byte LRU, wanted/pin 보호, 동시 취득 2, 취소·늦은 decode 해제·중복 dispose 보호를 구현했다. 기존 BP3D controller도 96MiB 한도를 사용한다. 새 상세 요청은 overview를 유지하다 동일 node의 geometry만 교체하고 1M triangle 예산을 넘으면 overview를 유지한다.

## 검증 중 수정 및 한계

기존 cancel 테스트 두 개는 callback 시작을 microtask로 늦춘 변경 때문에 실패했다. 동기 시작 계약을 복원했고 최종 31개가 통과했다. 단순 chunk 크기 추정이 glTF JSON overhead를 놓칠 수 있어 **실제 GLB 크기로 재분할**하도록 수정했다. 자료 삭제나 예산 상향은 없었다.

Blender의 신선 재평가는 normals/decimation이 비트 동일하지 않았고 overview 삼각형이 1개 달라진 실행도 있었다. 원본 평가 geometry hash는 모두 T98과 일치한다. 신선 Blender byte 재현을 합격 주장하지 않으며, **동결된 indexed unit의 재pack은 동일 hash**로 검증했다. 실제 resource/instance와 compiler code를 dataset revision에 포함해 새 결과를 과거 승인 cache로 취급하지 않는다.
