- 신경 주행 보기에서는 주변 근육·뼈가 반투명해지고 선택 신경은 보라색, 근거 있는 같은 쪽 전경골근은 파란색으로 구분된다. `주행 보기`·`지배근 강조`·숨김·되돌리기·복원이 같은 controller의 상태를 사용한다. 신경을 숨기거나 레이어를 끄거나 근육을 선택하면 남아 있던 관찰 강조를 해제한다. 복원이 사용자가 끈 레이어를 되살리지 않는다.
- 얇은 원본 신경이 보이는데 실제 클릭은 뒤 근육을 선택하던 결함을 수정했다. 투명 주행 보기에서 원본 삼각형에 대한 **1 CSS pixel 범위의 실제 ray 교차**만 보완한다. 일반 보기의 깊이 선택은 유지한다. 확대 mesh, 허구 centerline, 이름으로 추정한 hit는 없다.
- mobile 카드 접기는 유지하며 1024 이상으로 다시 넓히면 설명 카드를 열어 접근 불가능한 빈 줄이 남지 않게 했다. 기존 선택/scene/camera를 유지한다. Home 키는 현재 지역에 맞춘다. 숨긴 외복사근은 다른 근육을 선택해도 다시 생기지 않는다.
