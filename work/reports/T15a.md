# T15a 보고서 — 이름 요구 교정과 한자 노출 제거

상태: **complete_with_gaps**. T15a만 수행했고 T15b는 시작하지 않았다.

## 범위와 기준선

요청된 AGENTS.md, STATUS, 설계 00/03/06, R12 설계 검토, T15a 명세를 읽고 실제 학습/검토 UI와 terminology overlay를 확인했다. 시작 HEAD는 `4452411d8a6f52e7a9aacfce003571d8ae53fb6b`였다. 시작 전부터 R12, T13c, T14a, T14b 문서·데이터·화면 변경이 섞여 있었다. 상세 기준선은 [start-baseline.json](../evidence/T15a/start-baseline.json)에 기록했다.

## 구현

- learner name projection에서 기존 `label`/`korean`/`english`를 `koTraditional`/`koModern`/`en`으로 분리했다. 화면 제목은 한글 표기 한자어명, 우리말명, 영어 순으로 fallback한다. 값이 없는 우리말/한자어 필드는 빈 출처를 추측하지 않고 `—`로 표시한다.
- 학습 카드에는 `삼각근`, `어깨세모근`, 영어 출처명 `Deltoid muscle`을 표시한다. 현재 overlay에 있던 소문자/대문자 `Deltoid` 동의어를 유지하고 `deltoids` 편의 alias를 추가했다. 네 검색어 모두 같은 기존 ID `HA-M-000030`을 최상위 선택으로 연다.
- learner 검색 projection과 검토 용어 목록에서 실제 Han script/Hani 용어 행을 제외했다. 원자료 locator가 화면에 나타날 때 실제 한자 연속 문자열은 `[출처 한자 생략]`으로 보인다. 학습 검색 안내에서 한자 입력을 유도하지 않는다.
- 기존 overlay의 실제 한자 값 `三角筋`, `hanjaNote`, source IDs, locator, 검색/용어 근거는 삭제하지 않았다. 원래 이름 기록의 영어 필드도 출처 문구 `Deltoid muscle`로 보존했다.

검색어 `삼각근`, `어깨세모근`, `Deltoid`, `deltoids`로 최상위 항목을 눌렀을 때 주소의 선택 ID는 모두 `HA-M-000030`이었다. `Deltoid`는 서로 다른 부분 구조 결과도 함께 표시되지만 정확한 근육 항목이 맨 위에 남는다. 실제 한자 `三角筋` 검색은 0건이었다. 출처 상세를 펼친 learner 화면과 `/review`에 실제 Han script 문자가 렌더되지 않았다.

`/review`에는 별도의 **한국어 용어 미확인** 상태가 남아 있다. 이것은 한글 용어 원문/locator 결측을 알리는 것이며, 실제 한자 누락을 요구하거나 경고하는 gate가 아니다. T15a에서 그 근거 공백을 추측으로 채우지 않았다.

Build는 통과했으나 현재 앱 번들의 minified chunk가 500 kB 기준을 넘는 기존 최적화 경고가 출력됐다. T15a에서는 chunk splitting을 범위에 추가하지 않았다.

## 보존과 미완

- 시작/종료 비교에서 `canonical-catalog.json`과 `learning-structure-summaries.json`은 바뀌지 않았다. T15a 보존 기록은 [preservation-after.json](../evidence/T15a/preservation-after.json)에 있다.
- `OpenSim_Models` 시작 HEAD `d9b05d470b1a481c222372c85b75772faf8f7792`, clean status를 보존했다. 원본 모델, GLB/OBJ, 기존 사용자 변경을 건드리지 않았다.
- `/review`는 읽기와 UI 탐색만 했다. annotation/spatial draft 저장·가져오기·삭제를 하지 않았다. T14b는 계속 `needs_human_review`; 사람 검토 의견은 0건이고 anatomy 승인·reviewed 승격도 없다.
- 뼈 검색과 12부위 통합, 전신 이름 coverage, 전신 자산/장면은 미완이다. selected deltoid에는 3D 연결이 없으며 본 task의 명칭 검증을 구조 완성으로 간주하지 않는다.
- 검증 시 서버 번들 변경으로 learner/browser에서 T05 부착 surface나 anatomy claim을 보강하지 않았다. 전신 언어/사람 검토 상태도 그대로다.
