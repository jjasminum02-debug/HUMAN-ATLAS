- `atlas-web/src/viewer/GLBViewer.tsx`: 학습 모드는 선택한 근육 메시 bounds로 카메라를 맞춘다. 부착 문맥을 선택하면 선택 근육과 관련 뼈를 함께 강조하고 카메라는 근육 중심 프레임을 유지한다. 전체 장면 프레임은 별도 `전체 보기` 동작으로 유지한다. 보기 초기화는 활성 부착 ID를 지우고 근육 선택 프레임으로 돌아간다.
- `atlas-web/src/ui/App.tsx`: 기시와 정지의 한국어 요약을 구조 탭 앞부분에 나란히 배치했다. 부착별 뼈 강조 제어와 영문 claim 설명/판본을 접힌 disclosure 안에 배치했다. 근육 선택 변경과 뒤로가기는 부착 선택을 해제한다.
- `atlas-web/src/ui/styles.css`: 두 요약과 접힌 근거를 위한 간결한 카드 배치 및 모바일 목록 높이를 조정했다. 390px에서 파일럿 6개 근육명이 모두 잘리지 않는다.
- `design/2026-09-25-muscle-atlas/00-START-HERE.md`, `work/STATUS.md`: 현재 단계를 T13a 기술 통과, 다음을 T13b 미시작으로 맞췄다.
- 상세 기록: `work/tasks/T13a.md`, `work/evidence/T13a/`.

이 변경은 기존 사용자 변경이 들어 있던 작업 파일을 이어서 수정한 것이다. 주변 구현을 되돌리거나 파일을 덮어쓰지 않았다.

## 검증

실제 로컬 학습 `/` 페이지를 Codex in-app browser에서 조작하고 육안으로 확인했다. 수치는 `work/evidence/T13a/browser-validation.json`에 기록했다.

- 1440×900: 기시·정지 요약이 둘 다 스크롤 없이 보였다. 선택 근육은 canvas 높이의 약 75%를 차지했다. 영문 상세는 기본 접힘 상태였다.
- 1280×720: 목록·3D stage·설명 카드와 5개 보기 도구가 겹치지 않았고 문서 가로 넘침이 없었다. 근육의 시각적 세로 점유는 약 65%였다. `전체 보기`를 눌러 장면 전체 축소 프레임이 별도로 동작하는 것도 확인했다.
- 390×844: 목록·stage·설명 카드가 세로로 배치되고 서로 겹치지 않았다. 가로 넘침이 없었고 6개 목록 항목이 모두 보였다.
- 첫 기시 설명 선택 시 관련 뼈 문맥과 상태 안내가 나타났다. 보기 초기화 뒤 선택 부착 수가 0이고 안내가 사라졌으며 선택 근육 프레임이 복구됐다.
- 부착 선택 후 가자미근으로 전환했을 때 선택이 해제됐다. 브라우저 뒤로가기로 비복근에 돌아와도 부착 선택은 남지 않았다.
- 초기 상태에서 source disclosure 둘 다 닫혀 있고 긴 영어 claim 문장은 화면 본문에 없었다. 브라우저 console error/warning은 0개였다.
- 브라우저 스크린샷은 대화에서 inline으로 확인했고 파일로 저장하지 않았다. 검증은 로컬 개발 `/` 경로에 한정했다.

`atlas-web`에서 `pnpm typecheck`, `pnpm test:search`(38/38), `pnpm test:annotations`(12/12와 exchange schema), `pnpm build`를 통과했다. 빌드의 학습자료 검증도 통과했다. Vite는 App 번들이 500 kB 기준을 넘는다는 경고를 출력했지만 빌드는 성공했다. 실행 결과 요약은 `work/evidence/T13a/commands.json`에 있다.
