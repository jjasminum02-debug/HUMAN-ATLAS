## 원문·권리·기하 QA

공식 [IS-A 99% mesh 자료 페이지](https://dbarchive.biosciencedbc.jp/en/bodyparts3d/data-7.html)는 `isa_BP3D_4.0_obj_99.zip`, OBJ mesh, 2,234 entries 및 DOI `10.18908/lsdba.nbdc00837-007`을 표시한다. 공식 [IS-A compound/ELEMENT 관계 설명](https://dbarchive.biosciencedbc.jp/en/bodyparts3d/data-5.html)는 atomic ELEMENT가 mesh이고 관계 파일이 compound-to-ELEMENT 연결을 제공한다고 설명한다. [R4 release note](https://dbarchive.biosciencedbc.jp/data/bodyparts3d/LATEST/release_4.0_e.html)는 Release 4.0의 날짜를 2013-05-16으로 적고 FJxxxx를 개념 ID와 구별되는 고유 mesh file ID라 설명하며, canonical whole-body 모델로 쓸 때 오류가 있을 수 있다고 경고한다. 조회 위치·판본·접근방법은 [official-source-checks.json](../evidence/T75/official-source-checks.json)에 적었다.

공식 archive 전체(페이지 표시 약 136 MB)는 받지 않았다. frozen ID만 archive central directory/member HTTP Range로 선택했다. 실패 또는 부분 처리였던 초기 획득 기록을 보존했고, 최종 attempt 03은 여섯 원본을 20개 HTTP 206 응답으로 받아 크기/CRC32/SHA-256을 검증했다. T75 전용 central-directory parser가 `FJ1468M` 같은 suffix를 보존하도록 했다. 공통 historical extractor는 수정하지 않았다. 재취득·검증은 `python3 atlas-data/tools/acquire_bodyparts3d_r4_t75.py --check`로 확인한다.

원본 OBJ 6개에는 CC BY-SA 2.1 Japan 문구가 있고 현재 공식 [license 페이지](https://dbarchive.biosciencedbc.jp/en/bodyparts3d/lic.html)는 2025-02-27 갱신일과 CC BY 4.0을 표시한다. 이 자료들의 file-level license 적용 관계를 확정하지 않았으므로 원본/파생 파일은 로컬 기술 검증용으로만 두고 재배포를 보류한다. 각 header 전문과 SHA는 [source-audit.json](../evidence/T75/source-audit.json)에 있다.

세 OBJ의 Bounds header와 실제 정점 extrema 최대 차이는 FJ1468 0.1022 mm, FJ1467 0.4658 mm, FJ1513 0.3248 mm다. 나머지 세 파일은 0.001 mm 이내다. 이 metadata 차이를 오류 원인이나 충돌/표면 접촉으로 추론하지 않았고 AABB를 접촉·비관통 증거로 쓰지 않았다. 각 actual vertex bounds, source bytes, triangle/topology 및 position hashes는 source audit와 manifest에 기록되어 있다.
