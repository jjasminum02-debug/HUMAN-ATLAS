# HUMAN ATLAS 로컬 앱 전달

현재 지원한 정상 구조와 학습 기능을 실행할 수 있다. 전체 콘텐츠는 **partial**이며 공개 배포 승인은 아니다.

## 지금 실행하기

같은 폴더의 `start.command`를 실행한 뒤 **http://127.0.0.1:5180/**를 연다. 이 앱은 개발 서버와 별개다. 종료는 실행 터미널에서 Ctrl+C이며, 같은 파일을 다시 실행하면 자산을 검사하고 재시작한다. 포트가 사용 중이면 `start.command --port 5181`로 실행한다. 이미 실행 중인 다른 서버를 임의 종료하지 않는다.

`atlas-web/dist-local/CURRENT.json`이 최종 고정 패키지를 가리킨다. 패키지는 다음과 같다.

`atlas-web/dist-local/local-20261006032053779-deedfed2/`

이 **폴더 전체**와 Node.js 24 이상만 있으면 저장소·개발 서버·원본 모형·인터넷 없이 실행할 수 있다. 폴더 안의 `start.command` 또는 그 폴더에서 `node serve.mjs`를 실행한다. Windows에서는 명령을 사용한다. 현재 컴퓨터의 실행 파일은 설치된 Node가 없을 때 Codex의 기존 Node를 사용하지만, 다른 컴퓨터에는 Node.js 24 이상이 필요하다.

## 검사·복구·새 패키지

- 저장소에서 검사: `cd atlas-web` → `pnpm local:verify`.
- 이동한 패키지에서 검사: `node serve.mjs --verify-only`.
- 모형 누락·해시 오류: 서버를 종료하고 폴더 전체를 보존된 정상 사본으로 복구한다. 파일 하나를 다른 revision으로 섞거나 해시 검사를 끄지 않는다.
- 원장이나 등록 자산을 변경했다면 보존된 작성 작업 트리에서 `node --experimental-strip-types scripts/buildLearnerMotionRuntime.mjs`로 두 출력을 함께 갱신한다. 카드 입력을 바꿨다면 해당 카드 작성 도구도 실행한다. 임의 권리 승격이나 실패 자산 등록을 하지 않는다.
- 원래 작업 트리에서 새로 만들기: Node.js 24 이상 및 잠금 파일과 일치하는 의존성 필요. 기존 의존성이 없으면 허용된 로컬 캐시에서 `pnpm install --offline --frozen-lockfile`로 확보한다. `pnpm local:prepare`는 생성 출력 freshness를 확인하고 production bundle을 만든 뒤 검증된 전신/신경 모형과 실제 등록 GLB를 복사한다. 없는 원본/미검증 후보를 대신 생성하지 않는다.
- 이미 검증한 build 입력과 출력이 완전히 같다면 `pnpm local:prepare --reuse-validated-build`로 bundle을 재사용한다. 입력이 하나라도 다르면 이 경로는 실패한다. 실패한 작성은 기존 정상 CURRENT를 교체하지 않는다.

**현재 전달 기준은 보존된 WIP를 포함한 고정 실행 패키지다. Git checkout만으로 같은 콘텐츠를 재생성할 수 있다는 뜻이 아니다.** HEAD 밖의 실제 자산 33개와 runtime 의존성은 T40의 `asset-provenance.json`, `snapshot-manifest.json`, `feature-coverage.json`에 파일·바이트·해시와 소유 범위가 기록되어 있다. 기존 작성자 receipt는 보존했으며 이 변경을 임의 커밋하지 않았다.

기존 `dist/`만 실행하는 Vite preview는 전신·신경 projection 경로를 제공하지 않는다. 로컬 전달에는 위 완전한 패키지를 사용한다. 원본/source-cache/OpenSim_Models/T13은 수정하거나 패키지의 실행 의존성으로 연결하지 않았다. 런타임 원장 두 개와 작은 색인은 패키지 `.internal/`에 있으며 브라우저 주소로 제공하지 않는다.

## 지원과 한계

우선 7근육군의 제품 합격은 20표면·22실제 작용 연결·13고유 GLB다. 전체 앱에서는 추가 작용 및 자세 관찰도 제공되지만 후보 원장 1,166행을 실제 근육 작용 수로 세지 않는다. 현재 도달 가능한 실제 작용 연결은 38표면/56연결이며, 다른 관찰 옵션과 전체 근육 완성 여부는 별도다.

뼈 166 source 표면에 직접 선택 시범이 연결되어 있다. 공동 이동과 고정 지지 역할을 포함하며, 각각의 뼈에 독립 운동축을 만든 것이 아니다. 관절 조절은 단일 방향의 교육용 자세이고 개인의 정상 ROM·힘·활성도 추정이 아니다.

신경은 195개 정적 source 표면/98개 원본 이름 묶음이다. 독립 신경 개념 분모는 확정하지 않았다. 근거 있는 주행 설명은 이름 묶음 10개, 기존 원장이 지원한 포착 설명은 5개이며, 정적 맥락만 있는 항목의 안내 문구를 완성된 주행 설명으로 세지 않는다. 동적 신경 자세와 포착 좌표 연결은 0이다. 지배 관계 18행 중 좌표/측이 확인된 연결은 2행이고 16행은 문헌 개념 관계다.

모형의 source 기준 자세·좌표를 유지한다. 교육용 authored 변형·trajectory와 실측 부착/관절축/생리량은 다르다. 동적 신경 근거가 없는 동작에서는 정적 신경을 가리고 rest에서 사용자의 레이어 상태에 맞춰 복원한다.

Source-only, 검증된 로컬 선택, 사람 검토 `not_performed`, 공개 재배포 `held`를 독립적으로 유지한다. 미래 병리 모형은 정상 geometry/frame/pose와 해시를 보존한 별도 파생 데이터·검증으로 확장해야 한다. 정상 전체 모형이 partial이므로 병리 구현 준비 완료로 판정하지 않았고 이번에는 병리·진단·치료·자침 기능을 만들지 않았다.
