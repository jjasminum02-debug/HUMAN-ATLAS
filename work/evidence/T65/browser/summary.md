# T65 실제 브라우저 검증

- 2026-10-02, `http://127.0.0.1:5173/`의 실제 Codex in-app browser에서 1440×960, 1024×900, 390×844로 확인했다. 문서 너비가 각 viewport와 일치했고 가로 overflow는 없었다. 390px에서는 구조 카드가 세로 흐름으로 이어지고 스크롤로 나머지 내용을 볼 수 있었다.
- 공통종아리신경의 접힌 설명을 열고 심부/얕은종아리신경으로 전환했다. 분지 전환 후 접힘이 유지됐고, Enter 키로 disclosure를 열고 닫았다. 심부가지에는 등록된 전경골근 링크만 보였으며 얕은가지에는 근육 관계를 추가하지 않았다. 전경골근 카드 선택 후 브라우저 뒤로가기가 심부가지로 복귀했다.
- 승모근 상부는 `Descending part`로 표시되며 뒤통수·C7 기시와 빗장뼈 정지를 보였다. 승모근 하부는 `Ascending part`로 표시되며 T4–T12 기시와 어깨뼈 부근 널힘줄 정지를 보였다. 양쪽 선택 URL/상태를 확인했다. 하부 승모근의 어깨뼈 정지 문구에 뼈 연결을 만들어 넣지 않았다.
- 하부 승모근에서 T4 전체 뼈 문맥을 열고 뒤로 돌아 같은 근육 카드/지역으로 복귀했다. 선택 숨기기→다시 표시, 선택만 보기 on→off를 실제 클릭하여 카드와 기본 표시를 복원했다.
- 화면 캡처는 세 크기에서 실제 브라우저로 시각 확인했으나 CUA는 로컬 PNG 저장 API를 제공하지 않아 파일로 저장하지 않았다. 콘솔 error/warning은 0건이었다.

구체 경로, view state와 관찰 값은 `checks.json`에 남겼다. 이 검증은 표시된 표본과 앱 조작의 정확성을 확인하며 모든 신경·근육·부착 범위 또는 사람 검토를 승인하지 않는다.
