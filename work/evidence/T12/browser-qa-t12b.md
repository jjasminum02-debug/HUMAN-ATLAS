# T12b 실제 브라우저 회귀 기록

- 날짜: 2026-09-26
- 대상: 로컬 Vite `http://127.0.0.1:5174/`, Codex in-app browser, Three.js WebGLRenderer.
- `/` 학습 화면에서 정적 우측 종아리 모델이 렌더됐다. 정면·후면·측면 버튼, 근육 목록 선택, 메시 직접 클릭에 따른 카드 전환, 주변 투명, 선택만 보기, 보기 초기화, 드래그 회전, 휠 확대, 일반 왼쪽 화살표 회전, Home 전체 보기를 실제 화면으로 확인했다.
- `/review`에서 11개 메시 목록을 확인했다. FJ1394 숨김·복원과 투명·불투명, 다른 메시 격리 후 복귀를 확인했다. FJ3360/FJ3366/FJ3387은 구조 후보 ID로 표시되고 FJ3385 talus는 대상 ID 미확인으로 표시된다.
- `/review`에서 FJ1394를 격리하고 점 입력을 시작한 뒤 실제 표면을 클릭했다. `표면 점을 기록했습니다` 메시가 나타났고, 저장된 로컬 draft에는 triangle/topology hash와 `instance 미생성 — canonical 데이터가 아님` 상태가 표시됐다. 새로고침 후 초안 1개가 다시 로드됐다. 검증용 임의 점을 UI에서 삭제하고 다시 새로고침해 최종 초안 0개를 확인했다. 이 점을 해부학적 부착 후보로 채택하지 않았다.
- 브라우저 console `error`/`warn`: 0개. 화면 캡처는 실행 중 시각 검사에 사용했으며 파일로 저장하지 않았다.
- 제한: 기존 사용자 작성 localStorage 초안의 실물을 이전 상태에서 확보하지 못했다. 변경하지 않는 코드 경로와 11/11 자동 테스트의 JSON 왕복·topology stale 검사를 통해 손실 방지 회귀를 확인했다. 실제 해부학 동일성/부착면 검토는 수행하지 않았다.
