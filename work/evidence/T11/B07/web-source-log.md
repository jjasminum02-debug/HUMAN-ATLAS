## 필드 연결 및 미채택 사항

모든 B07 core field 및 alias의 URL, 판본 상태, 세부 locator, 조회일, 접근방식은 `term-review-batches.json`의 `fieldEvidence`에 반복 기록한다. TA2 기본 필드는 UK/US English 기본 셀과 Latin term 셀을 사용한다. Latin synonym, English synonym, Other 셀은 각각 추가 alias로 구분한다. 기존 T04 crosswalk가 몇 행에서 synonym 열을 기본 term처럼 선택한 차이(M43, M47, M48)는 B07 overlay의 `observedTableCells`에 명시하고 canonical source-crosswalk 원본은 변경하지 않는다.

작업 전부터 P1/P2 이름 overlay가 있었다. 기존 표시 label, English, parent, source reference를 보존하고 이번에 기사에서 같은 head 표현을 확인했다. 반면 기존 `장딴지근 · 가쪽갈래` / `장딴지근 · 안쪽갈래`는 head-specific 우리말 번역이 출처에서 확인되지 않아 검색용 `korean` 필드에서는 null로 내리고, 이전 문구는 batch ledger의 `unadoptedCandidates`와 `preservedPreviousOverlay`에 남겼다. 이는 기존 기록을 삭제하지 않으면서 미확인 이름을 검색 표준으로 승격하지 않기 위한 것이다.

- M43: `內閉鎖筋`은 직접 관찰하지 못해 생성하지 않음.
- M46: `大槌方形筋`은 source row에서 보이나 문자 손상 가능성을 배제할 수 없어 검색 alias로 채택하지 않음.
- M47: `短母指屈筋`과 `短足拇趾屈筋` 후보가 source index에 각각 보여 표준 Hanja는 결측으로 둠.
- M48: exact old row에는 `拇趾內轉筋`이 `무지내전근`과 함께 있고 `母趾內轉筋`은 별도 `모지내전근` 문자열과 연결됨. 기본 표시 한자에는 앞의 exact pair만 기록하고, 다른 문자열은 별도 후보로 보존.
- P1/P2: 논문 표기는 한자어를 포함한 관용 표기다. 현재 순우리말/해부학회 번역을 추측하지 않아 `korean=null`; head-specific Hanja도 없음.
- P3: `교근의 천부`는 검색 색인에서 관찰한 부분 표기. 부모 근육의 `깨물근` 또는 `咬筋`을 부분명에 자동 확장하지 않아 `korean`/`hanja`는 null.

검색 색인 및 열린 웹 자료 어느 것도 사람 해부학 검토를 대체하지 않는다. 모든 대상은 `humanReviewed=false`, `not_performed`다. TA2 PDF 페이지 시각 검사도 하지 않았다.
