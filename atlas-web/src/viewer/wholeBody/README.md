# Local whole-body integration (T56)

One controller owns `AnatomySceneRoot`, camera, controls, lights, renderer and the update loop. React never keys the viewer by region. Region changes update demand/visibility and explicitly frame that region. Selection, layer changes, asynchronous completion, retry and context restoration do not reframe the camera. Future motion controllers must use `addUpdate()` and restore their own deltas; this task creates no motion or OpenSim registration.

From `atlas-web`, run `pnpm prepare:whole-body` once with the frozen T70/T71/T72 local source caches available, then `pnpm dev`. The preparation script verifies parent/sibling hashes, unchanged inherited rows, input GLB hashes, unique IDs and source metadata. It repacks existing accessor bytes into 27 regional/layer chunks without changing geometry, source IDs, coordinates or source hashes. The ignored cache contains about 65 MB. Regeneration is deterministic. `pnpm test:whole-body` checks lifecycle/policy and output bytes. `/qa/t56.html` runs actual-GLB lifecycle verification with an injected one-time HTTP failure and actual WebGL context loss/restore. It is a developer entry, not learner navigation or a production build entry.

T70 contributes 493 unique source IDs. T71 and T72 are siblings over that same parent; merge their **new** 9 and 11 IDs rather than replacing one sibling with the other. 513 unique IDs are integrated, 481 are default visible, 12 held IDs stay invisible/unpickable, 20 supplements require explicit local opt-in. Only the existing 10 source bindings are pickable. Selection of a catalog parent may highlight its existing bound child IDs without adding a new binding. Left-side routes do not reuse right-side bindings.

Only the known bone/muscle layer and recorded region memberships drive demand. There is no validated superficial/deep muscle classification or high-LOD dataset in these inputs; neither is inferred. Optional supplements are request-loaded, and disabling a region/layer cancels unneeded pending requests. Completed chunks remain in a bounded-by-manifest cache (513 source nodes maximum) until scene disposal. Stale parse results are disposed. Idle scenes do not redraw, while registered updates use the single renderer loop.

The local Vite middleware serves only allowlisted hash-checked generated chunks. It deliberately has no preview hook or build emission. Public redistribution is still held. A production build therefore displays a clear unavailable state without a calf fallback; serving these assets in a released product requires a separately authorized rights/hosting decision. No source-only record is a canonical term, learner card, reviewed anatomy, whole-body denominator or completed coverage. Bone-root gaps remain 26. The initial region route remains the pre-existing route; branded opening/full-body home and final UX belong to T57/T58.
