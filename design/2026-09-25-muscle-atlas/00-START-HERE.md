# 근육 Atlas 설계·Luna 직렬 실행 패키지

작성일: 2026-09-25. 개정: 2026-09-26 T13b 인계 갱신. T11-B01–B09는 gaps가 남은 조사 배치, T12는 technical pass, T13은 실제 표면 검토 대기 상태다. T13a 학습 화면 회귀 수정과 T13b 분리 draft 공간자료 경로는 technical pass이며 현재 다음 작업은 **T13c-B01**이다. T13 표면 후보와 사람 검토는 0/41이다. 최신 상태의 기준은 `work/STATUS.md`이며 이 문서 자체는 완료 증거가 아니다.

## 결론

**전신 근육 지식 데이터베이스를 중심에 두고, 3D는 그 데이터를 보여주는 화면으로 만든다. 구조 → 기능 → 평가 순서로 확장한다.** 첫 구현은 오른쪽 종아리 6개 근육으로 검증하고, 구조를 전신으로 확장한 다음 기능과 평가를 같은 순서로 채운다. 치료는 이번 범위에 포함하지 않는다.

이 패키지는 웹앱의 설계서다. 실제 근육별 내용, 검증된 기시·정지 좌표, 완성된 전신 웹앱을 제공하는 문서가 아니다. `OpenSim_Models`는 읽기 전용 원본이다. 첨부 이미지의 침·혈자리·깊이·디버그 문구는 참고 이미지 안의 내용이며 이번 요구사항으로 채택하지 않았다.

## 읽는 순서

1. `01-PRODUCT-AND-ARCHITECTURE.md`: 무엇을 만들고 왜 그렇게 나누는가.
2. `02-DATA-CONTRACT.md`: 용어, 기시·정지, 3D 연결, 기능, 평가의 데이터 규칙.
3. `03-LUNA-SERIAL-RUNBOOK.md`: 실제 작업 순서·산출물·완료 기준·실패 복구.
4. `04-SOURCES-AND-DECISIONS.md`: 확인한 자료, 출처 전략, 아직 검증하지 않은 사항.
5. `templates/`: 다음 모델이 이어받을 진행 상태와 작업 보고 양식.

## 완료를 과장하지 않는 세 가지 이정표

- **구조 파일럿:** 오른쪽 종아리 6개 근육을 세 언어로 찾고, 뼈 표지와 기시·정지를 확인할 수 있다. 메시·용어·부착부의 검토 범위가 표시된다.
- **전신 구조:** 동결한 전체 목록의 모든 항목을 찾을 수 있고, 기시·정지 설명의 누락과 3D 미지원 항목을 별도 목록으로 확인한다. 목록이 있다는 것만으로 전신 구조 완성이라고 부르지 않는다.
- **구조·기능·평가:** 근육에서 작용으로, 작용에서 검사로, 검사에서 관찰·해석의 한계로 이동할 수 있다. 개별 검사 결과만으로 원인 근육을 확정하지 않는다.

전신 3D 부착 영역을 모두 직접 검토하는 일은 코드 작성만으로 대체할 수 없다. Luna가 목록·입력·검증 도구를 만들고 자료를 정리하되, 근거가 없는 한자명이나 해부학적 위치를 추측으로 완성하지 않는 것이 실행의 핵심이다.
