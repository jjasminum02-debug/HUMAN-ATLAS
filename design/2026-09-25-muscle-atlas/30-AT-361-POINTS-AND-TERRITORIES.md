# AT1–AT29 — 361혈 전체와 체표 영역

2026-10-11 사용자 결정 반영. **계획이며 AT 구현은 미착수**다. 이번 요청에서 별도로 제거한 기존 ‘관찰 시점’ 메뉴는 AT 기능 완료가 아니다.

## 1. 이번에 확정한 범위

사용자 답변: **우선 14경맥 361혈 전체**. 이전 29 설계의 ‘12정경 우선/임독맥 제외’와 AC1–AC5 향후 실행 순서는 이 문서로 대체한다. 경외기혈·이침은 이번 범위에 포함하지 않는다. 기존 기능과 역사 evidence는 삭제하거나 완료로 재분류하지 않는다.

- 임맥·독맥을 포함한 361개 경혈의 명칭·검색·선택·위치 표시.
- 좌우가 있는 경혈은 양측, 정중혈은 정중에 표시한다. 361은 고유 명칭/코드 수이며 화면 점 개수와 다르다.
- 선택 경맥의 점·체표 학습 경로·경맥별 색 영역, 모든 경혈 보기와 영역 전체 비교.
- 경혈 카드의 기본 위치 및 이후 교과서 설명 입력 경로.
- 기존 카메라에서 부드러운 경맥 선택과 따라보기. 별도 관찰 시점 메뉴 없이 화면 맞춤/선택 맞춤 사용.
- 새 인체 앱/renderer, 전체 UI 개편, 자침 깊이/방향·치료 시뮬레이션은 범위 밖.

## 3. 색 영역은 실제로 어떻게 만드는가

**인체 표면의 일부 삼각형을 선택해 색칠하는 방식**을 기본으로 한다. 화면 위의 평면 그림이 아니라 인체와 같은 좌표에 붙어 회전하는 면이다. 전신 carrier 하나 또는 연결된 부위 patch 집합을 모든 경맥이 공유하고 경맥마다 인체 geometry를 복제하지 않는다.

작성/표시 순서:

1. **기준 표면 고정:** 몸통·머리·팔·다리·손발의 고정 topology, frame/pose/metre와 hash를 등록한다. 표면 교체 시 기존 mask가 조용히 다른 곳에 붙지 않도록 stale 처리한다.
2. **경계 지표 작성:** 경맥별로 앞/뒤/측면의 범위를 설명할 landmark와 경계 control point를 작성한다. 첨부 사진을 몸 앞면 전체에 투사해서 끝내지 않는다. 보이지 않는 뒤쪽은 별도 자료/해석으로 작성한다.
3. **표면 위 윤곽 생성:** 같은 부위의 인접 face를 따라 윤곽을 연결하고 내부 face를 채운다. 가까운 다른 손가락이나 맞닿은 몸통으로 건너가지 않도록 부위 component와 경계 조건을 쓴다. 외곽선의 가장 짧은 경로도 해부학 정답으로 취급하지 않는다.
4. **mask 저장:** 예를 들어 `channel=ST`, `carrierHash`, `boundaryRevision`, `triangleIds`, `weights`, `basisKind`, `sources`를 저장한다. weight는 렌더링 농도용이며 치료 영향력·확률이 아니다. 실제 schema는 기존 Territory를 확장해 통일한다.
5. **체표 위 렌더:** 선택 경맥의 patch를 은은한 색으로 표시하고, 경혈 점과 경로는 더 선명하게 표시한다. depth test와 작은 시각적 offset/polygon offset으로 표면 겹침을 제어한다. 원래 근육 material을 영구 변경하지 않는다.
6. **경계 수정:** review 화면에서 칠하기/지우기/undo/redo, 경계점 이동과 수정 전후 비교를 한다. 수정은 mask에만 적용하여 경혈 anchor/경로/인체 hash를 보존한다.

복잡한 3D 조형 툴을 새로 만드는 대신 **triangle mask 편집 하나**로 시작한다. 좋은 UV가 확인되지 않은 상태에서 UV paint 시스템까지 병행하지 않는다. 초기 alpha 0.2–0.35, 경계 feather는 시각 QA에서 조절하는 디자인 값이며 생물학적 경계 폭이 아니다. 부위 표면이 끊기면 새 contour component로 나누고 공간을 가로지르는 띠로 연결하지 않는다.

### 선택한 영역과 전체 비교

- 기본: 선택한 경맥의 점·선·영역 하나. 원래 근육·뼈와 사용자의 layer 상태를 유지한다.
- 전체 경혈: 대상 점을 모두 표시한다. 이름은 확대 정도에 따라 줄이고 현재 선택 이름만 펼친다. label 축약 때문에 실제 점이 빠지지는 않는다. 후면 점은 뒤로 돌리면 볼 수 있어야 한다.
- 전체 영역 비교: 14개 색 범례를 제공하고, 선택 영역은 채움+경계, 나머지는 옅은 채움 또는 윤곽으로 표시한다. 무조건 14색을 진하게 섞지 않는다.
- overlap: 두 경맥 자료가 겹치는 면을 강제로 한쪽에 배정하지 않는다. 우선 표시 순서가 해부학적 우열이라는 뜻이 아니며, 선택 시 해당 영역을 전면 강조한다.
- 선택한 경혈: 그 혈의 소속 경맥 영역을 강조한다. **각 혈마다 고유한 치료 반경 361개를 만들어내지 않는다.** 개별 혈의 확대용 원/halo는 선택 장식이지 효과 영역이 아니다.

### ‘위경 영역이 너무 넓다’의 처리 예

교수님이 지적한 구간을 선택 → 현재 ST mask와 대조 자료 확인 → 가슴/배/허벅지 등 해당 구간의 경계점이나 칠해진 면만 수정 → 전면·사선·측면 같은 카메라 비교 → 새 boundary revision 저장. ST1–45의 위치와 경로는 바뀌지 않는다. 폭을 일괄 20% 줄이는 것만으로 정확성을 주장하지 않는다.

사진은 경근/피부/경맥 학습 영역 중 정확한 이론과 판본이 불명확하다. 그 상태에서도 **AI가 문헌을 조사해 학습용 해석 초안을 작성하고 수정할 수는 있다.** 그림을 확정 해부 경계로 간주하거나 자료가 없다는 이유로 모든 그래픽 개발을 차단하지 않는다. 교수 피드백은 이 초안을 정교하게 만드는 입력이다.

12정경의 경근 설명과 임독맥의 학습 강조 면은 유형이 다르다. 임독맥에 임의의 13번째·14번째 경근을 만들지 않는다. 경근 자료가 있는 경우 주행/관련 근육은 별도 관계로 제공하며 **색 면 완료를 실제 경근 해부 모델 전부 완료라고 부르지 않는다**. 신경 지배·피부분절도 독립 레이어다.

60분에는 남은 작업을 확인하고 80분에는 안전한 checkpoint와 실제 미완 unit을 남긴다. 성공하면 즉시 종료하고 최소 시간을 채우기 위해 기다리지 않는다. 두 번 연속 같은 원인이면 다음 회차는 동일 재시도 대신 접근 교정으로 사용한다. 새 번호를 자동 발급하지 않는다. **시간상한 준수와 기능 합격은 별개**이며, 80분이 됐다는 이유로 partial을 pass로 바꾸지 않는다.

AT8–18 예상은 모든 점을 처음부터 손으로 그리는 시간이 아니다. 규칙이 명확한 데이터는 일괄 처리하고 모델 대응이 어려운 점만 수정하는 시간이다. 공통 도구가 준비되지 않았다면 위치 task부터 밀어붙이지 말고 담당 AT5를 바로잡는다.

## 5. 완료와 미완을 명확하게 계수

- 전체 경혈 표시 완료: 361개 코드가 검색되고, 각 대상 instance의 실제 위치를 선택·관찰할 수 있다. 클릭 목록만 있거나 모든 좌표가 DEV proposal이면 실패다.
- 좌우/정중 instance 수, 실제 표시 가능 수, 교육용 개략 수, 기준 구조 대조 수, 미해결 수를 각각 기록한다. 품질 단계가 다른 점을 하나의 ‘정확도 100%’로 합치지 않는다.
- 구강/회음/발바닥 등 접근이 어려운 점도 명시적으로 포함한다. 정상 가림은 누락이 아니지만 점을 선택했을 때 같은 장면에서 확인할 수 있어야 한다. 보이지 않는다고 엉뚱한 체표로 이동시키지 않는다.
- 14개 경맥 선택 각각에 독립 영역 mask가 있고, 근거 유형과 수정 가능성이 확인되어야 영역 기능 완료다. 자료가 없는 경계는 초안 여부를 표시하며 정설로 표현하지 않는다.
- 교과서 전체 해설은 사용자 자료 입력 여부에 따라 따로 기록한다. 교재 대기만으로 이미 검증한 표준명/기본 위치/기술 기능까지 미완으로 되돌리지 않는다.
- 공개 재배포 상태는 로컬 학습 기능 완성과 별도다. 이번 계획/구현 프롬프트는 push나 배포 권한이 아니다.

## 6. 효율·상태·Git

한 controller, 한 overlay, 공통 compiler, 경맥별 compact data를 쓴다. task별 loader를 늘리지 않는다. 점은 공유 geometry/instancing을 우선하고, 화면 label만 축약한다. mask는 body geometry 복사 대신 부위 index/weight를 저장한다. 전처리는 offline이며 관찰 중 매 frame 전체 표면 탐색을 하지 않는다.

기존 20MiB overview / 96MiB geometry / 1M active triangles / 8MiB chunk 예산을 그대로 쓴다. AC2에서 overview 잔여가 작았으므로 전신 carrier를 그대로 initial bundle에 넣지 않는다. 선택 부위 stream, 공통 topology 참조, binary packing/LOD를 사용하고 전체 점 보기 비용을 실제 측정한다. 증거·교재 원문·검토 기록은 앱과 분리한다.
